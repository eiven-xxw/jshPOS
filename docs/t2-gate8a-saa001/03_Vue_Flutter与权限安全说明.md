# Vue、Flutter 与权限安全说明

## 1. Vue 平台运营旅程

`admin-web/src/views/saas/operations/index.vue` 提供三组内部正式旅程：

1. 套餐与权益：创建套餐、创建权益草稿、校验、独立审批、发布和显式生效；
2. 商户开户：创建、预检、独立审批、一次性技术开户、初始化检查点和激活；
3. 生命周期：暂停、停用、受控恢复、注销申请和逻辑注销。

前端请求守卫禁止把 `tenantId/state/approverUserId/technicalTenantId/lifecycleState/quotaUsed`
混入请求体。页面仅展示服务端状态、版本、摘要和检查点，不计算权益、配额或生命周期。
所有写操作使用稳定幂等键并禁用重复点击；不确定结果只能沿原命令查询或重试。

## 2. Flutter 契约

Flutter 本批不新增商业运营页面，只提供受限状态提示模型：ACTIVE 正常；暂停、停用、
注销申请和逻辑注销显示明确原因及受控恢复能力。客户端不得自行延长、恢复、切换套餐，
不得因旧快照静默继续经营。

## 3. 权限与审计

- 平台运营权限拆分为读、创建、预检、审批、技术开户、初始化、激活、套餐、权益发布、
  生命周期和配额消费。
- 申请和权益审批强制与创建人分离。
- 关键操作记录操作者、理由、前后状态、请求摘要、关联标识和稳定结果引用。
- 缓存、任务、导出和对象存储不得使用客户端租户值作为授权；本批未新增这类运行时。
- 真实客户资料、真实 PII、生产 Secret、真实收费和外部执行均禁止。
