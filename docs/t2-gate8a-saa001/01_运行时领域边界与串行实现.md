# T2-SAA-001 运行时领域边界与串行实现

## 1. 准入与结论边界

- 起点：`bcfcaa4621ea55c61bd1cd22fc355b5f74d8dae4`
- 分支：`t2/gate8a-sprint24a-saa001-runtime`
- Requirement：仅 `T2-SAA-001`
- Owner：`jshpos-saas`
- 技术租户 Owner：Foundation 经 `TenantProvisioningPort` 适配 RuoYi System
- 证据上限：`INTERNAL_SYNTHETIC_SOFTWARE_ONLY`

SaaS Owner 写商户申请、套餐、权益版本、租户商业生命周期、配额、幂等命令、审计和
Outbox。它不依赖 `ruoyi-system`，也不直接写 `sys_tenant` 或其他业务 Owner 私有表。
Foundation 只承载技术租户写入适配，不承载套餐、审批或商业生命周期规则。

## 2. 串行实现

1. 建立独立模块、状态机、不变量和 Foundation 端口；
2. 实现申请创建、预检、职责分离审批和服务端 tenant_id 分配；
3. 实现套餐、权益版本、发布生效、服务端授权和原子配额；
4. 实现技术租户、权益绑定、Owner 初始化检查点、激活、暂停、停用、恢复和逻辑注销；
5. 固化 V81/V82 前向迁移、MyBatis-Plus/XML 边界、审计、Outbox 和并发失败关闭；
6. 提供 Vue 平台运营旅程与 Flutter 受限提示契约；
7. 以固定故障向量、MySQL 8.4、双平台 CI 和证据索引收口。

## 3. 状态机与冻结点

- 申请：`DRAFT → PREFLIGHTING → READY → APPROVED → PROVISIONING → INITIALIZING → ACTIVE`；
  失败和取消使用具名分支，禁止跨阶段跳转。
- 权益：`DRAFT → VALIDATING → READY → APPROVED → PUBLISHED → EFFECTIVE`；发布前检查
  有效窗口，发布后内容和摘要不可变。
- 生命周期：`PENDING_ACTIVATION/ACTIVE/SUSPENDED/DEACTIVATED/TERMINATION_REQUESTED/
  RETENTION_HOLD/TERMINATED_LOGICAL` 只经具名迁移推进；历史只追加。
- 冻结点：申请内容摘要、Foundation 分配的 tenant_id、套餐与权益版本、初始化检查点、
  生命周期版本、幂等键与请求摘要。

## 4. 关键不变量

- 租户创建前操作只允许平台管理员；租户管理员不得替代。
- `tenant_id` 只接受 Foundation 返回值或认证后的可信租户上下文。
- 创建人与审批人必须分离；并发修改使用状态条件和乐观版本失败关闭。
- 同幂等键同内容返回原结果；同键异内容拒绝。
- 暂停、停用和逻辑注销不删除订单、支付、退款、库存、成本、审计或其他历史事实。
- `REFUND/RECONCILIATION/AUDIT/BACKUP_RESTORE/LEGAL_EXPORT/DATA_MIGRATION/
  DATA_DELETION_REQUEST` 在受限状态保留受控入口。
- 本需求不产生真实订阅收费、支付或资金效果。
