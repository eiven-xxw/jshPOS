# 测试矩阵、故障注入与重复运行手册

## 1. 量化门禁

| 域 | 门槛 |
|---|---|
| 治理 | Ubuntu/Windows 均通过 RTM、ADR、范围、Secret 和零外部执行检查 |
| Server | `ruoyi-admin -am clean verify` 全绿；SaaS Domain 行覆盖≥90%、分支≥85% |
| MySQL | MySQL 8.4 从 V1 到 V82；validate 通过；历史触发器和原子配额有效 |

| 缺陷 | P0=0、P1=0；禁止自动重跑掩盖 Flaky |

30 个固定向量位于 `contracts/t2/gate8a-saa001/fixed-vectors.json`，覆盖开户、技术租户、
权益、配额、生命周期、租户攻击、迁移、Web/Flutter、外部零执行和 Outbox 恢复。

## 2. 本地重复运行

PowerShell：

```powershell
python scripts/check_t0_structure.py
python scripts/check_rtm.py
python scripts/check_contracts.py
python scripts/check_t2_gate8a_saa001.py

$env:JAVA_HOME='C:\Program Files\java'
Set-Location server
.\mvnw.cmd -pl ruoyi-admin -am clean verify -DskipTests=false

Set-Location ..\admin-web
pnpm build:prod
pnpm lint:eslint
pnpm typecheck
pnpm test:unit:ci

Set-Location ..\pos-flutter
flutter analyze --fatal-infos
flutter test
```

MySQL 迁移测试必须使用隔离空数据库，通过 `GATE8A_SAA_MYSQL_JDBC_URL/USERNAME/PASSWORD`
注入测试容器凭据；不得使用生产或商户数据库。CI 证据由专用 Workflow 自动执行和聚合。

## 3. 失败处置

- 测试失败保留原日志和 seed，不删除用例、不降低阈值、不自动重跑。
- 迁移失败不得修改 V81/V82；新增前向修复迁移并重新从空库验证。
- Secret/PII 命中立即停止封板、吊销材料并清理普通制品。
- 外部 Provider、设备、外设或伙伴执行计数非零时本 Gate 直接 NO-GO。
