# 运行时范围与兼容边界

## 已准入变化

- Reporting Owner 新增 `readInventoryCost` 受控批量读取端口。
- 新增 `/api/v2/reports/inventory-cost-daily` 有界 keyset 查询，单页上限 500。
- 新增 HMAC-SHA256 签名游标，绑定可信租户、筛选摘要和冻结投影版本。
- 库存成本导出按最多 10,000 行分批流式写入，检查点保存原请求摘要、原投影版本和原最后键。
- MySQL 测试探针采集固定 10k/100k 的 JSON/TREE 执行计划、查询数、逐键完整性和十二字段守恒。

## 冻结边界

- v1 Controller、OpenAPI operation 与 `queryInventoryCost` Mapper statement 保持兼容，不在本批改写。
- Reporting 只读自身可重建投影，不改变 Inventory、Costing、Tenant、Sync 或事件事实。
- 未新增依赖、索引、数据库对象或 Flyway 迁移。
- 缺少 `JSH_REPORT_INVENTORY_CURSOR_HMAC_KEY_B64` 或密钥非法时，v2 游标能力失败关闭。

## 回退

回退应用代码即可停止 v2 入口；v1 仍保持兼容。已生成导出检查点绑定原请求摘要和原投影版本，
不得在回退或重启后使用新身份续跑。任何数据库索引需要独立前向迁移，不属于本批回退范围。
