# 测试矩阵与停止线

| 维度 | 验证 | 退出标准 |
|---|---|---|
| 交互查询 | v2 limit、limit+1、next cursor | 每页不超过 500，顺序稳定 |
| 游标安全 | 坏签名、跨租户、筛选变化、投影变化 | 全部失败关闭 |
| 导出恢复 | 中断、检查点、同请求恢复 | 复用原 request SHA、projection、last key |
| 租户权限 | 可信 tenant、门店授权、缺席租户 | 0 越权 |
| MySQL 完整性 | 10k/100k 全量 keyset 导出 | 0 重复、0 缺失 |
| 数据守恒 | 7 个数量字段与 5 个成本字段 | 十二项逐字段等于权威投影汇总 |
| 查询数 | 交互与流式导出 | 交互 1 次；导出按固定批大小增长，不按门店增长 |
| 执行计划 | EXPLAIN JSON/TREE、SHOW INDEX | 如出现全扫或 filesort，停止并提交独立索引 CR |
| 兼容 | v1 SQL/API 摘要与契约 | 无语义变化 |
| 迁移 | 与准备封存提交比较 | 迁移变化为 0 |

MySQL 计划结论只能来自 GitHub `mysql:8.4.11` 固定执行器。当前本地环境不具备 Docker，
不得用本地静态推断替代可执行计划证据。
