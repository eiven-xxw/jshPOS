# T2 外部依赖并行解阻计划

## 1. 原则

外部输入可以与内部需求治理并行，但不能被 Fake、静态文档或现金路径替代。每个解阻项必须记录资料提供方、版本、授权环境、证据等级、Owner、截止点和失约回退。

## 2. 主认证 Android 设备与外设

### 当前状态

`T1-HWD-002`、`T1-PRN-001`、`T1-SCN-001`、`T1-SCL-001`、`T1-IO-001` 继续 `BLOCKED`；映射 `T2-HWD-001`、`T2-PRN-001` 也保持 `BLOCKED`。

### 必需输入

| 类别 | 必填信息 | 截止点 |
|---|---|---|
| 主机 | 厂商/型号、Android/补丁、CPU/内存/存储、固件、生命周期、采购/RMA | S0 结束前选候选，S2 前到样机 |
| SDK | 获取方式、版本、许可证、Demo、错误码、线程模型、升级/兼容联系人 | S1 前 |
| 打印 A | 主机内置 SDK、纸宽、切刀、状态、队列、连续打印 | S2 前 |
| 打印 B | USB/网口/蓝牙标准外置方案、协议和替代件 | S2 前 |
| 扫码 | 内置/USB/HID/Camera、广播/KeyEvent、条码集合、重复输入 | S2 前 |
| 电子秤 | 品牌型号、串口/USB/网口、协议、精度/单位/去抖、计量合规边界 | S4 前 |
| 钱箱/客显 | 接口、电平/命令、副屏协议、能力探测和断连恢复 | S2/S3 前 |

### 解阻门槛

资料完整→法务/安全审查→样机登记→L1 实验室→L2 认证矩阵。仅完成资料不等于 `REAL_DEVICE PASS`。

### 回退

S2 前无主机：继续厂商无关契约和桌面 Android 模拟，不宣称 POS 可发布；社区超市秤能力从 T2 Alpha 主闭环移除。

## 3. 支付沙箱

### 当前状态

`T1-PAY-002` 和 `T2-PAY-002` 继续 `BLOCKED`。五家 Fake 只提供契约输入。

### 候选池

易宝、汇付、拉卡拉、银盛、富友、随行付、收钱吧、乐刷、银联商务、通联等候选，最终只选择一家作为商业 V1 主支付；品牌列表不代表已签约或推荐结论。

### 必需输入

- 合作方主体、商务/技术联系人、服务地区和行业准入；
- 正式接口文档版本、SDK/签名库、许可证和变更政策；
- 沙箱商户/门店/终端、测试密钥注入方式和测试账单；
- 统一下单、查询、撤销、退款、回调、账单/对账、错误码和限流；
- 支付终端/扫码模式、回调公网策略、证书轮换和 IP 白名单；
- 成功/失败/超时/UNKNOWN/重复乱序回调/退款 UNKNOWN/对账差异测试能力；
- 沙箱验收标准和对方签署人。

### 截止与回退

S0 结束前确定主候选，S2 前账号/文档齐备，S3 完成沙箱最小闭环。S2 前未解阻：Gate 3 保持 `NO-GO`，只完成支付核心状态机和 Provider 端口设计，不实现真实网络适配器；现金 Alpha 不替代电子支付 Alpha。

## 4. 设计伙伴

### 当前状态

`T1-PAR-001` 与 `T2-PAR-001` 继续 `BLOCKED`。

### 目标

- 5 家目标伙伴，至少 3 家书面表达试点意愿；
- 便利店为主要样本，最多 1 家零食折扣和 1 家社区超市条件样本；
- 签署保密、数据授权、反馈频率、现场责任、旧系统对账和退出机制；
- T2 只允许授权脱敏样本进入受控环境，不进入仓库或公开制品。

### 截止与回退

S2 前完成名单和意愿，S4 前完成脱敏迁移样本。未达成不阻断合成数据 Alpha，但阻断 T4 试点和任何市场可用声明。

## 5. 鲸熵汇

`T1-JSH-001`、`T2-JSH-001` 继续 `DEFERRED`。按项目发起人指令，在收银主体完成后提醒提供：接口目录、鉴权、限流、沙箱、回调、数据主权、验收、变更策略和负责人。

不得猜测协议或提前创建“已接入”的 Provider。连接器 Runtime 和标准契约可独立设计，但鲸熵汇最小闭环不进入 T2 Alpha 主关键路径。

## 6. 商业许可证

`T1-LIC-001`、`T2-LIC-001` 继续 `DEFERRED`，不阻断 T2-Prep 和经批准的内部 Alpha，但阻断商业发布。

| 组件 | 当前事项 | 所需结论 | 最迟截止 |
|---|---|---|---|
| Aviator | 许可证/商用边界或替换 | 法务批准或替换测试 | T3 结束前 |
| simple-http | 许可证/来源/维护性 | 法务批准或移除 | T3 结束前 |
| MySQL Connector/J | 分发与服务使用边界 | 法务书面结论或替换方案 | T3 结束前 |

每次新增依赖仍需即时许可证和安全审查，不能以这三项延期为普遍豁免。

## 7. 外部解阻状态变化

状态只在以下证据全部到位后变更：

1. 资料版本和来源可追溯；
2. 授权环境与测试对象明确；
3. 测试按预定义矩阵执行；
4. 原始证据、摘要、限制和失败保留；
5. 责任 Owner 和独立验收人签署；
6. RTM、风险台账和 CR 同步更新。
