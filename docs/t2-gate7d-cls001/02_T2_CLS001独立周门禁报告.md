## 3. 开发期缺陷与修复

1. 封板复核发现 Operations Owner 虽已加入模块依赖，但未进入商业 V1 启动时的唯一
   能力装配校验。已补入 `CommercialV1AssemblyContract` 并把唯一能力数由 17 更新为
   18，增加缺失/重复装配失败关闭回归。
2. 初始列表 API 允许省略 `storeId`，可能退化为租户内全部门店查询。已在 OpenAPI、
   Controller、应用服务和 Vue 请求契约中将门店改为必填，服务端再次调用数据范围授权，
   并增加未指定门店失败关闭测试。
3. 量化对照发现百万级合成事实只有固定向量而无实际执行。封存变更新增 MySQL 8.4
   一百万行精确整数聚合测试，断言数量与金额守恒并输出 `SYNTHETIC_NOT_SLA` 边界。
4. 上述问题均在候选/封存提交内修复；没有降低阈值、跳过测试、自动重跑失败 Job、
   修改已发布迁移或创建测试后门。
