# T2-SUB-001 Vue、Flutter、权限与降级说明

## Vue 运营旅程

运营工作台支持创建草稿、读取服务端权威状态、激活、续期、暂停、受控恢复、申请终止和逻辑终止。
写操作使用稳定幂等键：失败时保留原键供安全重试，成功后才生成下一业务命令。页面只提交期限、外部引用和
原因，不提交权威租户状态、套餐结果、访问模式或服务端时间。

权限分别为读取、创建、激活、续期、暂停、恢复、终止和调度。平台操作在服务端再次校验平台管理员身份；
租户用户只能读取可信上下文中的自身摘要。跨租户读取、缓存污染、任务冒充和客户端 tenant 注入均失败关闭。

## Flutter 受限提示

POS 只展示服务端下发的订阅状态、访问模式、到期/宽限时间和恢复能力列表，不根据设备时间自行推导状态。
未知状态、缺少权威字段或受控访问失败时显示明确受限提示，不伪造正常权限，也不静默离线降级。

Flutter 本批不新增计费、支付、通知或后台订阅状态机。既有 POS 交易事实、退款和同步恢复能力通过服务端
权益端口受控保留，客户端不得通过隐藏页面、改本地时间或伪造 tenant 绕过授权。

## 安全边界

合同和订单仅保存不透明引用；真实合同正文、Secret、商户号、支付数据与真实 PII 不进入仓库、日志、CI 或普通制品。
提醒仅形成内部通知意图和 Outbox，不发送真实短信/邮件。所有外部执行计数保持为 0。
