20 个固定向量位于 `contracts/t2/gate8a-sub001/fixed-vectors.json`，覆盖状态迁移、期限、宽限、
重复任务、时钟偏移、幂等冲突、提醒、受控降级、恢复、租户攻击、迁移和外部零执行。

## 2. 关键故障预期

- 重复命令返回原结果；同键异内容拒绝。
- 扫描任务使用持久化租约；重复、并发、重启和时钟偏移不得重复产生业务效果。
- SaaS 访问投影失败时订阅状态、审计和 Outbox 同事务回滚，不出现半完成授权。
- 期限/状态乐观锁冲突失败关闭；不得覆盖只追加历史。
- 到期、暂停和终止不物理删除历史；恢复追加新期限并保留完整状态链。
- 提醒仅写通知意图；本 Gate 不接真实短信、邮件或 Provider。

## 3. 本地重复运行

```powershell
python scripts/check_t0_structure.py
python scripts/check_rtm.py
python scripts/check_contracts.py
python scripts/check_t2_gate8a_sub001.py

$env:JAVA_HOME='C:\Program Files\java'
Set-Location server
.\mvnw.cmd -pl ruoyi-admin -am clean verify -DskipTests=false

Set-Location ..\admin-web
pnpm build:prod
pnpm lint:eslint
pnpm typecheck
pnpm test:unit:ci

Set-Location ..\pos-flutter
flutter analyze --fatal-infos
flutter test
```

MySQL 测试只使用 CI 隔离空库，通过 `GATE8A_SUB_MYSQL_JDBC_URL/USERNAME/PASSWORD` 注入临时凭据。
本地缺少 Docker/Flutter 时不得伪造结果，必须由 GitHub 干净执行器补足并纳入最终证据。

## 4. 恢复与前向修复

- 保留失败日志和固定 seed；不得删除用例、降低阈值或自动重跑。
- 迁移失败保留 V83/V84，使用新迁移安全前向修复并从空库重验。
- Secret/PII 命中立即 NO-GO，清理普通制品并按保管规则吊销。
- 外部执行计数非零或保留状态漂移时，本 Gate 直接 NO-GO。
