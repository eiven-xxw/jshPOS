# T2-SUB-001 设计准入说明

## 结论

`T2-SAA-001` 已由项目发起人接受；`T2-SUB-001` 的数据主权、状态机、不变量、权限、审计、幂等、API/事件、迁移、容量、兼容、回退和测试均已冻结，准入状态为 `IN_PROGRESS`。

## 数据主权与事务边界

- Subscription Owner：订阅头、期限版本、状态事实、调度检查点、通知意图、审计和 Outbox。
- SaaS Owner：套餐/权益快照、技术租户商业生命周期和订阅访问投影。
- 每个 Owner 只写自己的表；同进程、同数据源下通过正式端口参与一个事务，但不开放跨 Owner Mapper。
- 续期只追加期限版本；状态和审计只追加；失败关闭，不物理删除订阅或业务事实。

## 状态、不变量与时间

状态固定为 `DRAFT、PENDING_ACTIVATION、ACTIVE、GRACE_PERIOD、SUSPENDED、EXPIRED、TERMINATION_PENDING、TERMINATED、RESTORED`。期限必须满足 `starts_at < ends_at <= grace_ends_at`，时区必须为有效 IANA 标识。客户端时钟只用于显示，所有判断使用服务端 `Clock` 与 UTC 时间。

## 权限、降级与非目标

平台写操作要求平台管理员权限；租户只可读取自身订阅摘要。商业 V1 只接受已冻结的 `RECOVERY-V1` 降级策略；到期/暂停保留八项恢复白名单能力，其余已购功能由服务端拒绝，未知策略版本失败关闭。真实计费、Provider、资金、发票、应付、总账、税务和真实通知渠道均不在范围。

## 容量与回退

按租户唯一活动订阅、期限版本只追加设计；扫描按到期索引分页并使用持久化租约。迁移只前进；运行时失败通过释放租约、保留原状态及具名人工重试恢复，禁止回写历史或回滚已发布迁移。
