## 3. 开发期缺陷与修复

1. 应用服务初始控制点测试把实际 17 个权限/租户/状态防线误写为 18。逐项核对后修正测试
   预期，并保留每个控制点的独立断言；没有删除控制点或降低覆盖率。
2. 修复结果回写初版没有强制验证乐观更新影响行数。现要求恰好更新 1 行，否则失败关闭，
   防止并发覆盖或不存在命令被误报成功。
3. Inventory/Costing 异常查询初版缺少显式门店 SQL 条件和服务端门店授权；现同时增加
   可信门店授权及 tenant/store 双范围 SQL，DataPackage 适配器也在异常捕获前完成授权。
4. 乱序或同序号异摘要观察初版可能推进来源头。现只追加观察/冲突，只有更高序号才推进
   来源头，固定回归覆盖重复、乱序、晚到与摘要冲突。
5. 首次候选 [Run 32615384874](https://github.com/eiven-xxw/jshPOS/actions/runs/32615384874)
   在 Ubuntu 治理 Job 暴露 Python `pathlib` 不接受递归 `**` glob 的跨平台问题；Windows
   本地未暴露。修复提交 `1166ac98cb4041a5a02e2e35fd6f63dd46dc40f1` 改用 `rglob`，
   随后重新运行完整流水线。
6. 失败 Run 和日志原样保留；没有删除用例、降低阈值、跳过 Job、自动重跑掩盖 Flaky、
   修改已发布迁移或创建测试后门。
