- 治理：RTM/ADR/CR/外部状态/零执行/历史 Blob 不变；
- Server：22 Owner 单元/集成、商业 JAR、300 项 API/OpenAPI、租户权限；
- 数据：空 MySQL 前向迁移、文件 SQLite、索引/约束、重建和守恒；
- Web：正式 dist 连接 live JAR，20 页既有回归和关键跨页旅程；
- Flutter：Ubuntu/Windows，正式 JAR、文件 SQLite、6 页可信会话与原命令恢复；
- 安全：Secret/PII、跨租户、权限、缓存/对象命名空间、外部失败关闭；
- 供应链：依赖、SBOM、许可证清单、APK/Kotlin 既有回归；
