# 生产装配与演示面收敛结果

## 收敛结论

商业无参数默认构建已只装配 22 个鲸熵汇 Owner 与必要平台基座。`ruoyi-demo` 活动生产源码、
服务端依赖、Springdoc 分组、Vue 页面/API/图标和四方言初始化种子已经移除；
`ruoyi-generator/ruoyi-workflow/ruoyi-job` 及 `ruoyi-common-job` 只保留在显式
`non-commercial-platform-tools` Maven profile，不能进入默认 reactor、商业 JAR 或聚合 SBOM。

- 没有修改资金、库存、订单、租户或审计事实；
- 没有通过隐藏菜单代替服务端隔离；
- 未删除 generator/workflow/job 的评估源码，只从商业默认装配隔离；
- 已随真实 SBOM 移除不存在的 Aviator/Javassist 旧许可证审批记录，但
  `T2-LIC-001` 状态没有改变；
- Provider 网络、真实资金、设备/外设、伙伴现场、完整 Alpha 和生产部署均为 0。

## 失败回归与修复

1. 初始装配审计按预期在 Maven/JAR、Web、SQL、SBOM 等 9 个检查面失败；
2. Web 类型检查发现删除工作流页面后残留 7 个 Process 组件引用，随后删除孤立组件并复跑通过；
3. 完整 Maven 首轮发现生产配置测试仍要求已移除的 SnailJob 配置，修正契约测试后 49 个
   Reactor 全绿；
4. SBOM 首轮许可证校验发现 Aviator/Javassist 已从制品移除但清单仍要求存在，清理过期审批后
   12 个实际受限许可证组件均完成精确审核。

这些失败均保留在实施记录中，没有通过自动重跑、跳过测试或降低阈值掩盖。
