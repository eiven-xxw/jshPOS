# T2-MEM-003 CR 与商业价值、范围和影响分析

## 1. 结论

建议 `CONDITIONAL GO`：基础会员等级权益与会员价进入商业 V1，但作为三业态共享、默认关闭、
按租户和门店显式启用的版本化能力。它不是强制要求每个门店经营会员，也不允许以便利店、
零食折扣店或社区超市为条件复制领域状态机。

正式决策仍由项目发起人作出；在确认前 Requirement 保持 `DRAFT / CR_REQUIRED`。

## 2. 业务问题

当前系统可以建立会员、处理隐私与同意、记录等级历史和积分，也能计算门店价、促销与人工
优惠，但缺少四个闭环：

1. 等级对应什么权益、在哪些门店和时间生效；
2. 会员价怎样作为价格候选并与促销确定性组合；
3. 离线 POS 怎样获得不含 PII、可验签且会过期的权益事实；
4. 订单和退款怎样冻结原权益，不因后续升级、降级、撤回或规则发布而变化。

若不补齐，运营人员只能手工改价或把会员权益伪装成普通促销，无法形成权限、解释、审计、
离线和退款一致性，商业 V1 的会员运营不可控。

## 3. V1 原子范围

### 3.1 包含

- 版本化会员权益策略与等级适用关系；
- 租户/组织/门店显式适用范围、未来生效、暂停、撤回和替代；
- SKU 会员价候选与基础会员权益 Adjustment；
- 普通价格、会员价、促销、人工优惠和抹零的固定计算顺序；
- 可解释报价、成交权益快照、订单金额摘要和原快照退款；
- 不含 PII 的签名离线权益/会员价包；
- 后台版本、范围、审批、发布、停用、审计和差异预览旅程；
- POS 会员识别、权益提示、过期提示、显式非会员重报和成交展示旅程。

### 3.2 不包含

- 储值、预付卡、钱包、资金沉淀；
- 复杂优惠券、券库存、营销预算抢占、秒杀名额；
- 加盟结算、总部补贴清分、供应商返利、跨币种；
- 新积分算法、积分抵现、离线积分核销；
- 真实 PII、短信/电话触达、画像、AI 动态定价；
- 跨租户会员权益、真实支付/设备/伙伴现场或商业 SLA。

## 4. 三业态边界

三个业态共用一个 Capability、状态机和计算器，差异仅通过版本化配置表达：

| 配置维度 | 便利店 | 零食折扣店 | 社区超市 |
| --- | --- | --- | --- |
| 默认状态 | 关闭 | 关闭 | 关闭 |
| 推荐策略 | BEST_PRICE | BEST_PRICE 且默认禁止折上折 | BEST_PRICE |
| 计量商品 | 可选 | 可选 | 支持精确数量快照 |
| 门店范围 | 显式 | 显式 | 显式 |
| 成本责任 | 销售门店 | 销售门店 | 销售门店 |

行业模板只能选择默认配置，不得改变金额守恒、退款、权限、隐私或 Owner 主权。

## 5. 影响范围

| Owner/端 | 复用 | 计划扩展 | 禁止 |
| --- | --- | --- | --- |
| Member | 档案、身份、等级、隐私、积分 | 权益策略版本、等级映射、最小权益快照 | 输出 PII、复制价格 |
| Pricing | 基础价、门店价、价格版本 | 会员价候选范围与解析结果 | 读取会员私有表 |
| Promotion | 报价、解释、分摊、成交快照 | MEMBER_BENEFIT Adjustment 和叠加判断 | 复制等级/价格事实 |
| Order | 订单金额、成交快照绑定 | 冻结会员引用、权益/价格/解释摘要 | 按当前权益重算 |
| Refund | 原单上限与原促销恢复 | 读取原会员权益/会员价快照 | 读取当前等级 |
| DataPackage | 签名、摘要、原子切换 | 最小权益包、会员价包或组合清单 | 下发 PII/Secret |
| Flutter POS | 最小会员缓存、报价和成交 | 权益状态展示、过期与显式重报 | 直接读 SQLite 拼事实 |
| Vue | 会员运营与价格促销页面 | 权益版本/范围/审批/发布向导 | 前端计算金额或写跨 Owner 表 |

## 6. 容量与成本假设

内部设计基线以每租户 100 个等级、1,000 个门店范围组、100k SKU 会员价项、每店每日
100k 报价为上限向量；这是合成设计输入，不是生产 SLA。会员权益包必须按门店和版本切分，
支持摘要复用和增量发布，不允许把全量会员名单下发到 POS。

## 7. 风险与控制

| 风险 | 级别 | 控制 |
| --- | --- | --- |
| 会员价与促销折上折造成毛利失控 | P0 | BEST_PRICE 默认互斥；双版本显式允许才叠加 |
| 离线旧权益继续优惠 | P0 | 短有效期、撤回纪元、验签、过期失败关闭 |
| 退款按当前等级重算 | P0 | 原订单不可变权益与价格快照 |
| PII 扩散到订单/包/日志 | P0 | 不可逆引用、字段白名单、Secret/PII 门禁 |
| 多门店责任不清 | P1 | 显式范围，优惠归销售门店；结算出 V1 |
| 兼容窗口导致新旧端结果不同 | P1 | 协议/Schema 版本、固定跨端向量、失败关闭 |

## 8. 准入结论

准备材料支持 `CONDITIONAL GO`，但尚未获得正式开发授权。`T2-MEM-003` 不可因文档完整而
转为 READY；ADR-053 继续 Proposed，所有运行时和外部执行保持 0。
