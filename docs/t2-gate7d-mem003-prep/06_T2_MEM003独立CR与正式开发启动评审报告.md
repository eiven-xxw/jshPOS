# T2-MEM-003 独立 CR 与正式开发启动评审报告

## 1. 评审结论

建议：`CONDITIONAL GO / AWAITING PROJECT SPONSOR CONFIRMATION`。

已完成商业价值、范围/非目标、数据主权、状态机、计算顺序、隐私、离线、多门店责任、API/事件、
持久化设计、兼容回退、跨端向量和量化验收准备。`T2-MEM-003` 仍为 `DRAFT / CR_REQUIRED`，
没有进入运行时编码。

## 2. 对五项 CR 问题的正式回答

1. 会员价是商业 V1 应具备的通用基础能力，但应作为三个业态共享、默认关闭的模板能力，不是
   所有门店强制流程。
2. 权益以不可变版本和显式状态生效；降级/撤回只影响新报价。离线快照短期有效，旧包、过期、
   撤回或摘要异常失败关闭，已成交按原快照。
3. V1 只做同租户显式门店范围，优惠经营责任归销售门店；不做加盟结算、总部补贴或成本清分。
4. 跨 Owner 和 POS 只使用不可逆引用、等级/权益版本、摘要与脱敏显示，不传播真实 PII；隐私删除
   不改写法定交易事实。
5. 复用现有 Member/Pricing/Promotion/Order/Refund/POS/DataPackage Owner；只允许前向迁移，
   回退关闭新版本但保留历史快照可读，不复制任何既有状态机或算法。

## 5. Go 条件

`T2-MEM-003`；先把 ADR-053 转 Accepted，再按 Member 权益 → Pricing 会员价 → Promotion 联动 →
Order/Refund 快照 → DataPackage/POS/Vue → E2E 的顺序独立实现和验证。任何前项未 VERIFIED，
后项不得铺开。

打印、伙伴、完整 Alpha、生产和商业发布均不在本次授权范围。
