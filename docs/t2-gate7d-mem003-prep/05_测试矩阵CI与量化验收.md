# T2-MEM-003 测试矩阵、故障注入、CI 与量化验收

## 1. 固定合成数据

- 两个虚构租户，各含至少三个门店和两个终端；
- 便利店、零食折扣店、社区超市三种模板，Capability 默认均关闭；
- 至少四个等级、多个未来/过期/撤回权益版本；
- 普通价、门店价、会员价、促销、人工优惠和抹零组合；
- 不使用真实姓名、手机号、商户、终端、支付或合作伙伴数据。

固定向量不少于 32 个，机器清单见 `member-benefit-price-vectors.json`。

## 2. 测试矩阵

| 类别 | 必测内容 | 量化标准 |
| --- | --- | --- |
| 状态 | 生效、未来生效、过期、降级、暂停、撤回、替代 | 非法迁移 100% 拒绝 |
| 计算 | 基础/门店/会员价、促销、权益、人工优惠、抹零 | Java/Dart 逐字段一致；金额守恒 100% |
| 退款 | 部分、最终、舍入余数、等级变化、权益撤回 | 100% 使用原快照；累计不超上限 |
| 离线 | 旧包、坏包、过期、撤回纪元、时钟偏移、业务日切换 | 全部失败关闭或显式重报 |
| 幂等 | 重复、同键异内容、乱序、晚到、ACK 丢失、重启 | 重复无第二业务效果；异内容 100% 拒绝 |
| 隔离 | tenant、store、缓存、任务、导出、对象存储 | 0 条跨范围数据可见或可写 |
| 隐私 | PII/Secret/令牌明文扫描、日志和制品 | 0 泄漏 |
| 容量 | 100k 价项、1k 门店范围、100 等级、100k 报价趋势 | 记录内部基线，不写商业 SLA |
| 兼容 | 双向客户端/服务端兼容、Schema 前向修复 | 不兼容必须失败关闭 |

## 3. 关键故障 seed

至少固定：等级在报价后降级、紧急撤回、包安装中断、摘要篡改、旧包重放、跨租户包、终端时钟
偏移、业务日切换、挂单后规则变化、身份合并/拆分、重复报价、同键异内容、部分 Owner 失败、
Outbox ACK 丢失、进程终止、部分/最终退款、最后一笔舍入、人工优惠审批失效和投影重建。

观察到的失败 seed 必须加入总账和回归，不得删除、随机跳过或用自动重跑掩盖。

## 4. 未来运行时 CI 门禁

独立开发阶段应包含：治理 Ubuntu/Windows、Server、Web、Flutter Linux/Windows、Android/Kotlin、
MySQL、SQLite、跨端向量、交易/退款故障、租户与门店攻击、Secret/PII、依赖、SBOM、许可证、
覆盖率、证据索引和既有 Gate 全量回归。不得降低现有阈值、修改已发布迁移或创建绿色占位。

准备阶段 CI 只验证：

1. EXC 已 ACCEPTED，MEM003/SAA/SUB/SVC 仍 DRAFT；
2. 外部 BLOCKED 和 DEFERRED 未漂移；
3. CR/ADR/DRAFT 契约/固定向量可解析且互相一致；
4. 相对基线的 server/admin-web/pos-flutter/迁移/依赖变更为 0；
5. 文档 UTF-8、RTM、契约、Secret/PII 和证据清单通过。

## 5. 正式开发完成的量化验收门槛

- 所有准入项从 READY 到 IN_PROGRESS 的转换均有机器证据；
- 固定向量至少 32 个，Java/Dart 结果逐字段一致率 100%；
- 金额守恒、退款上限、同键异内容、跨租户/门店攻击、过期/撤回失败关闭通过率 100%；
- P0/P1 缺陷均为 0，Flaky 测试为 0；
- 核心新增代码覆盖率不低于仓库现行阈值；
- 所有制品绑定 commit、SHA-256、SBOM、许可证和证据等级；
- 外部执行仍为 0，不能借本需求解除 SANDBOX/REAL_DEVICE/PILOT。

上述门槛是未来运行时 VERIFIED 的必要条件，不是本准备阶段的完成证明。
