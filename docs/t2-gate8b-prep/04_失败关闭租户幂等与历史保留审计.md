# 失败关闭、租户、幂等与历史保留审计

| 审计域 | 结论 | 强制规则 |
|---|---|---|
| 套餐权益 | PASS_WITH_EXISTING_EVIDENCE | 服务端依据已发布权益和可信租户判定；前端菜单不构成授权；并发配额原子校验 |
| 订阅访问 | PASS_WITH_EXISTING_EVIDENCE | ACTIVE/GRACE/RECOVERY_ONLY 等具名模式；权威 UTC 与版本化策略；降级保留受控恢复白名单 |
| Service 授权 | PASS_WITH_EXISTING_EVIDENCE | 每次访问重新校验 tenant/store/permission；附件对象键由服务端命名空间生成；短期链接到期失效 |
| tenant_id | PASS | 客户端 tenant、文件、缓存键或路径不作为授权依据；跨租户/跨门店失败关闭 |
| 幂等 | PASS | 稳定键+内容摘要；同键同内容返回原结果，同键异内容拒绝；重复任务与重启收敛 |
| 历史 | PASS | 商业生命周期、订阅、工单、责任、附件和审计历史只追加或受控状态迁移；停用/到期不得物理删除业务历史 |
| 恢复 | PASS_WITH_LIMIT | 受控恢复复用原租户和原命令；外部 Provider/设备不可用时只返回 BLOCKED/UNAVAILABLE |

## 审计限制

Gate 8B 新增测试只验证正式协议装配。上述 Owner 内部执行结论来自各自已接受测试、V81—V86 迁移、MySQL 和运行栈证据；不得用 Mock 结果替代这些证据。20 个固定向量见 `contracts/t2/gate8b-prep/fixed-vectors.json`。
