# Gate 6B 数据主权、状态机与不变量

## 1. 数据主权

| Owner | 可写事实 | 只读依赖 | 禁止 |
|---|---|---|---|
| Release Owner | 发布物、范围、灰度、软件任务、命令结果、事件、审计 | Terminal Registry、Sync、Shift、Payment、Refund、对象/公钥注册表 | 修改终端、订单、支付、库存或促销私表 |
| Sync/Terminal Owner | 终端身份、状态、版本、能力、Outbox | Release 只读任务 | 代写发布状态 |
| Payment/Refund/Shift Owner | UNKNOWN、班次等权威安全信号 | 无 | 让客户端自报“安全” |
| Hardware Adapter | 后续真实安装执行 | 受权只读任务 | 在 HWD 解阻前接入 |

## 2. 状态机

- 发布物：`DRAFT → SIGNED → STAGED`；任一未吊销状态可进入 `REVOKED`。`SIGNED` 后身份字段永久冻结。
- 灰度：`PLANNED → CANARY → ROLLING → COMPLETED`；CANARY/ROLLING 可 `PAUSED/FAILED`；PAUSED 仅恢复原灰度阶段或失败。
- 任务：`PLANNED → DOWNLOADING → VERIFIED → INSTALLING → HEALTH_CHECK → SUCCEEDED`。
- 应用/Web/APK 健康失败：`HEALTH_CHECK → ROLLED_BACK`；Schema 失败：`INSTALLING|HEALTH_CHECK → FORWARD_FIX_REQUIRED`；摘要/签名/顺序异常：`FAILED_CLOSED`。

## 3. 核心不变量

1. tenant 只来自可信上下文；release/rollout/task 的 tenant 和 store 不可迁移。
2. 发布范围只可在 rollout 收窄；终端必须同时属于发布范围、灰度范围和注册表绑定门店。
3. 发布签名通过前不得 STAGED；STAGED 后不得修改对象键、SHA、签名、key version、commit、SBOM 或兼容窗口。
4. CANARY 未出现至少一个成功且存在 active/failed 时不得扩散；ROLLING 未全健康收敛不得完成。
5. 每个命令以 tenant + command type + idempotency key 唯一；同键异摘要拒绝。
6. 范围、命令结果、事件、审计只追加；控制记录只允许具名条件迁移并使用乐观锁。
7. `UNKNOWN` 不通过重发支付/退款命令解决；发布只读取状态并阻断。
8. Schema 只前进，失败生成新前向修复事实，不回写或删除历史迁移。
