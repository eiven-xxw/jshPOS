# Gate 6B 运行手册、故障注入、测试与 CI

## 1. 合成运行手册

1. 在受控构建中生成虚构包、SBOM、SHA-256 和临时 Ed25519 密钥对；只保留公钥和签名证据。
2. 创建 DRAFT，服务端重新读取对象并验签，转 SIGNED；审核门店和兼容窗口后 STAGED。
3. 建立 1%—25% CANARY；查询可信终端与多 Owner 安全快照后创建软件任务。
4. 记录下载、校验、安装、健康观察；存在失败即暂停，不自动重跑掩盖 Flaky。
5. CANARY 全成功后才进入 ROLLING；完成前再次核对任务汇总、审计和事件守恒。
6. 摘要/签名/租户/迁移异常按失败关闭处理；Schema 只创建前向修复计划。

## 2. 固定故障矩阵

`BAD_SIGNATURE`、`DIGEST_MISMATCH`、`OLD_PACKAGE_REPLAY`、`CROSS_TENANT_PACKAGE`、`DOWNLOAD_INTERRUPTED`、`PENDING_OUTBOX`、`UNKNOWN_PAYMENT`、`UNKNOWN_REFUND`、`BUSINESS_HOURS`、`REVOKED_TERMINAL`、`VERSION_MISMATCH`、`CAPABILITY_MISMATCH`、`MIGRATION_FAIL`、`HEALTH_FAIL_ROLLBACK`、`FORWARD_FIX`、`IDEMPOTENCY_CONFLICT`、`CANARY_FAIL_STOP`。

## 3. CI 门禁

1. governance：AGENTS、ADR、CR、RTM、契约、状态和 BLOCKED/证据等级。
2. server：全部 Maven 模块、核心规则行≥90%/分支≥85%。
3. MySQL：V1—V41 空库/升级/validate、状态触发器、权限和 100k 合成容量。
4. release-security：固定故障、租户/门店/对象路径、Secret/PII、网络入口为 0。
5. Web、Flutter Linux/Windows、SQLite、Kotlin/Android 全量历史回归。
6. 依赖、漏洞、SBOM、许可证和证据索引；不得重复上传大制品或创建绿色占位。

## 4. 证据等级

允许：`STATIC/UNIT/MYSQL8.4_SYNTHETIC/SYNTHETIC_PACKAGE/SOFTWARE_EXECUTION`。禁止提升为：`SANDBOX/REAL_DEVICE/PHYSICAL_POWER_LOSS/PILOT/PRODUCTION/COMMERCIAL_SLA`。
