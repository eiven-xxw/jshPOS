# Gate 6B 范围、非目标与准入

## 1. 唯一正式需求

本 Sprint 只准入 `T2-UPG-001`。准入来源为项目发起人 2026-08-20 指令、ADR-010、详细设计 35/36、技术架构与开发规范第 11.3/12 章及 ADR-034。

准入完成项：数据主权、三套状态机、摘要/签名、可信终端、兼容窗口、营业保护、权限/审计、API/事件、Flyway V40/V41、容量、回退/前向修复、运行手册、固定故障向量和 CI。故需求从 `DRAFT` 更新为 `IN_PROGRESS`；只有完整 Gate 6B CI 与证据封存通过后才可更新为 `VERIFIED`，项目发起人确认前不得更新为 `ACCEPTED`。

## 2. 范围

- 七类发布物的不可混淆身份与租户/门店范围。
- Ed25519 合成签名验证、SHA-256、key version、build commit 与 SBOM 绑定。
- 发布物 `DRAFT→SIGNED→STAGED` 及吊销；灰度 `PLANNED→CANARY→ROLLING→COMPLETED`、暂停/失败；终端软件任务下载、校验、安装、健康、回退/前向修复/失败关闭。
- 可信 Terminal Registry 查询和多 Owner 营业保护端口。
- MySQL 控制记录、只追加事件/审计/命令结果及前向迁移。
- 虚构租户、门店、终端和合成包的故障注入、容量与安全攻击。

## 3. 非目标

- 不调用厂商静默安装 SDK，不安装真实 APK，不发送固件、重启或远程控制命令。
- 不接入生产对象存储、生产签名/KMS、真实发布节点或真实终端遥测。
- 不进行支付 Provider 网络、真实回调、账单下载或资金操作。
- 不启动完整 Alpha UAT，不改变 `T2-PAY-002/HWD-001/PAR-001` 的 `BLOCKED`，不改变 `T2-UAT-001/REL-001` 的 `DRAFT`。
- 不修改已发布 Flyway；不把 Gate 6A 设计夹具转为生产表。

## 4. 量化验收

1. 发布物身份字段 100% 冻结，非法状态边、删除和只追加更新 100% 拒绝。
2. 摘要、签名、密钥版本、旧包重放、跨租户/跨门店范围攻击 100% 失败关闭。
3. 待同步、UNKNOWN 支付/退款、营业班次、营业时段、吊销、版本/能力/系统不兼容 100% 阻断任务分配。
4. 应用健康失败进入回退；Schema 失败进入前向修复，禁止修改历史迁移。
5. 100k 合成发布/任务索引容量基线在 CI 限额内完成，结果只作趋势证据。
6. 核心规则行覆盖≥90%、分支覆盖≥85%，完整历史回归、安全、SBOM、许可证与证据门禁不得下降。
