# Owner 不变量与权限边界矩阵

| 页面 | 服务端最终权限与可信范围 | 必须保护的 Owner 不变量 |
|---|---|---|
| VUE-16 | 报表查询、支付对账、导出申请/审批/生成/下载分别最小授权；tenant/门店由服务端数据范围约束 | Reporting 只读投影可重建；导出脱敏、审计和短期链接；不得用报表覆盖权威事实 |
| VUE-17 | 套餐、权益、申请、审批、初始化、激活、生命周期分别授权；tenant_id 由平台分配 | SaaS 只编排商业生命周期；Foundation 独占技术租户；停用不删历史 |
| VUE-18 | 目录、项目、工单、附件上传/下载/清理分别授权；每次访问重验 tenant/门店 | Service 不改变租户/订阅；附件正文只在受控对象存储；租约和状态历史只追加 |
| VUE-19 | 读取、创建、激活、续期、暂停、恢复、终止分别授权；目标 tenant 不是授权依据 | Subscription 只读 SaaS 套餐；服务端时钟决定期限；降级与恢复保留受控能力 |
| VUE-20 | 查询、签发、状态、轮换分别授权；门店/终端绑定由服务端确认 | 一次性秘密只显示一次；凭据只存摘要；真实设备/升级执行继续 BLOCKED |
| FLT-01 | 可信员工 `exchangeRead/Create/Approve/Recover` 与当前班次/门店/业务日 | 换货是退货退款、新销售、只追加关联三事实；不得生成净额资金事实 |
| FLT-02 | 可信员工退货读取/创建/审批；当前班次、门店、业务日与原单匹配 | 金额数量上限和原成交快照不变；UNKNOWN 只查询原 returnRef |
| FLT-05 | `cashManage` 与 `drawerNoSale` 分离；绑定可信班次员工门店终端业务日 | 现金事实与 Outbox 同 SQLite 事务；钱箱只记录 BLOCKED 外设请求 |

共同禁止：客户端 `tenant_id` 成为授权依据、跨 Owner Mapper、前端重算金额/库存/成本/
促销/订阅状态、重新生成 UNKNOWN 命令、持久化 Secret/PII，以及任何真实支付或设备调用。
