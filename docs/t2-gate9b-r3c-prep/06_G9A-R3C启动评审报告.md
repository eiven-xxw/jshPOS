## 核心事实

1. 8/8 页面具有正式菜单或可信会话导航；
2. 五个 Vue 页面没有直接挂载交互测试；FLT-05 无 Widget 测试；FLT-01/02 仅有局部 Widget 证据；
3. VUE-16、VUE-20、FLT-05 的部分失败重试没有稳定保留原操作键；
4. 导出、附件、终端秘密、租户/订阅生命周期和现金动作的高风险确认、页内状态与失败恢复不完整；
5. 页面中的门店/目标租户输入需要交互测试证明服务端可信上下文和数据范围最终授权；
6. 未发现页面直接访问 Mapper、SQLite raw API、MethodChannel 或自行执行 Provider/设备调用。
