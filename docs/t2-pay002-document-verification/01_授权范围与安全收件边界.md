# T2-PAY-002 授权范围与安全收件边界

## 1. 已授权

- Provider：拉卡拉，身份仅为首接文档核验候选。
- 动作：接收不透明材料 ID、读取批准受控区中的材料、计算/比对 SHA-256、核验来源/授权/适用范围/版本/保管/期限/轮换/删除和吊销。
- 输出：逐项验真结果、整包 `VERIFIED_DOCUMENT` 或 `NOT_ACHIEVED` 结论、独立执行准入建议。

## 2. 未授权

- 不访问、探测或解析为网络目标的 Provider 沙箱/生产域名；
- 不创建 SDK/HTTP 适配器、真实回调 Controller 或账单下载任务；
- 不验证 Secret、证书、商户号或终端号是否可用；
- 不发起支付、查询、退款、下载账单或接收真实回调；
- 不使用真实资金、真实支付记录、生产密钥或未脱敏数据；
- 不启动完整 Alpha UAT 或生产发布。

## 3. 本次收件事实

用户提交的“受控材料不透明 ID”字段仍为 `[填写……材料 ID]`，属于操作模板而非 ID。仓库检索到的拉卡拉材料仅为 Gate 6C 公开官方网页快照及其哈希元数据，证据等级是 `PUBLIC_OFFICIAL_DOCUMENT`。

因此本次实际受控材料 ID 为 `0`，没有材料可执行来源、签署、版本和摘要验真；所有必需项失败关闭为 `MISSING`。

## 4. 保管与事件处理

- Git 只接受符合元数据 Schema 的不透明 ID、非敏感状态和摘要；不接受原始 Secret 或真实标识。
- 受控材料保存在批准文档系统；`controlledLocationRef` 不得含账号、路径口令、查询 Token 或个人联系方式。
- 收到疑似生产凭据时不得测试，立即隔离并通知安全负责人轮换/吊销。
- 摘要、签署、产品范围、版本、期限或保管链任一不一致时，材料保持 `RECEIVED_UNVERIFIED` 或退回 `MISSING`，不能通过人工备注强行提升。
