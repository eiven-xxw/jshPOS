## 2. 单份材料验真

1. 检查 ID 格式和类别，确认不是占位符、文件名、公开 URL 或 Secret 值。
2. 在批准受控区读取材料，核验来源主体和授权签署；仓库不缓存原文。
3. 独立计算字节数和 SHA-256，与提供元数据对比；不一致即失败。
4. 核验适用产品、接口/SDK 版本、商户/终端权限、环境、包含和排除范围。
5. 核验生效、到期、轮换、删除/吊销、保管人和访问审计。
6. 验真人与材料提供人分离，记录结论：`RECEIVED_UNVERIFIED`、`VERIFIED_ITEM`、`REJECTED` 或 `EXPIRED`。

## 3. 整包判定

只有 11 项全部为 `VERIFIED_ITEM`，没有冲突、过期、生产凭据或无法解释的范围缺口，才能把整包标记为 `VERIFIED_DOCUMENT`。整包通过后仍不得调用网络，只能提交更新后的《T2-PAY-002 支付沙箱执行准入评审报告》等待项目发起人确认。

任何单项缺失时，整包固定为 `NOT_ACHIEVED`，`T2-PAY-002` 保持 `BLOCKED`，执行准入固定为 `NO-GO`。
