# 逐页验收矩阵

机器权威：`contracts/t2/gate9b-r3-prep/acceptance-matrix-v1.json` 和
`page-audit-v1.json`。每页必须逐项填写，不允许用全局绿色替代页面证据。

| 检查 | 每页最低验收 |
|---|---|
| 路由 | 有菜单/父组件/可信会话入口；权限拒绝不可达；返回后上下文正确 |
| 按钮 | 状态可解释，危险动作确认，非法状态禁用 |
| 权限 | 展示权限与 Controller 对齐；服务端拒绝可见且不泄漏 |
| 数据范围 | tenant 不由客户端授权；门店范围越权失败关闭 |
| 加载/空态 | 初始、加载、空结果、成功可区分，无空白页 |
| 错误 | 安全消息、错误码、关联标识；无 Secret/PII/堆栈 |
| 防重 | 重复点击单航班，同键异内容拒绝 |
| 离线 | 仅适用 POS；断网提示、包/本地事实边界明确 |
| 业务日 | 使用可信冻结业务日；切换后旧页面不生成新命令 |
| 恢复 | 超时/UNKNOWN/重启观察或恢复原命令 |
| 测试 | Vue 挂载组件或 Flutter Widget 交互测试，失败 seed 固定 |
| 回归 | 三业态、双租户、Linux/Windows与既有 Gate 全绿 |

`N/A` 仅允许页面本身没有对应业务行为时使用，并必须写明其上游承载页面与服务端边界。
