# 生产配置与附件资源运行手册

## 启动前

部署平台必须注入数据库 URL/非 root 用户/密码、Redis 地址/密码、JWT Secret、接口加解密密钥和 Actuator 独立账号口令。Secret 不得写入 YAML、命令历史、普通日志或 CI 制品。可选集成保持关闭；确需启用必须走独立变更并补齐受控 Secret。

## 管理端点

反向代理只允许访问 `health`、`info`、`prometheus`，并限制来源网络。健康详情只有通过独立认证后可见。任何端点集合扩大、接口文档启用或认证绕过均应阻断发布。

## 附件暂存

`JSH_ATTACHMENT_TEMP_DIR` 应指向非 Web 可访问、权限受限、容量有界的专用目录；容器化部署应单独挂载临时卷。业务上限为 10 MiB，每个上传使用 64 KiB 应用缓冲。监控目录文件数、容量、最老文件时间和失败清理告警；异常残留只能按无活跃句柄和保留时间阈值受审计清理。

## 回退

配置回退不得恢复静态默认凭据、全量 Actuator 或整包附件读取。若对象存储不可用，附件上传失败关闭，工单其他事实不伪造附件成功。代码回退必须保持数据库无迁移变更这一事实并重新执行本 Gate 全量门禁。
