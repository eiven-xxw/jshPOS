# T2-SEC-002 实现与发现关闭说明

## G8C-SEC-P0-001

生产配置移除数据库、Redis、任务令牌、监控口令和第三方登录示例中的静态默认值；必需值全部改为 `JSH_*` 受控引用。Boot Admin、SnailJob 和 Mail 默认关闭；显式启用时由生产启动门禁校验 URL、账号或 Secret。门禁不记录 Secret 内容。

## G8C-SEC-P1-002

基础配置和生产覆盖均只暴露 `health,info,prometheus`；健康详情为 `when_authorized`，接口文档生产默认关闭。管理端点继续使用独立 Basic 认证，拒绝响应不回显底层异常，仅记录 URI 和远端地址审计。

## G8C-SEC-P1-003

Service 附件先读取 multipart 元数据并执行 10 MiB 业务上限，再打开流；基础设施使用 64 KiB 固定缓冲流式落入随机临时文件，同时计算 SHA-256。声明量、实际量、业务上限任一不一致即失败关闭。对象键仍由可信租户上下文生成，应用事务失败触发对象清理，暂存句柄在所有返回和异常路径关闭。

## 未改变事项

- 未新增或修改 Flyway/SQLite 迁移。
- 未改变服务工单、租户、资金、库存或其他业务状态机。
- 未新增依赖、Provider 客户端、真实设备或外设调用。
- 原 Gate 8C-Prep 的其他十一项发现继续开放并受后续独立需求约束。
