# Gate 5D 与 Gate 3B 下一步操作指令

> 文档编号：JSH-POS-T2-G5C-008  
> 使用条件：项目发起人确认《T2 Gate 5C / Sprint S11 周门禁报告》后复制执行

## 1. 建议决策

1. 接受 Gate 5C `CONDITIONAL PASS` 后，才将 `T2-MEM-001`、`T2-MEM-002` 从 `VERIFIED` 更新为 `ACCEPTED`。
2. 下一阶段建议为 Gate 5D / Sprint S12，严格按 `T2-RPT-001 → T2-RPT-002` 逐项准入；先形成销售、收银、库存和成本的可重建基础报表，再形成 Provider 无关的支付、退款与内部对账报表。
3. 报表是可丢弃、可重建的查询投影，不得成为订单、班次、促销、库存、成本、支付、退款或会员的事实源，不得跨 Owner 回写业务表。
4. `T2-RPT-002` 的内部支付/退款投影可使用已接受的 Provider 无关事实和固定合成账单向量；真实 Provider 账单、网络下载、签名、渠道差异验收继续被 `T2-PAY-002` 阻断，Fake 不解除阻断。
5. Gate 3B-Prep 继续只核验首接 Provider 的真实资料；未经独立解阻评审确认，不得新增 Provider SDK/HTTP、真实回调、账单下载或任何支付网络调用。
