# 会员数据主权、状态、不变量与隐私

Member Owner 唯一写入会员主体、身份、同意、合并关系、隐私请求、等级、积分和会员 Outbox/Inbox。Order/Return 只发送已冻结的交易事件；Reporting 只消费脱敏事件。

## MEM-001 状态

- 会员：`ACTIVE → SUSPENDED → ACTIVE`，`ACTIVE/SUSPENDED → MERGED → ACTIVE`，合法删除请求后进入 `ANONYMIZED`。
- 身份：`ACTIVE → REVOKED`；绑定与撤销都追加审计事实。
- 同意：只追加 `GRANTED/REVOKED`，当前状态由相同 purpose 最后事实计算。
- 隐私请求：`REQUESTED → IDENTITY_VERIFIED → IN_PROGRESS → FULFILLED/PARTIALLY_FULFILLED/REJECTED`；每次迁移追加历史。

## PII 处理

| 类型 | 存储 | 查找 | 展示/日志 | 保留 |
|---|---|---|---|---|
| 手机/卡/外部身份 | 版本化 AEAD 密文或令牌引用 | 标准化后 HMAC-SHA-256 | 只返回 masked value 和标识 | 按租户策略；法定冻结优先 |
| 会员显示名 | 可选密文 | 默认不支持模糊搜索 | 授权后掩码 | 最短必要 |
| 会员令牌 | 随机不可推导值/摘要 | token hash | POS 仅存令牌与摘要 | 有效期、撤回或解绑即清理 |

密钥来自环境/KMS，无密钥时身份写入失败关闭。日志、审计和 Outbox 不得包含明文或完整密文。

## MEM-002 设计不变量（当前 DRAFT）

- 流水类型：`EARN/FREEZE/UNFREEZE/SPEND/EXPIRE/RETURN_EARN_REVERSAL/RETURN_SPEND_REVERSAL/MANUAL_ADJUST`。
- 数量使用 `DECIMAL(19,6)/BigDecimal`，禁止浮点。
- 消费按最早到期优先（FEFO）；分配事实只追加。
- 订单获取积分只在同步后服务端事件成功入账；POS 不离线抵扣积分。
- 退货只引用原账本事实和策略版本，不按当前等级/规则重算。
