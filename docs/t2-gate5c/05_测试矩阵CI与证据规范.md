# 测试矩阵、CI 与证据规范

| 类别 | 用例 |
|---|---|
| 身份 | 重复注册、绑定/解绑、合并冲突、拆分恢复、同键异内容 |
| 隐私 | 同意/撤回、查阅/复制/更正/删除请求、法定保留、脱敏、密文和日志泄漏 |
| 权限租户 | 跨租户身份替换、枚举查询、越权查看/导出/删除、Mapper/XML/任务/缓存/对象存储攻击 |
| POS | 不存明文 PII、过期/撤回/换机/解绑清理、SQLite 迁移失败回滚 |
| 权益 | 重复/乱序/晚到、返回冲正、到期边界、并发消费、FEFO、全量重建、前向修复 |

Gate 5C CI 必须包含 governance、server、admin-web、MySQL 8.4、Flutter Linux/Windows、SQLite、会员事件重放、tenant/PII/permission 攻击、Secret、依赖、SBOM、许可证、覆盖率和证据索引。禁止降低阈值、跳过、自动重跑或绿色占位。

本 Sprint 只能形成 `STATIC+UNIT+MYSQL_INTEGRATION+SQLITE_INTEGRATION+SYNTHETIC_VECTOR`。沙箱、实机、真实 PII、物理断电、试点和商业验收证据均为 0。
