# 迁移、容量、兼容、回退与修复

- MEM-001 使用新的 V28/V29 Flyway；MEM-002 独立准入后使用更高版本，禁止修改已发布 V1—V27。
- POS 追加 SQLite V7 最小会员快照表；迁移失败整体回滚，旧 Schema 继续可用。
- 新表/字段带中文 COMMENT，迁移摘要登记且不可改写。
- 身份 HMAC 索引在 `(tenant_id, identity_type, lookup_hmac)` 上唯一，不建明文索引。
- 同意、审计、Inbox/Outbox 和积分流水按 tenant + member + occurred/order key 索引。
- 容量验收使用 100k 会员、1m 积分流水合成数据的正确性/趋势，不形成生产 SLA。
- API/事件只做可选字段扩展，破坏性语义发新版。密钥旋转使用新旧版本共存窗口。
- 投影损坏从只追加流水重建；同键异内容、缺口、跨租户和无法解释的负值进人工修复队列。
- 上线后只前向修复，不以删表/流水回退。
