# 部署配置、许可证与运维证据设计

## 部署预检

内部配置只接受仓库外 Secret 引用，验证 MySQL/Redis 必需引用、Actuator 白名单、日志路径、镜像 digest、健康检查和前向迁移。示例占位值不得被解析为可部署 Secret；缺少必需变量时必须失败关闭。

部署包只包含 `infra/compose`、`infra/internal-rc` 和必要说明，不包含 `.env`、私钥、真实证书或云凭据。生产 KMS、真实对象存储、PITR、跨区域灾备和真实终端升级继续 BLOCKED。

## 许可证

`pos_device_adapter` 是 `publish_to: none` 的自有内部包，补充专有内部许可通知和 0.1.0 变更记录；这只关闭占位质量缺陷。三项第三方组件继续由 T2-LIC-001 负责，关闭数保持 0/3。

## 运维证据

复用已接受的备份恢复、升级回退、诊断脱敏和事故手册，但在当前 commit 的同一 Run 重新执行固定恢复/回退矩阵并生成摘要。证据只允许 `SYNTHETIC_RESTORE/SYNTHETIC_PACKAGE`，不能升级为生产灾备或商业 SLA。
