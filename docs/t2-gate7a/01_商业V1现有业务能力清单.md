## 4. 不重复实现规则

1. 新需求必须扩展既有 Owner；不得为现金、打印、批次、日结或订阅复制第二套租户、订单、库存、支付或促销事实源。
2. Vue 和 Flutter 只调用正式应用端口；不得在前端重算金额、库存、成本、促销或会员权益。
3. 已发布 MySQL/SQLite 迁移不得修改；后继 Gate 只能前向迁移。
4. `T2-E2E-004` 只能组合正式路径，不得新增数据库后门或测试专用成功适配器。

完整逐族矩阵见 `contracts/t2/gate7a/v1-capability-family-matrix.csv`。
