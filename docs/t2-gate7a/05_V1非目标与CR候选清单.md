# V1 非目标和 CR 候选清单

## 1. 无需新增 Requirement ID 的明确非目标

以下能力不进入当前 Gate 7 商业 V1 内部收口：

- 储值、预付卡、充值、资金沉淀和复杂分账；
- 复杂优惠券、营销预算抢占、CDP 和自动化营销；
- 发票、应付、总账、税务申报和复杂业财一体；
- 批次成本、库位、波次、越库、加工和复杂 WMS；
- 加盟结算、供应链金融和真实资金划拨；
- AI 收银、智能预测补货、自然语言问数和任意 SQL；
- 跨租户经营大盘、自助收银、Windows 正式版和私有化交付；
- 鲸熵汇及其他连接器的提前实现；
- 真实支付、真实外设、现场试点和生产发布。

这些能力若进入实现，必须建立新的范围变更，不得借用 Gate 7 的 DRAFT ID。

## 2. 需要独立 CR 才能 READY 的候选

| Requirement | 原决策/原因 | CR 必须回答 | 当前结论 |
|---|---|---|---|
| `T2-EXG-001` | `DEC-04` 明确换货后置 | 付费客户、退换货频次、跨 Owner 风险、退货+新售替代是否足够 | `DRAFT / CR_REQUIRED` |
| `T2-MEM-003` | T2 会员原范围仅档案/等级/积分 | 会员价通用性、离线失效、加盟权益责任、隐私影响 | `DRAFT / CR_REQUIRED` |
| `T2-SAA-001` | 商业 V1 能力原计划 T3—T5 产品化 | SaaS Owner 边界、RuoYi 复用、开通工时、授权风险 | `DRAFT / CR_REQUIRED` |
| `T2-SUB-001` | 商业订阅原计划 T3—T5 | 计费非目标、合同状态、到期/宽限、数据保留、人工替代 | `DRAFT / CR_REQUIRED` |
| `T2-SVC-001` | 实施/工单原计划 T3—T5 | 服务目录、复用率、责任人、附件安全、SLA 非目标 | `DRAFT / CR_REQUIRED` |

未提供真实目标客户和合同数据时，CR 可以以“产品标准化假设”提交，但不得虚构金额或伙伴承诺。没有项目发起人批准，以上需求不能从 DRAFT 进入 READY。

## 3. 不需单独 CR 但仍需 Gate 确认的项

- `T2-POS-010/POS-011/ORD-004/DMT-001/ONB-001/CLS-001/EXC-001`：属于已冻结 V1 必选能力的实现缺口；仍需对应 Gate 逐项准入。
- `T2-PAY-004/LBL-001/RPL-001`：属于 V1 P1/后续增强；不得阻断便利店主闭环，也不得未经 Gate 7B/7C 确认自动启动。
- `T2-PRD-005/LOT-001`：只服务社区超市条件模板；不进入便利店主路径，真实秤/打印仍需外部解阻。
- `T2-E2E-004`：仅在实际准入项全部 ACCEPTED 后进入 Gate 7E。

## 4. 外部状态保持

`T2-PAY-002/HWD-001/PRN-001/PAR-001` 继续 `BLOCKED`；`T2-JSH-001/LIC-001` 继续 `DEFERRED`；`T2-UAT-001/REL-001` 继续 `DRAFT`。本文件不构成任何一项解阻或接受。
