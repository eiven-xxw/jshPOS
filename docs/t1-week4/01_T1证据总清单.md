## 4. 供应链和安全证据

- T0 已封存服务端聚合 SBOM、前端许可证清单、APK、Docker Compose、Trivy 漏洞/Secret/IaC 和受限许可证证据；T1 沿用该基线。
- T1 PoC 仅使用 Python 标准库，没有新增 Maven、pnpm、Flutter 或 Gradle 依赖清单。
- Week 4 生成 T1 范围 CycloneDX SBOM（组件列表为空代表无第三方运行依赖）、CI 工具固定 SHA 清单、许可证边界和安全摘要。
- Aviator、simple-http、MySQL Connector/J 继续是商业发布前事项；用户此前允许不阻断 T1，但不得从商业发布阻断清单删除。
