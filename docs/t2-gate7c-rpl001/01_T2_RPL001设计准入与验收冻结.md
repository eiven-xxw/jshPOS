# T2-RPL-001 设计准入与验收冻结

## 1. 范围与非目标

准入版本化库存上下限、缺货预警、确定性补货建议、人工复核/审批/拒绝，以及通过
Procurement Owner 转为采购草稿。非目标包括 AI 预测、自动下单、自动审批、供应商
比价、配送优化、批次/效期、采购承诺、收货、库存和成本效果。

## 2. 数据主权与端口

| 数据 | 唯一写入 Owner | 协作方式 |
| --- | --- | --- |
| `inv_stock_ledger/inv_stock_balance` | Inventory | `ReplenishmentInventorySnapshotPort` 只读快照 |
| 商品与单位换算 | Catalog | `InventoryCatalogSnapshotPort` 只读快照 |
| 供应商、在途、采购单 | Procurement | `ReplenishmentProcurementSnapshotPort` 只读；`ReplenishmentPurchaseDraftPort` 写草稿 |
| `rpl_*` 规则、运行、建议、事件、审计 | Replenishment | 自有 Mapper/XML，禁止其他 Owner 写入 |

所有端口都不接收 `tenant_id`；租户、门店数据范围和操作者来自可信服务端上下文。

## 3. 计算冻结

数量固定 `DECIMAL(19,6)`。规则满足 `0 ≤ minimum ≤ maximum`、`minimumOrder > 0`、
`orderMultiple > 0`。若启用在途，只有已批准或部分收货且未关闭的采购剩余基础数量
可计入：

`effective = available + includedTransit`

仅当 `effective < minimum` 才生成建议；`requiredBase = max(maximum - effective, 0)`；
`rawPurchase = requiredBase × denominator ÷ numerator`；最终采购数量不低于最小订货量，
并按订货倍数使用 `CEILING` 向上取整。冻结输入包括规则和明细身份、内容摘要、库存
流水序号、余额版本、在手/预占/冻结/安全库存/可用量、在途量、换算和计算明细。

## 4. 状态机与不变量

- 主路径：`GENERATED → REVIEWED → APPROVED → PURCHASE_DRAFTED`。
- 分支：`GENERATED/REVIEWED → REJECTED`；开放建议可转 `STALE`；草稿创建的受控
  业务失败可转 `FAILED`。
- `PURCHASE_DRAFTED/REJECTED/STALE/FAILED` 是终态；不允许恢复为开放状态。
- 同 generation run ID 或命令幂等键同摘要返回原结果，同键异摘要返回 409。
- 新库存流水序号生成建议时，旧开放建议必须显式 `STALE`；较旧检查点不得覆盖新建议。
- 采购草稿来源唯一绑定原建议；重复转单返回原草稿，同建议不同内容失败关闭。

## 5. 权限、审计、契约与迁移

权限分为规则管理/发布、建议生成/读取、复核、审批、拒绝和转采购草稿。所有写操作
保存操作者、命令 ID、关联标识、前后状态、原因和 SHA-256；状态事件、审计与 Outbox
只追加。REST/OpenAPI 与事件 Schema 版本为 v1，错误码使用 `RPL-*`。

MySQL `V202608220062` 只前进创建 `rpl_policy_version/rpl_policy_item/
rpl_generation_run/rpl_suggestion/rpl_suggestion_event/rpl_audit_event/rpl_event_outbox`，并给
采购单增加不可变来源字段；包含复合租户外键、唯一约束、中文 COMMENT 和只追加保护。

## 6. 容量、故障与回退

- 单规则版本最多 10,000 个 SKU；单生成请求最多处理 10,000 项并按稳定主键顺序执行。
- 百万级场景只记录内部合成趋势，不形成生产 SLA。
- 覆盖重复/乱序/晚到、库存变化、并发审批、同键异内容、供应商停用、换算变化、
  重复转草稿、跨租户/仓库、迁移中断和安全前向修复。
- 回退停用入口与规则版本，保留全部建议、事件、审计和已生成采购草稿；禁止物理删除。

## 7. 量化验收

1. 18 个以上固定故障向量全部通过；规则计算单元覆盖率保持既有门禁。
2. MySQL 8.4 空库迁移、重复迁移、租户复合外键、快照不可变和事件只追加通过。
3. Vue 不计算建议数量，只展示服务端明细并携带稳定幂等键与版本。
4. 采购草稿转换前后库存/成本流水增量均为 0，采购单状态严格为 `DRAFT`。
5. 外部网络、真实资金、真实设备/外设、完整 Alpha、现场与生产执行均为 0。
