# 交互测试与验收矩阵

每个页面必须逐项通过下列十二维验收；静态源码断言不能替代第 12 项。

| 维度 | 量化标准 |
|---|---|
| Route | 菜单或完整父子装配链 1/1 可达 |
| Buttons | 正式用户旅程所需按钮均有状态约束 |
| Permission | 写按钮与 Controller 最小权限逐项一致，拒绝路径可测 |
| Data scope | 跨租户、跨门店请求失败关闭 |
| Loading | 请求期间可见且禁止重复提交 |
| Empty | 合法空结果不显示空白页或伪错误 |
| Error | 安全消息、稳定错误码、关联标识齐全，无 Secret/PII/堆栈 |
| Single flight | 连续双击只产生 1 个在途调用 |
| Recovery | 原键同内容稳定返回；同键异内容拒绝；UNKNOWN 只观察 |
| Confirmation | 冻结的高风险动作二次确认对象、版本、范围和影响 |
| Owner invariant | 页面/API 调用不改变既有 Owner 状态机和事实归属 |
| Mounted interaction | 页面真实挂载，许可/拒绝/成功/空态/失败/恢复可重复 |

联合退出标准：11/11 页面十二维全 `PASS`，本批 P0/P1=0，Owner 事实变化=0，
API/迁移/Requirement 新增=0，外部执行=0，完整 CI 全绿。
