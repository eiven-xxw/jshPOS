# Owner 不变量与权限边界矩阵

| 页面 | 必须保护的 Owner 不变量 | 页面禁止行为 |
|---|---|---|
| VUE-05 | Migration 只编排 staging/检查点/对账，各 Owner 写自己的事实 | 直接写私有表、跳过预检部分激活 |
| VUE-06 | Promotion 计算优惠；Member 独占身份、隐私和积分事实 | 前端重算优惠/积分、输入真实 PII |
| VUE-07 | 库存/成本流水不可变，余额投影可重建 | 覆盖余额/历史、前端计算移动平均成本 |
| VUE-08 | 权益/会员价版本化，成交与退款读取冻结快照 | 按当前等级重算退款、复制定价算法 |
| VUE-09 | 发布物绑定摘要、签名、范围和兼容窗口 | 伪造验签/健康成功、发送真实设备命令 |
| VUE-10 | 建议消费冻结库存检查点，转采购只建 DRAFT | 自动下单/审批、直接改库存或采购事实 |
| VUE-11 | 采购/调拨分别独占单据，库存/成本只追加 | 跨仓覆盖余额、客户端提交成本结果 |
| VUE-12 | 日结签署只追加，审批分离，晚到生成更正版本 | 用报表覆盖事实、改写 CLOSED 日结 |
| VUE-13 | 异常中心只持有案件和 Owner 命令引用 | 直接修事实、UNKNOWN 重新生成资金命令 |
| VUE-14 | 批次事实归 Inventory，社区超市模板才启用 | 批次成本、复杂 WMS、客户端判定过期 |
| VUE-15 | 只复制白名单配置和版本引用 | 复制 Secret/PII/历史/余额，伪造外部通过 |

共同权限边界：按钮权限只控制展示；正式 Controller、可信 tenant 上下文和门店数据范围
始终最终授权。页面不得发送 tenant_id 作为授权依据，不得根据按钮可见性推断服务端允许。
