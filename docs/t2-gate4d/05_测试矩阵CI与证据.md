# Gate 4D 测试矩阵、CI 与证据

## 1. 固定测试矩阵

- 状态：创建、提交、职责分离审批、发出、部分/全部收货、最终短少、差异审批、发出前取消、发出后取消拒绝。
- 数量：首笔发出、重复、乱序、同键异内容、超收、未发先收、六位精度、500 行边界、差异原因留痕、在途全量重建核对与投影漂移红灯。
- 成本：来源仓快照、目的仓继承、部分收货继承、目的仓移动加权、负库存结算、缺原成本拒绝、舍入边界。
- 事务：库存失败、成本失败、调拨更新失败、Outbox 失败和迁移失败均不得留下半完成效果。
- 安全：两个虚构租户、两侧门店范围、Mapper/XML、任务、缓存、导出、对象存储、请求 tenant 注入和跨租户 ID 攻击。
- 兼容：V1—V19 migrate/validate、重复执行、旧应用兼容、前向修复和固定失败 seed 回归。

固定向量至少 28 个，位于 `contracts/t2/gate4d/test-vectors/transfer-fixed-vectors-v1.json`。

## 2. CI 门禁

1. governance：基线祖先、ADR、RTM、范围、契约、迁移封印；
2. server：完整 reactor、调拨单元/属性/应用测试、覆盖率 line≥90%、branch≥85%；
3. mysql-migration：MySQL 8.4.6 V1—V19 与复合租户/不可变约束；
4. tenant-security：两个虚构租户和至少 16 个攻击面；
5. fixed-vectors：28 个固定 seed 与测试映射；
6. pos-linux / pos-windows：既有 Flutter、SQLite、HTTP 与 Kotlin/APK 回归；
7. admin-web：audit、build、lint、typecheck、测试和许可证；
8. security-sbom-license：Secret、IaC、HIGH/CRITICAL、服务端/Flutter SBOM 和许可证；
9. evidence：聚合上游制品、SHA-256 索引和范围摘要。

禁止 `continue-on-error`、自动重跑、跳过失败测试、降低阈值或绿色占位。Flaky 必须固定 seed 并修复根因。

## 3. 证据等级与退出

本 Sprint 最高证据为 `STATIC + UNIT + MYSQL_INTEGRATION + FLUTTER_REGRESSION + SYNTHETIC_VECTOR`。全部门禁通过后 `T2-TRF-001` 只可到 `VERIFIED`；`ACCEPTED` 必须等待项目发起人。

外部证据必须继续显示 `sandbox=0`、`realDevice=0`、`pilot=0`，Provider 网络调用为 0。内部合成证据不得形成 Alpha、试点或商用结论。
