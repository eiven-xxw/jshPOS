## 4. 失败关闭与回退

- 资料缺失、版本冲突、授权不覆盖自动化、Secret 交付不安全或联系人不可验证：继续 `BLOCKED`。
- 收到疑似生产凭据：立即停止、隔离、通知安全负责人并要求吊销；不得验证其可用性。
- 官方文档发生变更：生成新证据 ID 和哈希，重新核对差异，禁止覆盖旧记录。
- 沙箱未来获批后出现真实资金或生产路由迹象：立即停止网络，封存日志并触发安全事件流程。
