# 硬件 RFI、候选 BOM 与首批收件台账

## 1. 候选策略

本阶段只冻结“送样与 SDK 询证对象”，不确定最终主认证机型：

- 主认证候选：商米 T3 PRO MAX（具体认证型号/SKU 待厂商书面确认）。公开页面列出 Android 13 基础的 SUNMI OS、Kryo-670 八核最高 2.7GHz、6GB+128GB、可选副屏，并描述内置 80mm 打印能力。
- 兼容候选：iMin D4 Pro（具体 SKU 待厂商书面确认）。公开页面列出 Android 13 64 位、八核 Cortex-A78/A55、4GB+64GB 或 8GB+128GB、内置 58/80mm 打印和副屏选项。

这些参数是官网公开声称，不是采购承诺；实际样机的区域版本、固件、内存 SKU、GMS、SDK 权限和静默安装能力均须重新验真。

## 3. 主机统一 RFI

厂商或授权经销商必须提供：

1. 法定厂商、授权渠道、精确销售 SKU/认证型号、产地、上市/停产/EOL 和最低供货年限；
2. Android 基线、完整固件 Build、SELinux/安全补丁日期、GMS 状态、CPU/RAM/ROM、屏幕、端口和电源；
3. 打印、扫码、秤、钱箱、客显、设备信息、系统升级/静默安装 SDK 的版本、包名、许可证、校验和与变更日志；
4. 样机 SN 的受控引用、固件锁定、调试权限、恢复镜像、保修、RMA、备机和技术联系人；
5. APK 安装/升级/降级/回滚限制，营业时段保护，断电恢复，系统 WebView/Flutter 兼容与目标 SDK 支持；
6. CCC/SRRC/CTA/计量等适用证书清单及证书编号（按设备类别和中国销售区域确认）；
7. 日志、遥测、远程管理的数据出境/隐私边界、关闭方式和企业策略。

## 4. 外设统一 RFI

- 打印：接口、命令集、码页、DPI、纸宽、切刀、钱箱口、状态回读、SDK/驱动、失败码、寿命与耗材。
- 扫码：1D/2D 码制、USB 模式、PID/VID、键盘布局、串口配置、固件/配置工具、低质码和屏幕码指标。
- 秤：厂商/型号、量程/分度/检定、串口/USB 参数、协议/SDK、稳定/超载/负重状态码、去皮/置零授权、封印与年检。
- 钱箱：厂商/型号、电压、电流、脉宽、接口针脚、开箱状态回读、钥匙模式、寿命与安全测试。
- 客显：型号、分辨率、接口、触控/NFC、屏幕枚举、休眠/热插拔、隐私和内容安全。

## 5. 样机执行前证据包

至少需要主认证候选与兼容候选各一台可追踪样机、全部外设的具体型号/序列引用、固件/SDK 摘要、授权使用范围、恢复镜像、负责人、测试位置和归还日期。资料只能先达到 `VERIFIED_DOCUMENT` 并提交独立执行准入；不得因公开参数完整而直接安装 APK 或下发命令。

## 6. 当前风险

- 商米 T3 PRO 页面同时包含系列多个变体，必须把 T3 PRO、MAX、SUPER 与实际 SKU 分开验收。
- iMin D4 Pro 存在多内存 SKU，开发文档能力也可能按型号/Android 版本不同，不能用通用文档推定全部能力。
- S2 公开规格的 Android 7.1 生命周期与安全补丁不满足默认新部署预期，除非厂商提供仍受支持的精确型号/固件；否则应更换电子秤候选。
- 钱箱目前没有具体型号，硬件范围仍不完整。
