## 3. 伙伴 RFI

### 3.1 主体与意愿

- 企业/个体主体名称、统一社会信用代码的受控引用、门店范围和签字授权人；
- 书面说明愿意参加哪个阶段：访谈、脱敏数据核验、实验室 UAT、门店试点；
- 可投入的店长、收银员、财务/库存人员、技术接口人和时间窗口；
- 明确可随时撤回，撤回后的数据删除、设备回收和账号吊销方式。

### 3.2 现状与对账

- 旧系统、POS/外设/支付渠道、SKU/条码/多单位规模、日单量、峰值、门店和班次数；
- 销售、退款、班次、库存、采购、成本、促销、会员、支付账单可导出字段与保留周期；
- 旧系统权威口径、业务日/时区、金额/数量精度、历史更正方式和已知脏数据；
- 指定逐日对账负责人、容差规则、差异分类、原始凭证访问和签署机制。

### 3.3 数据授权与隐私

- 只接受字段级最小化、脱敏后的样本；真实支付凭据、完整手机号/身份证/银行卡、会员身份密文不得提供；
- 授权文件写明目的、字段、样本时间段、使用环境、访问人、保留期、删除方式和二次使用限制；
- 样本由伙伴先脱敏，鲸熵汇再做接收扫描、重识别风险检查、哈希和隔离；
- 到期/撤回必须删除原文件、派生文件、缓存和备份可寻址副本，并出具删除证明。

## 4. 书面意愿合格条件

同时具备可验证主体、授权签字人、明确试点范围/非目标、预计窗口、退出条款、数据条件和联系人，才计入 3 家指标。微信聊天截图、口头承诺、无主体邮件或“有兴趣了解”不计入。

## 5. 收件方式

真实伙伴身份、联系人和文件仅进入批准的 CRM/合同/受控文档系统；Git 中登记不透明伙伴 ID、材料 ID、SHA-256、状态和责任人，不保存实名、电话、门店地址或原始数据。每家材料由产品/商务、隐私/安全、QA 三方复核。
