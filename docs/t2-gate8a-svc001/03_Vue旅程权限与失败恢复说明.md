# T2-SVC-001 Vue 旅程、权限与失败恢复说明

## Vue 运营旅程

运营工作台按“目录版本 → 实施项目/检查项 → 工单 → 附件”组织。写操作展示服务端状态与版本、执行二次确认，
并保持原幂等键供失败后的安全重试；成功后才生成下一业务命令。页面不得推导租约有效性、自动关闭工单、
重算内部目标或拼装 Owner 结果。

- 服务目录：创建冻结检查模板，发布后不可原地修改。
- 实施项目：预检、开始、阻断、恢复、完成检查、准备移交和移交；必选检查未完成时失败关闭。
- 服务工单：新建、认领、转派、处理中、等待输入、解决、独立复核关闭、重开和取消。
- 附件：上传元数据、按次申请短期下载、到期清理；页面不接收或缓存永久对象地址。

## 权限与范围

服务端分别校验目录管理、项目读取/创建/操作、工单读取/创建/操作、附件上传/下载/清理权限。
所有列表和明细在可信租户与组织/门店范围内执行；平台管理员能力不能替代租户数据范围。
附件、缓存、后台任务、导出和对象存储键复用同一可信命名空间，跨租户或跨门店访问失败关闭并留审计。

## 失败恢复与边界

- 并发认领、转派和状态迁移使用租约与乐观锁；租约过期、旧版本和职责分离失败均拒绝。
- 对象正文先写对象存储，数据库事务失败时登记事务回滚清理；清理失败记录受控告警，不把正文写入日志。
- 工单关闭只基于已解决事实与不同人员复核；重开追加新历史，不覆盖原关闭事实。
- 内部响应目标只显示运营观察，不构成合同 SLA、赔付、自动升级或生产承诺。
- Flutter POS 本批不新增工单运行时；真实通知、第三方客服、远程控制、AI 派单和连接器继续不在范围。
