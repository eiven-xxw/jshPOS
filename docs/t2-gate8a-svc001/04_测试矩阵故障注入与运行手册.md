## 2. 关键故障预期

- 重复命令返回稳定原结果；同键异内容拒绝；乐观锁冲突不得覆盖新状态。
- 并发认领只允许一个有效租约；租约过期、转派竞态和重启后旧命令失败关闭或稳定收敛。
- 目录发布后不可修改；实施项目必选检查未完成不得移交。
- 工单无解决摘要不得进入已解决；解决人与关闭复核人为同一人时拒绝。
- 恶意文件名、超限正文、跨租户下载、过长签名有效期和对象存储失败不得产生成功附件事实。
- 外部状态漂移、真实通知/设备/Provider 调用或普通制品出现附件正文均直接 NO-GO。

## 3. 本地重复运行

```powershell
python scripts/check_t0_structure.py
python scripts/check_rtm.py
python scripts/check_contracts.py
python scripts/check_t2_gate8a_svc001.py

Set-Location server
.\mvnw.cmd -pl ruoyi-admin -am clean verify -DskipTests=false

Set-Location ..\admin-web
pnpm build:prod
pnpm lint:eslint
pnpm typecheck
pnpm test:unit:ci

Set-Location ..\pos-flutter
flutter analyze --fatal-infos
flutter test
```

MySQL 与正式运行栈使用 CI 隔离空库和短期凭据。缺少 Docker、Android SDK 或 Flutter 的本地环境不得伪造结果，
必须由 GitHub 干净执行器补足并写入最终证据。

## 4. 恢复与前向修复

- 保留失败日志和固定 seed；禁止删用例、降低阈值或自动重跑。
- 迁移失败保留 V85/V86，使用新迁移安全前向修复并从空库重验。
- 对象存储写入后数据库事务回滚时执行受控清理；失败对象进入诊断和人工清理，不产生可见附件元数据。
- Secret、PII、附件正文或永久签名 URL 命中普通制品时立即 NO-GO 并按保管规则清理/吊销。
