# 测试矩阵与量化验收

| 维度 | 准备阶段证据 | 后续运行时量化门槛 |
|---|---|---|
| 当前契约 | v1/OpenAPI/SQL/摘要冻结 | v1 回归不变，v2 operationId 唯一 |
| 数据规模 | MySQL 8.4.11 10k/100k | 两级均运行；1m 未获准，不执行 |
| 交互分页 | 当前无界红基线 | 每页 1—500，遍历 0 重复/0 缺失 |
| 导出 | 50 门店=50 查询红基线 | 每门店分块一次，恢复 0 重复/0 缺失 |
| 执行计划 | 当前扫描/filesort 红基线 | 无不可接受全扫/filesort，计划摘要稳定 |
| 查询数 | 交互 1、导出 50 | 交互 1；导出不超过授权门店分块数 |
| 数据守恒 | 12 个数量/成本列汇总冻结 | 分页/导出/当前契约逐字段一致 |
| 租户权限 | 跨租户 0 行 | 跨租户/门店/游标/缓存攻击均失败关闭 |
| 幂等恢复 | 请求身份尚缺 | 同键同摘要稳定、同键异摘要拒绝 |
| 故障 | 7 个固定 seed | 中断、重启、摘要漂移均复用原身份 |
| 迁移 | 当前不得变更 | 如获批索引：空库、升级、重复、validate、前向修复 |

准备阶段退出还要求 Ubuntu、Windows、MySQL 和证据聚合 Job 全绿，生产目录变化为 0，并取得
项目发起人的运行时确认。任何外部证据等级、完整 Alpha、生产容量或 SLA 均不在本矩阵内。
