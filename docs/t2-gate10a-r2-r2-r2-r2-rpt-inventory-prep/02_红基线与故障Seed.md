# 红基线与故障 Seed

## 当前可复现问题

1. v1 交互接口返回无界 `List`，正式 Mapper 没有 `LIMIT` 或 keyset 条件；
2. 50 个门店的库存成本导出执行 50 次 JDBC 查询，并在内存中汇总；
3. 库存成本批量读取端口、签名游标、可恢复流式导出均不存在；
4. MySQL 8.4.11 固定 10k/100k 分布仍可观察扫描或 filesort；
5. 当前租户攻击返回 0 行，数量和成本汇总已被记录，作为后续语义金标。

这些是“可执行红基线”，不是性能通过证据，也不代表生产容量或商业 SLA。

## 固定 Seed

| Seed | 当前红项 | 后续通过条件 |
|---|---|---|
| `R2R2R2-F02` | 交互结果无界 | keyset 页有上限且数量/成本守恒 |
| `R2R2R2-F04-INV` | 50 门店查询 50 次 | 每授权门店分块一次，且受查询预算约束 |
| `R2R2R2-F07-INV` | 租户/门店攻击需持续执行 | 越权结果恒为 0 |
| `R2R2R2-F08-INV` | 无签名游标 | 租户/筛选/版本/游标篡改失败关闭 |
| `R2R2R2-F09-INV` | 无稳定导出请求身份 | 同键异摘要拒绝且无部分输出 |
| `R2R2R2-F10-INV` | 10k/100k 计划扫描或排序 | 获批计划、索引与查询预算通过 |
| `R2R2R2-F12-INV` | 导出不可恢复 | 原游标恢复，0 重复、0 缺失 |

静态红基线位于 reporting 测试目录；MySQL 证据测试位于 release 性能测试目录。两者只读取
生产实现并写入临时测试数据库/制品目录，不创建生产候选索引。
