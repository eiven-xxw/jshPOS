## 证据等级

| 等级 | 定义 | 可以证明 | 不可以证明 |
|---|---|---|---|
| `STATIC` | 文档、Schema、静态扫描 | 设计一致性、结构和安全基线 | 运行行为 |
| `FAKE` | 受控模拟器/故障编排 | 内部契约、状态和恢复算法 | 厂商 SDK、实机或第三方沙箱可用 |
| `SANDBOX` | 合作方授权测试环境 | 指定合作方测试接口端到端行为 | 生产资金链路或其他合作方兼容性 |
| `REAL_DEVICE` | 指定序列号/固件的实机 | 指定设备与外设组合的运行结果 | 未测试型号或商业量产稳定性 |
| `PILOT` | 经授权的试点门店 | 指定版本和场景的门店结果 | 全市场普适性 |

低等级证据不得冒充高等级证据；所有报告标题、文件名和元数据必须标记等级。
