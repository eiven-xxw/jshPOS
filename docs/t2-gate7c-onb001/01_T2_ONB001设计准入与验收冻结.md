步骤键、请求摘要和结果摘要；任何客户端 tenantId、来源租户或 Owner 状态声明都不
构成授权依据。

## 3. 白名单、禁止项与模板规则

可复制配置键前缀冻结为：`business.time`、`business.day`、`ui.layout`、
`device.expectation`、`industry.template`、`catalog.scope`、`pricing.scope`、
`permission.template`、`receipt.template`、`approval.policy`。其他键一律拒绝。

键名或内容出现 `secret/token/password/credential/privateKey/member.identity/payment.raw/
order/inventory.balance/cost/points/audit/inbox/outbox` 等禁止语义时失败关闭。来源门店与
目标门店必须同属可信租户且不同；模板必须为已发布的
`CONVENIENCE/SNACK_DISCOUNT/COMMUNITY_SUPERMARKET` 版本。来源门店、模板或目标门店
版本变化后，旧计划显式过期并重新预检。

## 4. 状态机与冻结点

`DRAFT → PREFLIGHTING → PREFLIGHT_FAILED|READY → APPROVED → APPLYING →
APPLIED → CHECKING → CHECK_FAILED|READY_TO_OPEN → OPENED`。

- `DRAFT/READY/PREFLIGHT_FAILED` 可取消；`APPLYING` 后不得原地取消。
- 预检成功冻结来源门店版本、目标门店版本、模板版本/摘要和白名单配置快照。
- 审批人与创建人必须分离；审批后快照不可变。
- Apply 逐 Owner 记录只追加检查点；已有同摘要成功检查点直接返回原结果，同键异摘要拒绝。
- 内部必需检查全部 PASS、外部 P0 明确 BLOCKED 时可到 `READY_TO_OPEN`；商业
  `OPENED` 要求全部必需检查 PASS。合成测试中的 PASS 不提升外部证据等级。
- 部分 Owner 已成功后失败进入 `COMPENSATION_REQUIRED`；没有 Owner 效果的失败进入
  `FAILED`。恢复沿原计划和原步骤，不生成新业务命令。

## 5. 开店检查

内部检查：`STORE_ORG`、`BUSINESS_TIME`、`STAFF_SCOPE`、`CONFIG_TEMPLATE`、
`CATALOG_PRICE`、`DATA_PACKAGE`、`INVENTORY_POLICY`、`CASH_SHIFT_CLEAR`、
`DMT_RECONCILED`、`BACKUP_RECOVERY`。外部检查：`PAYMENT_EXTERNAL`、
`HARDWARE_EXTERNAL`、`PRINT_EXTERNAL`、`DESIGN_PARTNER_EXTERNAL`。

每条结果保存 Owner、事实版本、事实摘要、检查策略版本、结果
`PASS/FAIL/BLOCKED/UNAVAILABLE/WARN`、脱敏说明和检查时间。检查结果只追加；重检生成
新 run，不覆盖历史。

## 7. 权限、审计和容量

- `onboarding:plan:create/read/preflight/approve/apply/check/open/cancel` 分离授权；审批人
  不能是创建人，打开门店要求租户管理员和目标门店范围。
- 所有缓存、任务、导出、日志和对象路径使用可信租户命名空间；本 Requirement 不新增
  文件上传、导出或对象存储。
- 审计记录计划/目标/来源/模板/版本/请求摘要/关联 ID/操作者/审批人/结果，不记录
  Secret、凭据、会员身份或 Owner 私有载荷。
- 内部容量门禁：10,000 个合成计划状态归约不超过 60 秒，100,000 条合成检查结果
  摘要不超过 60 秒；只形成趋势，不构成生产 SLA。

## 8. 量化验收

1. 状态机、白名单、禁止项、版本漂移、幂等、审批分离和检查规则单元覆盖率：行≥90%、分支≥85%。
2. 至少 36 个固定故障/攻击向量，覆盖重复、乱序、重启、部分成功、跨租户、Secret/PII、外部假成功和前向修复。
3. MySQL 8.4 空环境执行 V1—V67、重复 migrate=0、validate 成功，租户复合外键和只追加触发器生效。
4. Vue 向导覆盖计划、差异、审批、Apply、检查、BLOCKED 展示和恢复；前端不得重算状态或构造 Owner 事实。
5. 服务端、Web、Flutter 双平台、SQLite、Kotlin/Android、Secret/PII、SBOM、许可证和既有 Gate 全量回归全绿。
