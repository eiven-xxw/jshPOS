## 3. 开发期缺陷与修复

在候选提交前的本地完整回归中，显式可选配置值为 `null` 时，Java `Map.copyOf`
不接受空值，导致冻结快照构造异常。修复后改为不可变 `LinkedHashMap`，保留空值参与
规范摘要，并在 Foundation 与 Onboarding 两层增加回归用例。候选 Run 首次即全绿，
没有跳过测试、降低阈值、自动重跑失败 Job 或修改已发布迁移。

候选 Run 通过后又补充“只有所有必需内部与外部检查均 PASS 才允许 OPENED”的正向
服务测试；该测试和本报告封存提交必须由完整闭环 CI 重新验证，不能用候选 Run
替代封存结论。
