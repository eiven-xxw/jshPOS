# ADR-059：Gate 8A 服务目录、实施项目、工单与附件安全边界

- 状态：Accepted
- 日期：2026-08-24
- 范围：T2-SVC-001
- 起点：`ae0c145b82306dd08f9a0999ba3f030d54e8e3e9`

## 决策

1. 新建 `jshpos-service` 模块，独占服务目录版本、实施项目/检查项、工单、租约、处理历史、附件元数据、审计和 Outbox。
2. Service 只通过 SaaS 正式权益服务读取套餐和 Subscription 访问投影；禁止直接写 SaaS、Subscription、Foundation、RuoYi 或其他 Owner 私有表。
3. 服务目录发布后内容不可变；实施项目和工单使用具名状态机、乐观锁、稳定幂等键和只追加状态/责任历史。
4. 必选检查项全部完成后才能移交；工单关闭必须绑定解决摘要，且关闭复核人与解决人职责分离。重开追加新状态事实，不覆盖原关闭事实。
5. 认领/转派租约保存在工单受控投影，所有责任变化另写只追加历史；过期租约不能继续操作。
6. 附件对象键只能由服务端按 `service/{tenant}/tickets/{ticket}/attachments/{attachment}` 生成。正文经正式对象存储端口写入，数据库只保存不透明对象键、SHA-256、媒体类型、大小和清理状态；下载链接最长 5 分钟且每次重新授权。
7. 内部目标时间只用于运营观察和告警，不构成合同 SLA、赔付或自动升级承诺。
8. 本 ADR 不准入真实通知、呼叫中心、聊天、远程控制、AI 派单、第三方工单连接器、伙伴现场授权或生产变更审批。

## 后果

- V85/V86 只新增前向迁移，已发布迁移不修改。
- 对象存储未配置或操作失败时附件能力失败关闭，不回落到本地磁盘、数据库或日志。
- Flutter POS 不新增服务工单运行时；运营旅程只进入 Vue 管理后台。
