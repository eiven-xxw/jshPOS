# ADR-063：Gate 8C 生产安全配置、管理端点与附件资源边界

- 状态：Accepted
- 日期：2026-08-24
- 关联：T2-SEC-002、G8C-SEC-P0-001、G8C-SEC-P1-002、G8C-SEC-P1-003、CR-T2G8C-004

## 背景

Gate 8C-Prep 已确认三个内部安全差距：生产配置包含静态默认凭据或令牌且可选集成默认启用；Actuator 暴露全部端点并固定展示健康详情；服务附件在 10 MiB 业务上限校验前调用 `MultipartFile.getBytes()`，并发上传会放大堆内存占用。

本批只关闭上述既定差距，不改变业务状态机、Owner 数据主权、租户授权、资金库存事实或外部证据状态。

## 决策

1. `application-prod.yml` 只保存受控环境 Secret 引用，不保存静态默认凭据。数据库、Redis、JWT、API 加解密和独立管理认证缺少必需值、使用已知默认值或强度不足时，生产安全配置 Bean 创建失败并阻断应用启动。
2. Spring Boot Admin、SnailJob、邮件、接口文档等可选集成在生产默认关闭；显式启用时必须同时提供该集成所需的地址或 Secret。短信和社交登录在没有受控配置时不建立生产 Provider 配置。
3. Actuator Web 暴露固定为 `health,info,prometheus`，健康详情使用 `when_authorized`；`/actuator/**` 继续使用独立 Basic 认证，拒绝访问只记录 URI 与来源地址，不记录 Authorization、用户名、密码或响应正文。
4. 全局 multipart 继续兼容 64 MiB 开业迁移文件，但落盘阈值固定为零；服务附件在获取输入流前按声明大小执行 10 MiB 上限校验。
5. 服务附件采用受限流式暂存：每次上传只使用固定 64 KiB 缓冲区，写入权限受控的随机临时文件，同时计算 SHA-256 并核对声明长度。对象存储只从暂存文件流式读取；所有成功、失败、超限和事务异常路径均关闭输入并删除暂存文件。
6. 对象键继续由可信租户、工单和服务端附件 ID 生成；客户端文件名、tenant_id、路径和摘要不得决定对象命名空间。数据库只保存元数据、摘要和受控对象引用。

## 不变量与失败语义

- 必需生产 Secret 不允许空值、未解析占位符或已知默认值；失败发生在业务端口开放前。
- Actuator 配置被命令行或环境扩大为 `*`、包含敏感端点或改为 `always` 时启动失败。
- 服务附件实际读取量必须等于声明量且位于 `(0, 10 MiB]`；不一致、超限、I/O 或对象存储错误一律失败关闭。
- 临时文件不得出现在对象存储键、数据库、普通日志、API 响应或证据制品中；关闭失败不能掩盖主异常。
- 不新增 Provider 网络、真实设备/外设命令、真实资金、真实 PII 或生产部署。

## 回退与兼容

- 配置回退只能恢复到上一安全配置模板，不得恢复静态默认凭据或全量 Actuator；Secret 由部署平台独立轮换。
- 附件 API 路径、幂等键、元数据、对象键和 10 MiB 上限保持兼容；仅将正文传递由 `byte[]` 改为流式暂存，不需要数据库迁移。
- 若对象存储写入后数据库事务回滚，沿用既有事务同步删除对象；本地暂存文件始终在方法退出时清理。

## 证据边界

本 ADR 的通过只代表内部软件安全整改，不代表生产 Secret 系统、生产 KMS、真实对象存储、支付沙箱、真实设备、完整 Alpha、生产或商业验收。
