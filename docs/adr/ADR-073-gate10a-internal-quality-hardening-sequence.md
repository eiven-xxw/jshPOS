# ADR-073：Gate 10A 内部质量加固的串行批次与语义停止线

- 状态：Accepted
- 日期：2026-08-26
- 决策范围：Gate 10A-Prep 与后续待批 R1—R4

## 背景

Gate 9C 已把 88 项需求、300 API、26 页面和 22 Owner 封存为内部产品完整性候选，但该结论不等于依赖生命周期、长期资源稳定、全 Owner 可观测性或 24/72 小时长稳已经完成。质量整改若和业务语义混在一起，会使资金、库存、租户、同步和迁移的已接受证据失去可比性。

## 建议决策

1. 按 R1 供应链、R2 Server/数据库、R3 端侧、R4 可观测性/长稳/恢复严格串行；
2. 每批先建立失败回归、阈值、影响分析和回退，再实施最小修复；
3. 技术债整改不得改变 Owner 数据主权、状态机、不变量、幂等身份、API 业务语义或已发布迁移；
4. 一旦需要新增业务或改变资金、库存、租户、支付、同步、迁移语义，立即停止并提交独立 CR 和 Requirement ID；
5. P2 关闭只形成内部质量证据，不提升 SANDBOX、REAL_DEVICE、PILOT、FULL_ALPHA 或生产证据等级。

## 当前阶段

项目发起人已于 2026-08-26 接受本 ADR 并准入 Gate 10A-R1。R1 只关闭已登记的三项
CI、依赖与供应链 P2；应用依赖和锁文件默认保持不变，第三方 Action 只允许使用单一
机器版本账中的精确 SHA。R2—R4 继续等待独立确认。
