# ADR-045：Gate 7C 秤码、金额码与计量快照

- 状态：Accepted
- 日期：2026-08-22
- Requirement：T2-PRD-005

## 决策

商业 V1 只准入版本化 EAN-13 秤码和金额码。Catalog Owner 持有模板、发布版本、
有效窗口、摘要和数据包；POS 本地按签名数据包确定性解析；Order Owner 冻结解析结果，
不得在成交或退款时按新模板重算。

模板字段采用 1 基位置，完整码固定 13 位，最后一位使用 EAN-13 校验。模板定义前缀、
SKU 段、数值段和小数位；字段不得重叠或覆盖校验位。门店范围优先于租户范围，随后按
最长前缀和显式优先级选择；仍然并列时失败关闭。

重量码的数值段形成精确主单位数量，以冻结单价计算最小货币单位金额并按
`HALF_EVEN` 舍入。金额码数值形成 CNY 分，金额为权威，按冻结单价和单位精度反算
数量并保存舍入标志。原始码、模板 ID/版本/摘要、SKU、单位、数量、单价、金额、
解析摘要和复核标志均进入购物篮及成交快照。

## 后果与边界

- 已发布模板不可覆盖修改；新版本、停用和安全前向修复保留完整审计。
- POS 不访问真实秤或厂商 SDK；只接收键盘楔入/合成字符串。
- 不准入价签、补货、批次、真实硬件或新价格算法。
