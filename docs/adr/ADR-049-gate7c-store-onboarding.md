# ADR-049：Gate 7C 门店开通编排、模板白名单与外部失败关闭

- 状态：Accepted
- 日期：2026-08-23
- 决策范围：T2-ONB-001

## 决策

建立独立 `jshpos-onboarding` 模块作为 Onboarding Owner，独占开店计划、冻结配置
快照、审批、步骤检查点、开店检查结果、状态事件、审计和 Outbox。Foundation 继续
独占组织、门店、行业模板及配置绑定，其他 Owner 继续独占商品价格、数据包、库存
策略、班次、终端和备份恢复事实；Onboarding 只通过正式端口读取或提交具名动作，
禁止跨 Owner Mapper 或直接修改私有表。

门店复制采用白名单快照而不是表级克隆。只允许复制营业参数、业务时区/业务日、UI
布局选择、设备能力期望、行业模板引用、商品/价格范围、权限、小票和审批模板引用。
Secret、终端凭据、会员身份、交易、库存、成本、积分、审计、Inbox/Outbox 和历史
流水永久处于禁止列表。快照绑定来源门店版本、模板版本、内容摘要和目标门店身份；
来源变化必须重新预检，不得静默使用过期快照。

跨 Owner 应用使用可恢复 Saga 和只追加步骤检查点，不承诺跨模块大事务。已发布模板
和已生效绑定不原地修改；失败保持上一有效版本，并沿原计划、原幂等键和原摘要观察
或恢复。已经营业或产生事实的门店不得用删除/覆盖回退，只能通过新配置版本或受审计
修复任务处理。

开店检查分为内部必需项和外部 P0 项。内部必需项全部通过、外部项仍为明确
`BLOCKED/UNAVAILABLE` 时，只能形成 `READY_TO_OPEN` 内部软件里程碑；外部支付、
真实硬件和真实打印未通过独立解阻前，不得伪造 `PASS` 或形成商业 `OPENED` 证据。
单元/合成测试可注入全 PASS 向量验证状态机，但证据等级仍为 `SYNTHETIC`。

## 后果与回退

- 三业态只通过版本化模板和页面配置表达差异，不复制核心状态机或领域算法。
- 关闭开店入口不会删除已应用的 Owner 事实；未应用计划可取消，已部分应用计划进入
  `COMPENSATION_REQUIRED` 或安全前向修复。
- `T2-LOT-001`、Gate 7D 和外部 P0 不因本决策自动准入。
