# ADR-058：Gate 8A 订阅生命周期、受控降级与时间收敛

- 状态：Accepted
- 日期：2026-08-23
- 范围：T2-SUB-001
- 起点：`abcf34ab2e99a75ba476fade6f203b38a2ed3c75`

## 决策

1. 新建 `jshpos-subscription` 模块，独占订阅头、期限版本、只追加状态事件、调度检查点、通知意图、审计和 Outbox。
2. Subscription 通过 `SaasSubscriptionControlPort` 读取套餐/权益快照并切换 SaaS 自有订阅访问投影；禁止直接写 SaaS、Foundation、RuoYi 或业务 Owner 私有表。
3. SaaS 访问模式固定为 `NORMAL/GRACE/RECOVERY_ONLY/TERMINATED_RECOVERY`。后两者仅保留退款、支付退款查询、对账、审计、备份恢复、法定导出、数据迁移和数据删除请求。
4. 既有未建立订阅的已开户租户进入明确的 `LEGACY_UNMANAGED` 兼容窗口，继续按既有套餐权益授权；一旦绑定订阅就必须由订阅访问投影控制，禁止回退到兼容路径。
5. 订阅期限采用只追加版本；续期不能覆盖历史。状态迁移、SaaS 访问切换、审计、通知意图与 Outbox 在同一 MySQL 事务内完成。
6. 到期扫描采用权威 UTC、IANA 时区、持久化租约/检查点及确定性命令键。重复、延迟、乱序、时钟偏移和重启只允许复用原业务身份并收敛。
7. 调度由可审计的具名任务入口触发，不在模块内隐式启用不可控定时器；生产调度策略在后续运维配置中显式装配。
8. 本 ADR 不准入真实计费、自动扣款、Provider、发票、应付、总账、税务、短信/邮件或资金沉淀。

## 后果

- 到期不会停用技术租户或删除业务历史；恢复通过新期限版本和新状态事实完成。
- 前端只展示服务端状态和原因，不根据本地时间推导订阅权限。
- MySQL 仅新增 V83/V84 前向迁移，已发布迁移不修改。
