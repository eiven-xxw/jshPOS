# ADR-053：会员权益、会员价与成交快照联动边界

- 状态：Proposed
- 日期：2026-08-23
- 决策范围：T2-MEM-003 准备阶段
- 准备基线：`39a72c65a08899f305ee0c04a5e337e1ee9ffbc9`

## 背景

现有 Member 已拥有会员档案、身份、同意、等级历史和积分；Pricing 已拥有基础价/门店价；
Promotion 已拥有确定性促销、人工优惠、成交分摊；Order 与 Refund 已冻结成交及退款快照。
仓库尚无会员权益版本、会员价候选、离线权益包和跨 Owner 成交引用，不能靠 UI 或直接查询
会员表补齐，否则会破坏主权、隐私、离线和退款不变量。

## 提议决策

1. 会员价/权益是三个业态共享、默认关闭的版本化能力，不按业态复制核心算法。
2. Member 独占权益策略版本、等级适用关系和最小权益快照；Pricing 独占会员价候选；
   Promotion 独占权益 Adjustment、互斥/叠加与解释；Order 只冻结不可变成交引用；Refund
   只读取原快照恢复。
3. 默认计算策略为 `BEST_PRICE`：普通价格/促销路径与会员候选/显式可叠加权益路径分别计算，
   选择应收更低者；平价按稳定优先级选择。双方未显式允许时禁止折上折。
4. 离线权益包不含 PII，必须签名并绑定可信租户、门店、版本、摘要、有效期和撤回纪元；失效
   时只允许显式确认后重新按非会员报价，禁止静默降级。
5. 已冻结订单、部分/最终退款始终读取原权益、会员价、促销和人工优惠快照，不受当前等级、
   当前价格或撤回影响；事后发现撤回只形成异常和审计。
6. 商业 V1 同租户、显式门店范围，优惠经营责任归销售门店；加盟/总部清分另行 CR。
7. 迁移只前进，已发布迁移不得修改；运行时阶段必须新增独立权限、审计、幂等和跨端向量。

## 状态与后果

本 ADR 仍为 `Proposed`，只冻结候选设计，不授权运行时。项目发起人接受 CR 后才可转为
`Accepted`，并另行启动 `T2-MEM-003` 独立实现。此前 RTM 必须保持 `DRAFT`，生产路径、表、
迁移、Controller、页面和任务的新增数量均为 0。
