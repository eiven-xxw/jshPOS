# ADR-043：Gate 7B POS 交易运营第一批串行扩展

- 状态：Accepted
- 日期：2026-08-21
- 基线：`fd255f45115015fa0bab91f1fd8b1c14c2acc51e`

## 决策

1. 严格按 `T2-POS-010 → T2-POS-011 → T2-ORD-004` 串行准入；
2. POS-010 在既有 Checkout/Order Owner 内新增非销售现金移动和钱箱请求事实，不扩大 Device Owner；
3. 非销售现金移动使用独立只追加表，避免修改已发布销售/退款现金流水约束；关闭班次汇总两个合法现金来源；
4. 钱箱请求不产生金额效果，真实设备未解阻时执行状态必须为 `BLOCKED_EXTERNAL`；
5. SQLite 本地事实、班次版本、审计、幂等和 Outbox 同事务；服务端通过可信 Sync/REST 上下文重放同一事实；
6. 后继小票补打和取消作废只可在前项独立 VERIFIED 后准入，不能提前预建运行时。

## 理由

独立只追加表保留 Gate 2 已封存现金销售事实和 Gate 5B 退款事实，减少修改历史约束的风险；钱箱请求与硬件执行分离可满足内部产品化而不伪造 REAL_DEVICE 成功。

## 后果

关班理论现金必须汇总原销售/退款流水与新非销售移动。未来真实钱箱接入只能追加 Device Owner 执行观察，不能回写业务请求为伪成功。
