## 2. Owner 复用

Checkout/Order Owner 继续拥有本地/云端班次、现金、订单、审计、幂等与 Outbox；Sync Owner 只负责至少一次传输和可信设备上下文；Device Owner 只报告外设执行观察。本 Gate 不创建平行 Cash、Receipt 或 Void Owner。

## 3. 共同门禁

每项在实现前冻结：数据主权、状态机、冻结点、金额不变量、权限、审计、幂等、事务、API/事件、MySQL/SQLite 前向迁移、容量、兼容、回退、故障向量和量化验收。Controller 与 UI 只做协议和展示，不能拼装领域事实。

## 4. 非目标

不包含换货、组合支付、Provider 网络、真实钱箱/打印、硬件 SDK、储值、优惠券、后续 Gate、完整 Alpha、生产部署和商业声明。`T2-EXG-001/PAY-004` 保持 DRAFT。
