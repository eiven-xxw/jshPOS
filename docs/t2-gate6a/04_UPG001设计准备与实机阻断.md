# T2-UPG-001 设计准备与实机阻断

> 状态：`DRAFT / REAL_DEVICE BLOCKED`。本 Sprint 禁止正式升级运行时。

## 1. 设计输入

- 发布物：服务端、Web、APK、MySQL Schema、SQLite Schema、数据包/行业模板。
- 身份：release ID、版本、渠道、内容 SHA-256、签名、构建 commit、SBOM、最低协议/Schema/系统版本。
- 状态：`DRAFT → SIGNED → STAGED → CANARY → ROLLING → COMPLETED | PAUSED | FAILED`。
- 终端任务：`PLANNED → DOWNLOADING → VERIFIED → INSTALLING → HEALTH_CHECK → SUCCEEDED | ROLLED_BACK | FORWARD_FIX_REQUIRED`。
- 营业保护：班次开启、待同步 Outbox、UNKNOWN 支付、磁盘/电量不足、关键营业时段默认阻断自动安装。
- 兼容窗口：服务端至少支持当前与上一批准 POS 主版本；Schema 只前进，事实错误用前向修复。

## 2. 允许的合成向量

摘要/签名错误、截断、旧包重放、跨租户包、版本跨度、下载中断、安装前进程终止、迁移失败、健康检查失败、待同步状态、营业时段、旧客户端/新服务端、新客户端/旧服务端和前向修复。

## 3. 阻断项

- 缺主认证 Android 厂商/型号/固件/SDK、静默安装权限与样机；
- 缺 Android Keystore/设备证书、物理断电、存储压力和真实安装回滚证据；
- 缺 MDM/厂商升级 SLA 与固件兼容承诺。

因此本 Sprint 不创建 `dev_app_release`、`dev_update_job`、升级 Controller、安装命令或远程终端执行器，不得将合成向量写成 `REAL_DEVICE` 或 Alpha 通过。
