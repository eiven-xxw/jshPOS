# Gate 6A 测试矩阵、CI 与证据规范

## 1. TRM-001

覆盖签发/过期/取消/重复激活、同键异摘要、凭据一次展示、轮换/吊销、克隆、时钟偏移、最低版本、能力降级、门店迁移、跨租户/跨门店、缓存与任务污染、100k 终端查询和迁移前向修复。

量化门槛：终端/激活/凭据/能力/审计表的租户攻击 0 成功；明文秘密持久化/日志/制品命中 0；100k 终端分页查询基线 ≤30秒（CI 合成趋势，不是生产 SLA）；固定向量全部确定性通过。

## 2. BAK-001

覆盖清单/摘要/加密、缺片/损坏/错密钥/跨租户替换/过期/保留锁、并发写入与 cutoff、PITR 边界、对象缺失、空环境恢复、Flyway validate、投影重建、逐日守恒、游标/审计核对、恢复中断与重新开始。

量化门槛：内部合成 RPO≤15分钟、RTO≤60分钟、未解释差异=0、跨租户对象=0、错误恢复点误接受=0。生产 KMS、跨账号/跨区域和真实云对象证据保持 0。

## 3. CI Job

governance、server、mysql-terminal-capacity、terminal-security、backup-restore、fixed-vectors、admin-web、pos-linux、pos-windows、security-sbom-license、evidence。TRM 独立阶段的 backup-restore 只能校验 DRAFT 契约；BAK 获准后才执行正式恢复演练。

所有 Action 固定 SHA；无 `continue-on-error`、自动 retry、阈值降低、测试跳过或绿色占位。每个生产 Job 只上传一次制品，最终 Job 只上传证据索引。

## 4. 证据等级

`STATIC/UNIT/MYSQL8.4/SYNTHETIC_RESTORE` 不得升级为 `REAL_DEVICE/PRODUCTION_DR/PILOT`。证据必须记录 commit、Run/Job/Artifact ID、测试数、覆盖率、迁移版本、攻击面、固定向量、RPO/RTO、失败修复和所有未验证边界。
