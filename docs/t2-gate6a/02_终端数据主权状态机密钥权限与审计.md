# T2-TRM-001 终端数据主权、状态机、密钥、权限与审计

## 1. 数据主权

| 对象 | Owner | 物理对象 | 策略 |
|---|---|---|---|
| 终端注册与当前状态 | Terminal Registry（`jshpos-sync`） | 扩展 `pos_sync_device` | `XML_ONLY`，条件状态更新，禁止通用 CRUD |
| 一次性激活授权 | Terminal Registry | `dev_terminal_activation` | `XML_ONLY`，只存 HMAC 摘要与消费状态 |
| 凭据版本 | Terminal Registry | `dev_terminal_credential` | `XML_ONLY`，明文只返回一次，历史不删除 |
| 能力快照 | Terminal Registry | `dev_capability_snapshot` | `XML_ONLY`，只追加、摘要去重 |
| 命令幂等结果 | Terminal Registry | `dev_terminal_command_result` | `XML_ONLY`，同键异摘要拒绝 |
| 终端审计 | Terminal Registry | `dev_terminal_audit` | `XML_ONLY`，只追加不可更新/删除 |

`pos_sync_device` 是 Sprint S3 已发布的正式表，本 Gate 通过 V36 Expand 方式扩展。逻辑上它承载详细设计中的 `dev_terminal`，禁止再建同语义主表。

## 2. 状态与冻结点

激活授权：`ISSUED → CONSUMED | EXPIRED | CANCELLED`。只有 `ISSUED`、未过期、摘要匹配且未消费才能激活；消费与终端/凭据/能力/审计在同一事务。

终端：`ACTIVE → BLOCKED → ACTIVE`（受权解阻），`ACTIVE|BLOCKED → REVOKED → RETIRED`。`REVOKED/RETIRED` 不可恢复；门店迁移必须吊销旧绑定并签发新激活授权，禁止原地改 `tenant_id/store_id/terminal_id`。

凭据：`ACTIVE → ROTATED | REVOKED | EXPIRED`。每终端最多一个 ACTIVE 版本；轮换创建新版本并使旧版本不可再验证。

## 3. 关键不变量

- `device_id`、tenant、org、store、terminal profile、fingerprint digest、public-key digest 在激活成功后冻结；修正使用新激活事实。
- tenant/store 来自激活授权或已认证设备会话，任何 Header/Body tenant 只可用于一致性校验。
- 激活码和设备凭据均至少 256 bit 随机，服务端仅保存 HMAC-SHA-256 摘要；比较使用常量时间函数。
- capability JSON 先规范化再 SHA-256；业务按能力代码与契约版本判断，不按厂商/型号字符串猜测。
- 应用、协议、Schema 版本使用解析后的数字元组比较，不允许字符串字典序比较。
- 客户端时间仅用于测量偏移；超过允许阈值进入 `BLOCKED` 或拒绝时效动作，不能决定事实顺序。
- 同一幂等键同摘要返回原结果；同键异摘要返回冲突并写安全审计。
- 克隆判定使用同一凭据版本同时出现不同 fingerprint/public-key 摘要；检测后失败关闭并阻断终端。

## 4. 权限与审计

| 操作 | 权限 | 额外约束 |
|---|---|---|
| 签发/取消激活授权 | `terminal:activation:manage` | 门店数据范围；激活秘密只返回一次 |
| 查询终端 | `terminal:registry:read` | tenant + 组织/门店范围 |
| 阻断/解阻 | `terminal:security:manage` | 原因必填；解阻需租户管理员 |
| 吊销/退役 | `terminal:security:manage` | 不可逆确认；Outbox 积压仅记录风险，不自动抹除 |
| 轮换凭据 | 已认证设备或 `terminal:security:manage` | 原凭据有效或管理员强制轮换审计 |
| 上报能力 | 已认证设备 | 只能为自身追加快照；租户/门店由会话注入 |

审计至少记录事件 ID、tenant、device、store、动作、前后状态、摘要、版本、actor、原因、correlation ID 和 UTC 时间；不得记录明文秘密、公钥原文、完整指纹或不必要 PII。

## 5. 兼容与回退

V36 仅增加可空/有安全默认值的列和新表，不删除 Sprint S3 字段。旧设备行标记 `LEGACY_IMPORTED`，仍可在兼容窗口内同步，但不能获得“已完成 Gate 6A 激活”的证据。应用回退读取旧列不受影响；迁移问题只用新前向迁移修复。
