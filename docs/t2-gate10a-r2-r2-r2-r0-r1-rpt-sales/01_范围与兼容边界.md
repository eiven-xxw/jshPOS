# 范围与兼容边界

## 准入

- Reporting Owner 的销售批量读取端口；
- `/api/v2/reports/sales-daily` 有界 keyset 分页；
- `SALES_DAILY` 导出固定批次流式生成与可恢复检查点；
- MySQL 8.4.11 的 10k/100k 合成执行计划、查询数、守恒和租户攻击。

## 兼容

`/api/v1/reports/sales-daily`、`querySalesDailyReport` 和原列表响应保持不变。v2 使用新的
`querySalesDailyReportV2`，页面最多 500 行；游标绑定可信租户、投影版本、日期、门店、终端、
收银员和上一行复合键。关闭 v2 路由与销售流式装配即可回退，历史事实和导出审计不得删除。

## 非目标

库存成本和支付对账报表仍使用旧契约；不修改索引、数据库对象和已发布迁移；不改变报表口径、
资金、库存、租户、支付、同步、事件或其他 Owner 事实；不进入资源长稳、R3、完整 Alpha 或生产。
