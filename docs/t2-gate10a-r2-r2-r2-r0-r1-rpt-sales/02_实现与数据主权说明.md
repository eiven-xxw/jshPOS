# 实现与数据主权说明

## 调用链

Vue 报表页 → v2 Controller → `ReportQueryService` → `ReportingBatchReadPort` →
`MyBatisReportingPersistenceAdapter` → `ReportingPersistenceMapper.querySalesPage` →
Reporting Owner 自有 `rpt_sales_daily` 投影。

Controller 只做协议和校验，不接收 `tenant_id`。应用服务从 `TrustedTenantContext` 取得租户，逐门店
调用数据范围授权；Mapper XML 显式包含 tenant、projection、业务日、门店集合、可选筛选、keyset、
稳定排序和 LIMIT。

## 游标与错误

游标采用 HMAC-SHA256，载荷包含格式版本、tenant、filter SHA-256、projection version 和复合键。
签名、租户、筛选、版本、长度或尾随字节异常统一失败为 `RPT-R2R2-008`。缺少安全密钥时 v2
游标能力失败关闭，不回退为无签名游标。

## 流式导出与恢复

销售导出不再按门店执行 50 次列表查询，也不在 Java 内存拼接全量 CSV。每批最多 10,000 行，
写入后 flush，并原子保存请求摘要、已确认字节偏移和签名游标。进程失败后先截断未确认尾部，
再从原游标续写；同导出身份异摘要返回 `RPT-R2R2-009`。库存/支付导出路径保持兼容，未提前整改。
