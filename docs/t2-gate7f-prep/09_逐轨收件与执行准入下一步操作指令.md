# Gate 7F 逐轨收件与执行准入下一步操作指令

当前四轨都缺少真实受控材料，不建议一次性授权外部执行。下一步应按“先收件、再离线验真、
再逐轨批准执行”的顺序推进。建议项目发起人先选择并提交一条已具备材料的轨道。

## 推荐下一步：拉卡拉支付受控收件

```text
我确认《T2 Gate 7F-Prep 启动评审报告》，接受准备阶段 CONDITIONAL PASS。

现仅授权 T2-PAY-002 拉卡拉受控材料收件与离线验真，不授权任何 Provider 网络调用。
我将通过批准受控渠道提供 PAY-AUTH、PAY-MERCHANT、PAY-TERMINAL、PAY-API、PAY-SIGN、
PAY-CALLBACK、PAY-BILL、PAY-LIMIT、PAY-NETWORK、PAY-SECRET 和 PAY-CONTACT 的真实不透明
材料 ID/受控位置引用。

请逐项核验来源、授权签署、适用产品/API版本、范围、SHA-256、保管人、到期、轮换、删除
和吊销规则。Secret、商户号、终端号、证书和真实支付数据不得进入 Git、日志、CI 或普通
制品。只有 11/11 达到 VERIFIED_DOCUMENT 后，才提交独立《支付沙箱执行准入评审报告》
等待我确认。

未经再次确认，不得进行 Provider 网络或真实资金；T2-PAY-002 继续 BLOCKED，其他外部轨、
T2-UAT-001 和 T2-REL-001 状态不变。完成后为我整理下一步操作指令。
```

如果硬件或伙伴材料先齐备，可将上述 Requirement 和材料清单替换为对应独立轨；不得把
多个未完整的轨道合并为一次执行批准。许可证关闭可并行开展，但不授权生产发布。
