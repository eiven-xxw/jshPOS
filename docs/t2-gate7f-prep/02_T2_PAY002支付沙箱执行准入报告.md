# T2-PAY-002 支付沙箱执行准入报告

## 1. 评审结论

`NOT_ACHIEVED / BLOCKED / NO-GO`。首接候选为拉卡拉，实际受控材料仍为 `0/11`；本报告
不是支付沙箱解阻。Provider 网络、真实资金、SDK/HTTP、回调入口和账单下载均为 0。

| ID | 材料 | 当前 | 验真重点 |

| PAY-AUTH | 授权沙箱及自动化授权 | MISSING | 签署主体、产品、环境、期限、允许用例 |

吊销规则。任一缺失时整包不得达到 `VERIFIED_DOCUMENT`。

## 3. 获批执行前矩阵

需覆盖支付成功/失败/超时/UNKNOWN、原请求查询、重复乱序回调、同键异内容、部分/最终
退款、退款 UNKNOWN、账单缺失/重复/差异、签名错误、证书轮换、限流、网络中断和对账。
UNKNOWN 只能查询、回调或账单观察收敛，禁止创建第二次扣款或退款命令。

## 4. RACI、停止与下一决定

支付 Owner 负责接口映射，安全 Owner 负责 Secret/网络，财务 Owner 负责账单口径，QA
负责证据，项目发起人负责执行批准。当前只能通过批准受控渠道补齐 11 项；整包达到
`VERIFIED_DOCUMENT` 后仍须提交独立报告等待确认。
