# Gate 4B 测试矩阵、CI 与证据

## 1. 固定风险矩阵

- 盘点：盲盘、计数修订、复盘阈值、三人职责分离、销售穿越截止点、差异为零、盘盈/盘亏、重复批准、入账后修改拒绝。
- 采购：重复供应商码、审批分离、部分收货、拒收、超收拒绝/容差、重复确认、原收货退货上限、重复退货审批、单位精确换算。
- 共性：两虚构租户、跨租户 ID、同事件异 hash、事务回滚、迁移失败、不可变触发器、Secret/PII、依赖/SBOM/许可证。

## 2. CI

Gate 4B CI 包含治理、服务端完整 reactor、MySQL V1—V15、盘点/采购租户攻击、20 个固定向量、Flutter Linux/Windows、Web、安全/SBOM/许可证与证据汇总。不得 `continue-on-error`、自动重跑、跳过失败测试或降低既有 90% line/85% branch 阈值。

## 3. 证据等级与退出

本 Sprint 最高证据为 `STATIC+UNIT+MYSQL_INTEGRATION+SYNTHETIC_VECTOR`。`T2-INV-003`、`T2-PUR-001` 只有全部门禁通过才可到 `VERIFIED`，`ACCEPTED` 仍须项目发起人确认。`SANDBOX/REAL_DEVICE/PILOT` 均保持 0。
