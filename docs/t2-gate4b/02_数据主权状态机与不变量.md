# Gate 4B 数据主权、状态机与不变量

## 1. 数据主权

- `jshpos-inventory`：盘点、库存命令、不可变数量流水、余额、异常、库存审计与库存 Outbox。
- `jshpos-procurement`：供应商、采购订单、收货、采购退货、采购审计与采购 Outbox。
- `jshpos-catalog`：SKU、基础单位和采购单位换算，只通过只读端口提供快照。
- `jshpos-foundation`：可信租户、门店数据范围和业务日。

## 2. 盘点状态

`COUNTING → RECOUNT_REQUIRED → COUNTING` 或 `COUNTING → PENDING_REVIEW → REVIEWED → POSTED`；入账前可 `CANCELLED`。同一计数修改不覆盖历史，而是追加 `count_revision`。差异为零可无库存流水直接 `POSTED`；非零差异必须产生唯一 `STOCKTAKE_GAIN/LOSS`。

不变量：`adjusted_book_quantity` 取提交时锁定余额；`variance=counted-adjusted_book`；批准时把 variance 加到最新余额，不能把余额设置为 counted。创建人、复核人、批准人互不相同；入账后单据和计数不可修改。

## 3. 采购状态

- 供应商：`ACTIVE/SUSPENDED/BLOCKED`。
- 采购订单：`DRAFT → SUBMITTED → APPROVED → PARTIALLY_RECEIVED/RECEIVED → CLOSED`，入库前可取消。
- 收货：`DRAFT → CONFIRMED`，确认后不可修改。
- 采购退货：`DRAFT → PENDING_APPROVAL → POSTED`，批准人与申请人分离。

不变量：订单不改变库存；`received_base_quantity ≤ ordered_base_quantity × (1+tolerance)`；`returned_base_quantity ≤ confirmed_received_base_quantity`；拒收数量不入库；同一 receipt/return event 重放只返回原结果；采购价快照不得作为成本账本结果。
