# Gate 4B Flyway、容量、兼容与回退

## 1. 迁移

- V13 扩展库存命令/流水受控类型并建立盘点头、行、计数和调整引用。
- V14 建立供应商、采购订单/行、收货/行、退货/行、采购审计和采购 Outbox。
- V15 建立盘点与采购权限号段。
- V11/V12 保持 checksum 不变；V13—V15 通过 closure 后另行封印。禁止修改已发布迁移。

## 2. 容量目标

盘点或收货单最多 500 行；锁按 SKU/来源行稳定排序。普通 500 行收货目标 5 秒内完成或明确失败，不允许部分库存可见。单租户千万级库存流水仍须按来源、仓库、SKU、业务日定位。

## 3. 兼容与恢复

旧应用忽略新表；库存移动类型扩展保持 Gate 4A 类型语义不变。应用回退只允许停用新入口并回退二进制，不回滚已落流水或删除新表。迁移/约束错误只能通过 V16+ 前向修复；跨模块事务失败时采购单据与库存效果必须整体回滚。
