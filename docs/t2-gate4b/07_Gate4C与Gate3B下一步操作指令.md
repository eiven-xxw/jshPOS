## 2. Gate 4C 建议冻结的关键规则

- 成本模块是成本事实和成本投影的唯一 Owner；不得回写库存数量流水，不得以采购单价直接覆盖库存成本。
- 成本输入只接受已确认的采购收货/原收货退货、已接受的库存流水以及后续获准的更正事实；每个来源使用稳定幂等键和内容摘要。
- 移动加权平均使用 `DECIMAL/BigDecimal`，禁止浮点数；必须冻结内部精度、舍入模式、货币、单位换算、零库存、负库存和跨业务日规则。
- 历史出库保留出库时成本快照；晚到事实、退货、更正和重放通过新事实/冲正表达，禁止修改历史成本流水。
- 成本余额只是可丢弃投影，必须能从不可变成本流水全量重建，并与增量计算得到相同摘要。
- 本 Gate 不包含应付、发票、总账、税务会计、生产加工成本、批次成本、先进先出或商业财务验收。
