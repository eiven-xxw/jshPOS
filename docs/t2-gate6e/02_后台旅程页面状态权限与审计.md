# T2-ADM-002 后台旅程、页面状态、权限与审计

## 1. 数据主权与页面分区

| 页面分区 | 唯一 Owner | 页面能力 | 禁止行为 |
|---|---|---|---|
| 库存与盘点 | Inventory | 余额/流水查询、受控重建、盘点状态操作 | 直接改余额或历史流水 |
| 采购 | Procurement | 供应商、采购单、收货与原收货退货 | 前端生成库存/成本事实 |
| 调拨 | Transfer | 申请、审批、发出、收货、差异与取消 | 同时覆盖两仓余额 |
| 成本 | Costing | 成本余额/流水查询与受控重建 | 人工覆盖历史成本 |
| 促销 | Promotion | 规则版本验证、审批、发布、暂停/退役 | 前端复制规则计算器 |
| 会员 | Member | 令牌化查询、同意/隐私请求、积分只追加操作 | 展示或保存不必要 PII |
| 报表 | Reporting | 查询、差异、审批导出与重建 | 报表反写权威事实 |
| 终端与发布 | Terminal/Release | 状态、凭据轮换、发布验证、灰度与暂停 | 客户端自报租户或直接发设备命令 |

## 2. 页面状态

统一页面状态为 `IDLE/LOADING/READY/CONFIRMING/SUBMITTING/SUCCEEDED/FAILED/STALE`。写操作在 `SUBMITTING` 时单航班；失败保留原输入、服务端错误码和关联标识，不伪造成功状态。

## 3. 权限与数据范围

- 路由和按钮权限只负责展示，服务端 `SaCheckPermission` 与可信租户/门店范围是最终授权。
- 查询和写入请求都不得携带可作为授权依据的 `tenant_id`；组织、门店、仓库和终端范围必须由服务端交叉校验。
- 高风险操作至少包括盘点审批、采购退货、调拨发出/差异、成本/库存重建、促销发布、积分人工调整、报表导出、终端吊销/轮换和发布灰度。

## 4. 确认、幂等与审计

- 二次确认必须展示对象 ID、当前状态/版本、目标动作、影响范围和原因。
- 幂等键由前端应用服务为一次操作生成并在重试时复用；同键异内容由服务端拒绝。
- UI 显示服务端返回的审计/关联标识；前端日志不得记录令牌、密文、真实 PII 或签名材料。
