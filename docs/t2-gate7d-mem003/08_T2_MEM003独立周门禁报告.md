## 3. 开发期缺陷与修复

1. 首次候选 Run `32623623290` 暴露 Flutter Gate 6D 覆盖率 `0.8895 < 0.90`。补充正式
   POS 会员识别、重报价和清除会员应用服务旅程后提升至 `0.9093`，没有降低阈值。
2. 同一 Run 的 MySQL Job 因 `ruoyi-admin` 默认标签过滤实际执行 0 项，证据复制正确失败。
   初次只给测试增加 `local` 标签后，Run `32624233813` 仍因默认 `dev` profile 执行 0 项；
   最终由专属 MySQL Job 显式 `-Plocal`，常规 Server Job 不被数据库依赖污染。
3. Run `32624504379` 首次真正执行 V1—V80，发现已发布 Gate 4C 与 Gate 7C 的
   `sys_menu` 主键 `9200540—9200543` 冲突。未回写历史迁移；新增组合根
   `beforeEachMigrate` 幂等前向修复，把成本权限和角色绑定迁至 `9201540—9201543`，
   目标冲突或未收敛时 `SIGNAL` 失败关闭。
4. Flutter Windows 曾在关闭 in-memory SQLite 时暴露 WAL 文件占用；关闭前新增 WAL
   checkpoint，并把所有正式 Schema 断言同步到 v16，避免依赖平台偶然释放文件句柄。
5. 签名包解码初版先解析 payload 再核对 tenant/store；现先验证可信范围、版本、摘要与
   签名，再解析内容，补充畸形包、跨门店、摘要漂移、撤回和旧版本回归。
6. 三个失败 Run、注解和日志原样保留；没有删除用例、跳过失败 Job、自动重跑掩盖
   Flaky、降低安全/覆盖率门槛、修改已发布迁移或建立测试后门。
