# T2-MEM-003 跨端向量、故障注入与内部 E2E 独立验证记录

## 1. 结论

第六段 `CROSS_PLATFORM_E2E = VERIFIED_LOCAL`，并已由 GitHub 干净执行器完成候选验证。
证据等级固定为 `INTERNAL_SYNTHETIC_SOFTWARE`，不得升级为支付沙箱、实机、伙伴、完整
Alpha、生产或商业证据。

## 2. 跨端确定性

- 共享契约 `member-benefit-price-vectors.json` 共 40 个唯一固定向量，其中 10 个为 Java、
  Dart 双端实际执行的金额向量。
- Java 由 `MemberBenefitCrossPlatformVectorTest` 执行，Dart 由
  `member_benefit_cross_platform_vector_test.dart` 执行。
- 覆盖 `BEST_PRICE`、普通路径平价胜出、双向显式叠加、门店范围、等级过期/撤回、
  人工优惠、业务日、原快照部分/最终退款和摘要篡改。
- gross、discount、payable 逐字段守恒；金额使用最小货币单位整数，数量与换算不使用
  `float/double`。

## 3. 正式 POS 与内部闭环

- 正式应用服务覆盖无效短期令牌拒绝、会员识别、会员路径重报价、清除会员恢复普通路径；
  Flutter Gate 2 覆盖率为 `0.9187`，Gate 6D 页面/应用服务覆盖率为 `0.9093`，均未降低
  既有 `0.90` 门槛。
- 内部 E2E 使用签名权益包、短期会员缓存、BEST_PRICE 报价、现金成交、不可变订单会员
  快照与 Outbox 正式路径；没有数据库后门、测试成功适配器或 Provider 网络。
- SQLite v16 的包槽、等级、会员价、报价权益和订单权益快照在规定事务内提交；WAL 关闭
  前执行检查点，Ubuntu 与 Windows 共 186 项 Flutter 测试通过。
