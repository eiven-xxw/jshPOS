| 链路 | 当前结论 | 失败条件 |
|---|---|---|
| Requirement → 实现/测试证据 | 88/88 可达 | 任一实现引用不可达 |
| Owner → Reactor/Admin/依赖管理 | 22/22 | 缺源码、测试或装配 |
| Controller ↔ OpenAPI | 300/300、差异 0/0 | 任一方向漂移或 operationId 冲突 |
| Vue/Flutter → API/Repository | 26/26 正式页面 | 页面缺失、API 无服务端、直接访问底层原语 |
