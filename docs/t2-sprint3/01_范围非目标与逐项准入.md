# S3 范围、非目标与逐项准入

## 1. 唯一正式范围

| Requirement ID | Owner | 正式范围 | 非目标 | 状态入口 |
|---|---|---|---|---|
| `T2-SYN-001` | Sync/POS | POS Outbox 发送、服务端持久 Inbox、逐事件 ACK/结果、下行 Inbox/游标、冲突、积压和恢复 | 支付 Provider、库存命令、硬件认证、商业 SLO | 完成十二维准入后进入 IN_PROGRESS |

十二维准入：来源、范围/非目标、数据主权、状态、不可变量、权限、审计、API/事件、MySQL/SQLite 迁移、容量、回退、测试证据均冻结于本目录、ADR-021 和 `contracts/t2/sprint3`。

## 2. Gate 3-Prep

| Requirement ID | 允许内容 | 状态 | 运行时限制 |
|---|---|---|---|
| `T2-PAY-001` | Provider 无关支付/尝试状态机、UNKNOWN 与端口 | DRAFT | 支付聚合、数据库表、调度器和网络适配器均为 0 |
| `T2-PAY-003` | 查询/回调观察结果的优先级与隔离契约 | DRAFT | 无回调 Controller、验签实现或 Provider SDK |
| `T2-REF-001` | 原单退款状态、可退金额/数量与职责分离测试向量 | DRAFT | 无退款表、API、渠道调用和现金退款 |
| `T2-REC-001` | 内部账/渠道账差异分类与处置状态 | DRAFT | 无账单下载、对账任务或财务调整运行时 |
| `T2-PAY-002` | 授权沙箱证据 | BLOCKED | 缺资料时禁止调用 |

## 3. 明确非目标

- 不实现支付、退款、库存、采购、成本、促销和鲸熵汇连接器；
- 不接收生产密钥、真实支付、真实个人/商户数据；
- 不实现设备激活、证书签发或主认证机厂商 SDK；
- 不把 Fake、Loopback HTTP 或 APK 编译解释为 SANDBOX、REAL_DEVICE、PILOT；
- 不创建支付绿色占位，不修改已封存 tag 和历史迁移。

## 4. 停止条件

任一跨租户成功、相同 event_id 不同 hash 未阻断、ACK 丢失导致重建业务命令、游标倒退、未 ACK Outbox 被删除、支付网络入口出现或迁移重写，立即停止并判定 No-Go。
