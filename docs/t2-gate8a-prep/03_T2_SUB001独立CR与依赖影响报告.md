# T2-SUB-001 独立 CR 与依赖影响报告

## 1. 当前结论

`T2-SUB-001` 有明确商业价值，但依赖 `T2-SAA-001` 的套餐权益、商业租户生命周期和受控
降级端口。当前保持 `DRAFT / DEPENDENCY BLOCKED`，不建议提前创建任何运行时。

## 2. 边界与状态

计划独立 `jshpos-subscription` Owner，写订阅、期限版本、状态事件、调度检查点、通知意图和
Outbox；只通过 SaaS 正式端口请求权益切换。状态固定为 `DRAFT、PENDING_ACTIVATION、ACTIVE、
GRACE_PERIOD、SUSPENDED、EXPIRED、TERMINATION_PENDING、TERMINATED、RESTORED`。

订阅绑定可信 tenant_id、不可变套餐版本、合同/订单不透明引用、生效/失效时间、业务时区、
宽限策略和内容摘要。续期、到期和恢复只追加状态事实；`TERMINATED` 不代表物理删除。

## 3. 依赖影响

- SaaS：提供套餐权益快照、能力切换命令和受控恢复能力集合。
- Foundation：提供可信时间/租户上下文和任务租户范围，但不承载订阅规则。
- 业务 Owner：只消费版本化能力决定；不得让 Subscription 直接改业务事实。
- Vue/Flutter：只显示服务端结果和明确受限原因，不能自行计算到期或权限。

调度需覆盖重复、乱序、时钟偏移、业务时区、服务重启和同键异内容；以权威 UTC 时间点、
期限版本、检查点和稳定幂等键收敛。

## 4. 非目标与后续 Go/No-Go

不包含真实计费扣款、Provider、资金、发票、应付、总账、税务、真实短信/邮件和商业赔付。
只有 SAA 运行时独立 VERIFIED 并经项目发起人 ACCEPTED 后，才提交 SUB 正式开发启动评审。
