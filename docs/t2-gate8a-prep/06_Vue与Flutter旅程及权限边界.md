# Vue、Flutter 旅程与权限边界

## 1. Vue 运营旅程

未来运营后台计划包含：商户申请队列与预检、双人审批、租户初始化检查点、套餐权益版本发布、
租户暂停/恢复、订阅时间线与续期、实施项目交付看板、服务工单与附件。每个写操作展示当前状态、
版本、影响范围和不可逆后果，使用稳定幂等键，执行二次确认并返回审计引用。

页面只调用正式 API，不查询私有表，不拼装 tenant_id，不计算套餐权益、配额、到期状态或租户
生命周期。跨门店列表、导出、附件和批量操作必须由服务端返回已经按可信租户、角色和数据范围
过滤的结果。

## 2. Flutter POS 提示契约

本阶段不新增 Flutter 页面，只冻结以下应用状态：

- `ENTITLEMENT_ACTIVE`：显示服务端签名能力快照和有效期；
- `ENTITLEMENT_RESTRICTED`：明确列出受限能力、原因和可恢复入口；
- `ENTITLEMENT_EXPIRED_OFFLINE`：离线快照过期时失败关闭受限业务，不静默放行；
- `TENANT_SUSPENDED_RECOVERY_ONLY`：只开放受控退款查询、对账/同步善后、导出申请等允许项。

客户端不得使用本地时间自行延长权益，不得修改签名快照，也不得把隐藏按钮当作安全控制。

## 3. 权限与数据范围

拟定权限至少拆分：申请提交、资料预检、开户审批、Provision 观察、强制补偿、套餐编辑/审批/
发布、暂停、恢复、注销、订阅续期/终止、实施项目管理、工单认领/转派/关闭、附件上传/下载和
导出。高风险动作执行职责分离，并记录理由、前后状态、影响租户/门店和 correlation_id。

对象存储路径、缓存键、异步任务、临时文件与导出目录均包含服务端确定的租户命名空间；下载
链接短期有效且每次签发重新鉴权。跨租户存在性不得通过错误码、计数、时延或文件名泄露。

## 4. 兼容与回退

Web/Flutter 只识别契约声明的能力版本。遇到未知新状态或能力时默认失败关闭并展示升级提示；
服务端在兼容窗口内保持旧字段语义。已生效配置不原地修改，失败回退到上一有效版本或通过新
前向修复版本处理。
