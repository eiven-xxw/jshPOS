# R3D-R3 可信 POS 会话联合旅程

## 执行结果

- 覆盖：`FLT-01..06`；
- 上下文：同一虚构租户、门店、终端、员工、班次及 `2026-08-25` 业务日；
- 页面：会话壳、收银工作台、组合支付、班次现金、原单退货退款和换货均使用正式 Widget；
- 外部边界：未配置正式应用组合根的页面失败关闭，电子支付、真实外设和真实换货执行均为零；
- 恢复：现金命令失败后退出页面再返回，继续使用原幂等键，不生成替代命令。

## 失败回归与最小修复

首轮联合回归稳定复现 `R3D-JNT-P1-003`：第二个现金动作失败后使用的键尾号为 `2`，退出并
重进现金页后同一内容却生成尾号 `1`。根因是操作键只存在页面 State，生命周期短于可信员工
会话。

最小修复把操作身份登记表提升到 `PosSessionShell` 会话作用域，页面只解析、完成或保留原键。
成功命令释放对应键；安全退出或关班成功清空登记表。修复未改变班次现金事实、服务端授权、
资金状态、数据库或 API。

## 证据边界

测试仅使用虚构终端和内部软件服务，不代表 `REAL_DEVICE`、真实钱箱、支付沙箱、完整 Alpha、
生产或商业验收。`R3D-JNT-P1-003` 更新为 `CLOSED_IN_BATCH`；整体 Finding 继续 `OPEN`。
