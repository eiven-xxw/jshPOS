# R3D-R2 商业运营与发布联合旅程

## 执行结果

- 顺序：`VUE-17 → VUE-19 → VUE-18 → VUE-20 → VUE-09`；
- 执行方式：同一 Vue Router、同一平台角色、可信租户/门店范围和权益版本；
- 页面：SaaS、订阅、服务、终端和发布五页均为正式组件；
- 权限：区分菜单入口权限与条件高风险按钮权限，最终授权继续由服务端执行；
- 外部边界：真实收费、Provider、附件正文、设备凭据、真实终端命令持续失败关闭；
- 跨页恢复：终端越权错误和关联标识在切换发布页后返回仍保持，未伪造设备成功。

## 失败回归

首轮错误地要求尚未读取权威订阅时出现“暂停”按钮；页面正确地未渲染条件动作。第二轮又揭示
终端菜单读取权限与激活签发按钮权限不能混用。测试据此分别冻结 route permission 与 button
permission；未修改任何页面运行时或服务端权限。

`R3D-JNT-P1-002` 更新为 `CLOSED_IN_BATCH`；整体 Finding 继续 `OPEN`。
