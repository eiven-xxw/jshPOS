# Gate 4A 数据主权、状态、不变量与策略

## 1. 数量事实

库存维度为 `tenant_id + warehouse_id + sku_id + SALEABLE`，规范哈希为稳定 `SHA-256`。流水严格满足：

- `quantity_before + quantity_delta = quantity_after`；
- `ledger_seq` 在维度内单调递增；
- `SALE_OUT` 的 delta 小于零，`SALE_RETURN_IN` 的 delta 大于零；
- 来源事件、来源聚合、来源行、移动类型在租户内唯一；
- 流水、策略版本、命令结果和审计只追加，不允许 UPDATE/DELETE。

余额保存 `on_hand/reserved/frozen/safety_stock`，可用量严格计算为 `on_hand - reserved - frozen - safety_stock`。本阶段 `reserved` 没有写入命令，保持零或只读历史兼容。

## 2. 来源状态

- 销售出库：仅 `COMPLETED + PAID` 订单快照；一个订单事件按全部行原子处理。
- 退货入库：仅 `SUCCEEDED` 原单退款；退款行必须存在于原订单，数量不得超过退款 Owner 已冻结数量。
- 命令状态：`PROCESSING -> APPLIED`；数据库提交前失败整体回滚，不保存半完成状态。重复同哈希返回 `APPLIED` 结果，异哈希返回冲突。

## 3. 策略

- `DENY`：锁内计算变动后可用量，小于零时拒绝整个命令。
- `ALLOW_AND_ALERT`：允许真实负数，保存策略版本并产生 `NEGATIVE_STOCK` 异常与 Outbox。
- `ALLOW_WITH_PERMISSION`：只保留 Schema 枚举，Gate 4A 不开放执行路径。
- 策略按租户+门店+仓库发布不可变版本，并以生效时间解析；命令显式记录实际采用的策略版本。

便利店模板默认 `DENY`。零食折扣店和社区超市仍继承 `DENY`，只有经后续业务评审的门店版本才可启用告警放行。
