# Gate 4A Flyway、容量、兼容与回退

## 1. 迁移

- V11：库存策略、余额、命令、不可变流水、异常、审计和 Outbox；所有业务唯一键显式包含 `tenant_id`。
- V12：菜单权限及保留 ID 冲突检查。
- 发布后记录 SHA-256，禁止修改；迁移失败使用前向修复，不删除库存事实。

旧应用忽略新表，新应用要求 V11/V12 均存在。回退旧应用时停止新的库存命令消费者，新表保留只读；恢复新应用后复用原 eventId 继续，不重新生成来源命令。

## 2. 容量与索引

初始工程目标按每租户 1,000 门店、每店 100,000 SKU、每日 100,000 库存流水的分区前容量模型评估；这只是设计上限，不是生产承诺。关键索引：

- 余额：租户+仓库+SKU+状态唯一；
- 流水：租户+维度+序号唯一，租户+来源+行+移动唯一；
- 命令：租户+eventId 唯一；
- 异常和 Outbox：租户+状态+时间。

批命令行数上限 500，按 SKU 稳定顺序锁定。任何分区/归档必须先证明不破坏全量重算与审计。

## 3. 重建与恢复

余额重建以流水 `SUM(delta)`、`MAX(seq)` 为唯一输入，先生成差异报告再在管理员权限下更新投影。流水缺口、哈希/数量不变量失败或重建后仍不一致均为 P0，停止库存消费者并保留证据。
