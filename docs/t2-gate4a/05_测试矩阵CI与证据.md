# Gate 4A 测试矩阵、CI 与证据

## 1. 固定测试矩阵

| 风险 | 自动化 |
|---|---|
| 重复/异哈希 | 同 eventId 重放 100 次单一效果；异哈希 409 |
| 租户逃逸 | 两虚构租户覆盖 Mapper、XML、任务、缓存、导出和对象键攻击 |
| 数量精度 | 六位小数、零/超精度拒绝，静态禁止 float/double |
| 负库存 | DENY 原子回滚；ALLOW_AND_ALERT 保存真实负数、异常和审计 |
| 原单权威 | 非完成订单、非成功退款、跨店/跨租户、伪造 SKU/数量拒绝 |
| 并发/故障 | 锁顺序、提交后响应丢失重放、流水/余额/Outbox 同事务 |
| 重算 | 线上投影等于流水汇总；篡改/缺口被拒绝或报警 |
| 迁移 | 干净 MySQL 8.4 执行 V1—V12、二次迁移为 0、不可变触发器有效 |

固定向量见 `contracts/t2/gate4a/test-vectors/inventory-fixed-vectors-v1.json`。Fake/合成结果的证据等级为 `STATIC/FAKE`，外部证据计数保持 0。

## 2. CI 门禁

治理、服务端全量测试、MySQL 迁移、库存固定向量、租户攻击、Flutter Linux/Windows 回归、Web、Secret、依赖差异、SBOM、许可证、覆盖率和证据索引必须全部通过。库存领域行覆盖率不低于 90%，分支覆盖率不低于 85%；禁止重跑掩盖 Flaky 或降低阈值。

## 3. 退出

三项需求只能在全部门禁通过后从 `IN_PROGRESS` 更新为 `VERIFIED`；`ACCEPTED` 仍须项目发起人确认。盘点、采购、成本、调拨、沙箱、实机和试点不得创建绿色占位。
