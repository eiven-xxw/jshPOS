# 四栈依赖兼容快照与回退计划

## 决策

R1 不批量升级 Maven、pnpm、Flutter Pub 或 Kotlin/Gradle 应用依赖，也不刷新锁文件。
本批在干净执行器中按 `Maven → pnpm → Flutter Pub → Kotlin/Gradle` 严格串行重建，
生成当前依赖树、可升级候选、SBOM、许可证、漏洞、测试与构建证据。存在新版本不等于
获准升级；需要修改依赖时必须按影响单独审批。

## 工具链

R1 请求 JDK 21、Maven Wrapper 3.9.9、Node 24、pnpm 10.33.0、Flutter 3.47.0、
Gradle 9.3.1、Android Gradle Plugin 9.1.0、Kotlin 2.4.0 与 Trivy 0.72.0。
实际执行版本随每个 clean run 进入证据，不能只依赖文档声明。

## 回退与升级边界

- 应用依赖未变，回退基线就是 `cdf0d3a5e60e679b483e1ea89b046958e4877c22` 的输入摘要；
- R1 不修改任何 Flyway/SQLite 已发布迁移；
- 高危/严重漏洞、许可证不合规、构建或测试不兼容必须失败关闭；
- 需要改变资金、库存、租户、支付、同步或迁移语义时立即停止并提交独立 CR 和 Requirement ID。
