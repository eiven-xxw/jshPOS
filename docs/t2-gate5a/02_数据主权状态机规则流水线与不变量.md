# Gate 5A 数据主权、状态机、规则流水线与不变量

> 文档编号：JSH-POS-T2-G5A-002

## 1. 数据主权

- `jshpos-promotion` 独占 `prm_*` 规则、版本、报价、解释、人工优惠、快照、分摊、退款恢复、包、审计和 Outbox。
- 商品与基础/门店价继续由 Catalog/Price Owner 管理；促销只接收冻结的价格输入，不回写价格表。
- Order Owner 在成交事务中保存经摘要核验的促销快照引用；促销不得修改已完成订单。
- Refund Owner 只通过 `PromotionRefundSnapshotPort` 获取原快照可退金额和逐行剩余额度；不得读取 Mapper 或按当前规则重算。
- `tenant_id` 只来自 `TrustedTenantContext` 或 POS 已绑定的可信设备上下文；请求体、规则 JSON、包内容、缓存键和路径参数中的租户值不是授权依据。

## 2. 规则与版本状态

```text
DRAFT -> VALIDATING -> APPROVED -> SCHEDULED -> ACTIVE -> ENDED
   |          |                         |          |
   +-------> REJECTED              PAUSED <-------+
                                          -> REVOKED
```

- `DRAFT` 可通过新版本内容替换；进入 `APPROVED/SCHEDULED/ACTIVE` 后内容不可变。
- 发布时间、门店业务时区和冻结 `business_time` 决定有效性，客户端当前时钟不能直接决定生效。
- 暂停、结束和撤销只影响新报价；已冻结报价和成交快照不改变。
- 同一规则的新修订必须使用新 `rule_version_id`；规则代码在租户内稳定唯一。

## 3. 固定计算流水线

1. 校验可信租户、门店、渠道、业务时间、币种、行标识、数量和版本。
2. 接收已冻结基础/门店价并计算行毛额。
3. 执行单品固定价、单品直减/折扣和第 N 件优惠。
4. 执行组合价、满额减和满件减。
5. PRM-002 准入后执行受权手工改价。
6. PRM-002 准入后执行整单固定/比例优惠。
7. PRM-002 准入后执行抹零。
8. PRM-003 准入后执行订单级最大余数分摊、冻结快照与指纹。

候选固定按 `priority desc, rule_version_id asc` 排序。互斥组先选择合法候选；`BEST_OF_GROUP` 优先优惠金额更大者，再按优先级和版本 ID 决胜。`STACKABLE/EXCLUSIVE/BEST_OF_GROUP/STOP_AFTER_APPLY` 必须显式配置，缺省为不叠加。

## 4. 金额与数量不变量

- 金额、优惠和应收均为 CNY 分的有符号 64 位整数；输入与计算过程必须防溢出。
- 数量为 `DECIMAL(19,6)`/`BigDecimal`；比例为 `DECIMAL(12,8)`/`BigDecimal`。Dart 使用整数定标值，不使用 `double`。
- `line_gross_minor >= 0`、`0 <= line_discount_minor <= line_gross_minor`、`line_payable_minor = line_gross_minor - line_discount_minor`。
- `total_discount_minor = sum(line_discount_minor)`；`payable_minor = gross_minor - total_discount_minor + rounding_minor` 且不得小于 0。
- 每个订单级调整的分摊总额精确等于调整额；最大余数按余数降序，再按 `line_no、sku_id、line_id` 稳定决胜。
- 输入行顺序、数据库返回顺序或 Map/Set 迭代顺序不得改变结果、解释顺序或指纹。
- 相同 `pricing_request_id + request_hash` 返回原结果；相同 ID 不同摘要返回 `PRM-IDEM-CONFLICT`。

## 5. 人工优惠与退款不变量

- 手工改价、整单折扣和抹零必须保存改前/改后金额、阈值版本、原因、操作人、审批人、终端、业务日和关联标识；需要审批时操作人不得等于审批人。
- 人工优惠不能让任何行或订单应收为负，也不能突破已冻结授权底价/最大优惠/抹零绝对值。
- 成交快照、调整和分摊只追加；同一订单只能冻结一个相同摘要的有效快照，同键异内容拒绝。
- 退款使用原行净额、原分摊和累计已退账本；累计数量、金额和优惠恢复不得超过原上限，最后一次退货承接余数。
- 门槛优惠默认不追缴；不支持的买赠返还、券返还或会员权益必须失败关闭并进入后续 Gate。
