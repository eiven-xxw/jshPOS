## 2. 共用页面状态

`useRecoverablePage` 只描述 `INITIAL/LOADING/READY/EMPTY/SUBMITTING/FAILED/UNKNOWN`
交互状态，不复制领域状态机。读取失败展示安全错误码和关联标识；同一操作身份并发只保留
一个 Promise；确定失败的价签命令继续复用既有原幂等身份，未知结果则锁定原操作，
只允许通过读取入口观察权威状态，不自动或经再次点击重放领域命令。

## 3. 组合支付装配说明

生产应用壳允许由组合根注入已有冻结订单的 `PosTenderController`。会话壳在导航前核对
`storeRef/terminalRef/shiftRef/businessDate` 与服务端确认的可信终端、当前班次完全一致；
任一不符返回 `TENDER_CONTEXT_MISMATCH`，不得进入支付页。

默认启动装配没有可信冻结订单来源，因此不注入控制器并显示“暂无冻结订单”。这不是绿色占位，
而是避免 UI 伪造订单、金额或已支付事实的失败关闭边界。

## 4. 未改变内容

- 服务端 Controller、Owner、API、资金/订单/库存/租户事实均未改动；
- MySQL/Flyway 与 SQLite 已发布迁移均未改动；
- 未增加 Provider SDK、HTTP 客户端、回调或网络调用；
- RTM 的 88 项 `ACCEPTED` 及外部 `BLOCKED`、UAT/REL `DRAFT`、LIC/JSH `DEFERRED` 均未改变。
