# Gate 1 候选领域模型、状态与不变量

## 1. 聚合边界

| 聚合 | Owner | 候选实体 | 不变量摘要 | Requirement |
|---|---|---|---|---|
| Product | 商品域 | SKU、Barcode、Unit、StoreAssortment | SKU/条码租户内唯一；主单位唯一；历史引用不物理删除 | T2-PRD-001/002/004 |
| ProductImport | 商品域 | ImportBatch、ImportRowError | 预检不改数据；提交幂等；批次回退只补偿本批次可逆变更 | T2-PRD-003 |
| PriceBook | 价格域 | PriceBook、PriceItem、PricePublication | 金额为最小货币单位整数；门店价优先；生效区间不歧义 | T2-PRC-001/002 |
| DataPackage | 分发域 | PackageManifest、Chunk、ActivationReceipt | tenant/store/version/hash/签名匹配后才原子切换 | T2-DPK-001 |

`tenant_id`、创建人和数据范围全部由可信服务端上下文注入；任何 API、导入行或数据包内容中的租户字段都不能成为授权来源。商品、价格和数据包分别拥有自己的事实，Controller 和通用工具类不承载领域判断。

## 2. 候选状态机

- SKU：`DRAFT -> ACTIVE -> INACTIVE`；`INACTIVE -> ACTIVE` 需新版本与审计；禁止物理删除被订单/库存引用的 SKU。
- 导入批次：`UPLOADED -> VALIDATED -> COMMITTING -> COMMITTED -> ROLLED_BACK`；任一校验错误保持 `VALIDATION_FAILED`，不得部分提交。
- 价格簿：`DRAFT -> APPROVED -> PUBLISHED -> RETIRED`；只有 `PUBLISHED` 可被打包，发布后内容不可改。
- 数据包：`BUILDING -> SEALED -> AVAILABLE -> RETIRED`；终端侧为 `DOWNLOADING -> VERIFIED -> STAGED -> ACTIVE`，任一校验失败保持旧版本 ACTIVE。

## 3. 冻结前决策（均未批准）

| ID | 待冻结问题 | 候选默认值 |
|---|---|---|
| DEC-G1-01 | SKU ID | 服务端雪花 BIGINT；离线只读，不在 POS 创建商品 |
| DEC-G1-02 | 条码唯一范围 | tenant 全局唯一，称重码由规则解析而非 SKU 重复条码 |
| DEC-G1-03 | 数量精度 | `DECIMAL(18,6)`，禁止 double/float |
| DEC-G1-04 | 金额与币种 | CNY 分整数；价格非负且不超过门店策略上限 |
| DEC-G1-05 | 门店价优先级 | STORE > TENANT_BASE；同优先级有效期不得重叠 |
| DEC-G1-06 | 导入回退 | 仅补偿本批次新建/未被后续修改的版本，冲突逐行报告 |
| DEC-G1-07 | 数据包签名 | Ed25519，密钥仅在服务端 KMS；PoC 不写入生产密钥 |
| DEC-G1-08 | 兼容窗口 | 当前 Schema N 与 N-1；超窗客户端拒收且保留旧包 |
