# Gate 1 测试矩阵、CI 与证据

## 1. 自动化矩阵

| 类别 | 必测内容 | 门槛 |
|---|---|---|
| 领域/状态 | SKU、导入、价格簿、数据包全部合法与禁止边 | P0/P1 分支 100% |
| 租户/权限 | API、Mapper、原生 SQL、任务、缓存、导入、导出、数据包 | 跨租户可见/写入 0 |
| 数据库 | MySQL 8.4 migrate/repeat/validate、复合 FK、唯一、CHECK、不可变 | 全部通过且无 skip |
| 导入 | 10k/100k、重复 SKU/条码、坏单位、同键同/异摘要、失败零可见 | 固定 seed 可重复 |
| 价格 | STORE/BASE、时间边界、重叠、并发版本、发布失败保持旧版 | 结果唯一、金额整数 |
| 数据包 | canonical hash、临时 Ed25519、损坏、错租户/门店、重放、N/N-1 | 错误全部拒收 |
| Web | client tenant 覆盖、金额类型、导入/发布 API 契约、构建 | lint/typecheck/JUnit/build |
| 安全供应链 | Secret、依赖、HIGH/CRITICAL、SBOM、许可证、IaC | 不得降阈值 |

## 2. CI Job

Gate 1 CI 至少包含 governance、server、mysql-migration、catalog-security-capacity、admin-web、security-sbom-license 和 evidence。证据 Job 必须重新解析 JUnit/JaCoCo、10k/100k 摘要、七类以上攻击面、迁移和 RTM 状态，生成 SHA-256 文件索引。

禁止 `continue-on-error`、`skipTests`、`passWithNoTests`、自动 retry 或删除失败 seed。观察到的 Flaky 必须固定 seed、记录根因并修复后以新提交完整重跑。

## 3. 证据分级

本轮最高证据为 `STATIC+UNIT+INTEGRATION+SYNTHETIC_CAPACITY`。`SANDBOX`、`REAL_DEVICE`、物理断电、真实商户迁移、`PILOT` 和商业验收均为 0；Fake/临时密钥/CI 性能不得解除外部阻断或用于商用宣传。
