# Gate 1 范围、非目标、决策与逐项准入

## 1. 允许范围

| Requirement | 能力 | Owner | 可执行验收摘要 |
|---|---|---|---|
| T2-PRD-001 | SPU、SKU、名称、状态与销售属性 | 商品负责人 | 租户内编码唯一，停用不抹除历史，乐观锁冲突可见 |
| T2-PRD-002 | 条码、单位和换算 | 商品负责人 | 条码保留前导零且租户内唯一，唯一主单位，换算无浮点 |
| T2-PRD-003 | 批量导入 | 商品/QA | dry-run、分页错误、幂等提交、无部分可见和安全回退 |
| T2-PRD-004 | 分类、品牌、扩展属性 | 商品负责人 | 分类防循环、编码唯一、属性 Schema 版本化 |
| T2-PRC-001 | 基础价和门店价 | 价格负责人 | CNY 分整数，STORE 优先，时间点解析结果唯一 |
| T2-PRC-002 | 版本发布和生效 | 价格负责人 | 同范围区间不重叠，发布不可变，失败保留上一版本 |
| T2-DPK-001 | 商品价格正式数据包 | POS/后端 | tenant/store/schema/version/hash/signature 完整且损坏拒收 |

## 2. 非目标

- 不实现订单、支付、退款、库存、采购、成本、促销、会员或后续 Gate；
- 不实现 POS Android 双槽安装、断点下载或实机性能；本轮只提供服务端包事实、签名端口与校验契约；
- 不接入公共商品库、鲸熵汇、供应商目录或任何无授权数据源；
- 不使用真实商户、真实条码库、生产签名私钥、支付凭据或未脱敏数据；
- 不承诺百万 SKU、真实大表迁移窗口或商业 SLA。

## 3. 冻结决策

| ID | Accepted 决策 | 原因与约束 |
|---|---|---|
| DEC-G1-01 | 平台创建商品使用 BIGINT；POS 只读，不离线创建商品 | 遵守平台主键规范并避免本 Gate 引入离线写冲突 |
| DEC-G1-02 | 标准条码在 tenant 内全局唯一，按二进制字符串保存 | 保留前导零并消除一码多 SKU 歧义；秤码由规则解析后另行准入 |
| DEC-G1-03 | 数量为 `DECIMAL(19,6)`；单位换算保存正整数分子/分母 | 禁止 float/double，换算可约分和精确重放 |
| DEC-G1-04 | 销售价为 CNY 最小货币单位 `BIGINT`，必须非负 | 与结算金额口径一致，不使用 JavaScript Number 做最终计算 |
| DEC-G1-05 | `STORE > TENANT_BASE`；同范围/SKU/单位的有效区间不得重叠 | 保证任一时间点价格结果唯一且可解释 |
| DEC-G1-06 | 导入先写 staging 并完整校验，再以活动版本指针完成原子切换 | 100k 导入不以超大事务换取表面原子性；未激活数据不可见 |
| DEC-G1-07 | 回退只切换可见版本或创建补偿版本，不物理删除已发布事实 | 历史和后续引用可追溯 |
| DEC-G1-08 | 数据包签名算法 Ed25519，生产实现只通过 KMS/HSM 端口 | 仓库和运行配置不得保存私钥；测试只用临时合成密钥 |
| DEC-G1-09 | 数据包 Schema 兼容窗口为 N/N-1，未知必需能力拒收 | 失败保持上一 ACTIVE 包，禁止带病覆盖 |
| DEC-G1-10 | 商品采用 SPU+SKU；Gate 1 只准入 STANDARD/WEIGHT/COUNT | 便利店主样板够用，组合/加工/服务商品留待单独评审 |

## 4. 十二维逐项准入

七项需求均必须满足：来源、范围、非目标、Owner、不变量、权限、审计、API/事件、迁移、容量、回退和测试。机器清单中任一项为 false 时保持 `DRAFT`。

跨租户、条码重复、主单位重复、导入部分可见、价格区间歧义、发布后改写、摘要或签名不匹配均为 P0 阻断。
