# Gate 6C 外部证据收件下一步操作指令

> 仅在《T2 Gate 6C-Prep 启动评审报告》门禁全绿并经项目发起人确认后使用。

```text
我确认《T2 Gate 6C-Prep 启动评审报告》，接受 Gate 6C-Prep CONDITIONAL PASS。

仅授权进入 Gate 6C 外部证据收件与离线验真，不授权 Provider 网络、真实终端命令、现场试点或完整 Alpha UAT。

保持 T2-PAY-002、T2-HWD-001、T2-PAR-001 为 BLOCKED，T2-UAT-001、T2-REL-001 为 DRAFT。只有真实资料达到 VERIFIED_DOCUMENT 后，分别提交独立执行准入评审等待我确认，不得自动解除阻断。

支付轨：按五家优先候选发出/整理统一 RFI，收集授权沙箱、测试商户/终端、官方版本化接口、签名/回调/退款/账单/限流/网络和技术联系人；Secret 不进入仓库。

硬件轨：收集至少一个主认证候选和一个兼容候选的厂商、型号、Android/固件、CPU/内存、SDK、样机，以及两种打印、扫码、电子秤、钱箱和客显资料；本阶段不得安装或下发命令。

伙伴轨：建立 5 家真实目标，取得至少 3 家可验证书面试点意愿，并核验脱敏样本授权、保留/删除和旧系统对账条件；真实身份与样本只进入受控系统。

完成首批收件与离线验真后，提交《支付沙箱执行准入评审报告》《实机执行准入评审报告》《设计伙伴解阻评审报告》和更新后的 Alpha P0 差距清单，等待我逐项确认。
```

项目发起人需要准备或指定责任人提供的首批输入：支付合作/技术联系人与资料入口；主机/外设厂商及样机联系人；5 家伙伴候选的受控身份引用。缺少输入时保持 BLOCKED，不猜测真实接口、设备能力或伙伴意愿。
