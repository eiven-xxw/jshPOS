# Gate 6C-Prep 范围、证据等级与准入边界

## 1. 目标与基线

- 工作分支起点：Gate 6B 封板提交 `f9b733adb2fe1715fd663bae6d2419c4eca668ff`。
- 已接受：`T2-UPG-001=ACCEPTED`，仅限内部 Provider 无关发布治理和合成执行证据。

本阶段的交付是“可收件、可验真、可决策、可失败关闭”的外部证据治理包，不是外部集成或 Alpha 执行。

## 2. 允许范围

- 保存候选清单、RFI/收件字段、非敏感联系人角色和资料截止点。
- 对用户或外部责任方提供的文件做离线来源、版本、适用范围、摘要和授权核验。
- 在仓库登记脱敏元数据、SHA-256、受控位置引用、验真人和证据状态。
- 准备支付沙箱、真实硬件、设计伙伴的独立解阻评审和 Alpha Go/No-Go 模板。
- 运行治理、契约、Secret、范围差异和既有内部基线回归。

## 3. 禁止范围

- 创建或调用 Provider SDK/HTTP 客户端、回调入口、账单下载器或真实支付终端。
- 安装真实 APK、调用静默安装 SDK、控制固件、重启、钱箱脉冲或远程终端。
- 接收真实资金、生产密钥、真实会员 PII、支付敏感数据或未脱敏商户数据库进入 Git/CI。
- 把候选、自填模板、公开资料、Fake、模拟器、合成包或内部人员意向提升为外部验收。
- 启动完整 Alpha UAT、试点发布或商业 Go-Live。

## 4. 证据等级

| 等级 | 定义 | 可支持结论 |
|---|---|---|
| MISSING | 尚未收到 | 只能保持 BLOCKED |
| RECEIVED_UNVERIFIED | 已收到但来源、授权、版本或摘要未核验 | 只允许隔离和补件 |
| VERIFIED_DOCUMENT | 来源、版本、授权、范围、摘要和保管人已验证 | 允许提交独立执行准入评审，不等于执行通过 |
| SANDBOX_EXECUTED | 在批准的授权沙箱按固定计划执行并封存证据 | 仅支持 T2-PAY-002 的沙箱结论 |
| REAL_DEVICE_EXECUTED | 在登记样机/外设上执行并封存设备、固件和日志 | 仅支持 T2-HWD-001 的实机结论 |
| PARTNER_VERIFIED | 书面意愿、签署主体、授权样本和对账条件已独立核验 | 仅支持 T2-PAR-001 的伙伴事实 |
| PILOT/PRODUCTION | 经后续独立审批产生 | Gate 6C-Prep 无权产生 |

证据只允许单向升级；发现撤销授权、错版本、错主体、摘要不符、范围超出或无法联系来源时，必须隔离并回退为 `BLOCKED`。

## 5. 收件元数据

每份材料至少登记：`evidence_id`、关联需求、轨道、类型、来源机构、标题/版本、发布日期、取得时间、授权范围、适用商户/设备/伙伴、数据分类、保管人、受控位置、SHA-256、验真状态、到期日、删除/撤销规则和审计引用。Secret 与原始敏感材料只保存受控位置引用，不保存内容。

## 6. 阶段退出门槛

Gate 6C-Prep 只在以下条件同时成立时可建议 `CONDITIONAL PASS`：

1. 三条独立报告和机器清单完整，所有缺失项如实为 MISSING/BLOCKED；
2. RTM 状态没有被模板或内部证据错误提升；
3. Alpha 差距、RACI、截止点、Go/No-Go 和安全回退可执行；
4. 网络调用、真实设备命令、完整 Alpha 执行均为 0；
5. 治理与证据门禁全绿。
