- 非目标：任何 Provider 网络、资金、实机、外设、伙伴联系、现场执行、完整 Alpha 或生产发布。

## 2. 证据状态机

| 状态 | 可证明内容 | 本阶段允许动作 |
|---|---|---|
| `MISSING` | 未收到真实受控材料 | 记录缺件，不能执行 |
| `RECEIVED_UNVERIFIED` | 收到不透明引用但来源、授权、版本、范围或摘要未闭环 | 隔离并离线核验 |
| `VERIFIED_DOCUMENT` | 来源、授权、适用对象、版本、范围、SHA-256、保管和生命周期均闭环 | 仅提交独立执行准入评审 |
| `EXECUTION_APPROVED` | 项目发起人批准具体范围、时间、责任人、停止和清除条件 | 仅执行批准矩阵 |
| `EXECUTED_EXTERNAL` | 已产生受控外部执行证据 | 仍须独立验收，不自动 ACCEPTED |

低等级证据不得替代高等级证据。公开文档只能证明候选存在；内部 Fake、软件预览和合成执行不能证明沙箱、实机或伙伴现场。

## 3. 统一受控元数据

每份材料必须登记不透明材料 ID、轨道、类型、来源主体、授权签署核验、适用产品/精确型号/伙伴范围、版本、生效与到期、SHA-256、字节数、保管人、受控位置、轮换、删除/吊销、验真人和复核人。材料提供、验真和最终批准必须职责分离。

仓库只保存不透明引用、SHA-256 和非敏感结论。支付 Secret、证书和真实商户终端号进入 Secret/支付受控系统；SDK 授权包、样机资产和设备证书进入设备资产系统；伙伴身份、联系人、意愿与样本进入 CRM/合同/隐私受控区。
