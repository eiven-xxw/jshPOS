实机准入后至少覆盖两机型启动/登录/数据包、扫码延迟与重复、100/1000 单连续交易、两打印方案缺纸/开盖/断连/重启、秤稳定/超量/负值/断连、钱箱授权/重复脉冲、客显隐私/断连、APK 前向迁移/失败回退、待同步和 UNKNOWN 资金状态下升级阻止、8/24 小时长稳及日志脱敏。

打印实机证据必须分别满足内置厂商 SDK 和标准外置打印链路；打印预览、Fake Adapter 或桌面输出不能替代任一方案。

## 4. 安全、资产与停止条件

- 样机序列号、设备证书、SDK 授权包和厂商账号只保存在设备受控系统。
- 固件、SDK、型号或授权摘要不一致，设备疑似生产在用，或命令可能影响营业时立即停止。
- 任何执行必须绑定批准样机、批准场地、操作人、时间窗、恢复点和停止开关。
- 达到 `VERIFIED_DOCUMENT` 后仍须项目发起人确认独立执行准入；当前设备命令和外设命令均为 0。
