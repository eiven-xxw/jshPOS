# Gate 3B 支付沙箱解阻输入与核验清单

## 1. 边界

本目录只准备 `T2-PAY-002` 的外部解阻评审，不创建 Provider SDK、HTTP 客户端、回调入口、凭据配置或网络探测。所有空缺必须保持 `BLOCKED`，不得用 Gate 3A Fake 结果替代。

## 2. 首接 Provider 决策

首接 Provider 暂记为 `ASSUMPTION`，在商务签约、覆盖区域、聚合码能力、Android 终端兼容、稳定性、费率、结算和技术支持材料齐全后确定。建议按以下顺序收敛候选池：拉卡拉、汇付、易宝、富友、通联；微信支付、支付宝和银联作为能力/路由兼容对象，不在未签约时宣称直连。

| 输入 | 必须证据 | 当前状态 | 通过条件 |
|---|---|---|---|
| 合作与授权 | 已签约主体、沙箱商户号授权范围 | BLOCKED | 法务/商务确认可测试且不涉及真实资金 |
| 沙箱账号 | 独立测试商户、最小权限操作员 | BLOCKED | Secret 管理交付，不进入仓库/日志 |
| 测试终端 | 终端型号、序列号、SDK/扫码模式 | BLOCKED | 绑定沙箱商户并可被撤销 |
| 正式文档 | 版本、发布日期、变更记录、错误码 | BLOCKED | Provider 官方来源且版本冻结 |
| 技术联系人 | 姓名、职责、升级渠道、服务时间 | BLOCKED | Provider 侧确认并完成一次非生产联络演练 |

## 3. 接口与安全核验

| 域 | 必核验项 | 当前状态 |
|---|---|---|
| 下单/支付 | 商户单号、终端号、金额币种、超时、UNKNOWN 查询 | BLOCKED |
| 签名验签 | 算法、证书链、密钥轮换、编码、规范串、时间窗 | BLOCKED |
| 回调 | 公网要求、TLS、源验证、重放防护、ACK、重试和乱序 | BLOCKED |
| 查询 | 原请求号复用、最终态优先级、频控和建议退避 | BLOCKED |
| 退款 | 原交易约束、部分退款、UNKNOWN、回调、退款单号 | BLOCKED |
| 账单 | 下载窗口、格式、压缩/加密、摘要、补单和时区 | BLOCKED |
| 限流 | 商户/终端/API 维度阈值、429/业务码和解封流程 | BLOCKED |
| 网络 | 域名/IP 白名单、DNS、TLS 版本、代理、超时和容灾域名 | BLOCKED |

## 4. 安全交付规则

- 凭据只能进入批准的 Secret 管理，仓库仅保存变量名和轮换 Runbook。
- 沙箱与生产网络、商户、证书、终端和账单存储完全隔离。
- 回调先原文落受控证据、验签、防重放，再映射为 Gate 3A `ProviderObservationPort`；验签失败不得影响资金状态。
- 任何网络调用必须在独立《支付沙箱解阻评审报告》由项目发起人确认后开始。
