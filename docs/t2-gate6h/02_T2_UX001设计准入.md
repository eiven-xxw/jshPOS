# T2-UX-001 设计准入

## 用户旅程

1. 终端可信校验、员工登录、门店/终端/业务日确认。
2. 根据服务端已发布行业模板版本展示便利店、零食折扣店或社区超市体验提示。
3. 开班后完成扫码/搜索、购物篮、促销与受权优惠、现金结算、同步、退货退款和关班。
4. 后台按可见行业模板切换工作提示，但所有数据继续来自正式 Owner API。

## 行业差异边界

| 业态 | 默认体验重点 | 禁止变化 |
| --- | --- | --- |
| 便利店 | 快速扫码、键盘结算、同步状态 | 订单、促销、库存算法 |
| 零食折扣店 | 多件录入、称重商品提示、批量关注 | 单位换算、价格和成本算法 |
| 社区超市 | 分类搜索、称重/多单位提示、交班关注 | 金额、退货与权限状态机 |

## 页面状态与恢复

- `BOOTSTRAPPING/LOCKED/SIGNED_OUT/READY/BUSY/FAILED` 均有稳定可见反馈。
- 重复点击共享单航班或禁用提交；失败不伪造成功。
- 键盘焦点、扫码输入、大触控目标、屏幕阅读语义和窄屏响应式布局必须有测试。
- 行业模板未知或不兼容时失败关闭到通用安全体验，不猜测业务规则。

## 权限与数据主权

- 行业体验只能从已验证配置/模板版本解析，不作为租户、门店或权限依据。
- Flutter 页面只调用会话、销售、退货和班次应用服务；Vue 页面只调用正式 API。
- 本需求不新增数据库表、迁移、Owner 事实或领域事件。

## 验收

- Dart 与 TypeScript 对三种行业代码映射一致。
- POS 与后台均显示当前体验边界、加载/空/失败/恢复状态。
- Flutter Widget/Domain、Vue 组件/模型、静态边界和既有全量回归通过。
- 外部执行计数全部为 0。
