# T2-RC-001 设计准入与内部候选变更说明

## 1. 候选身份与边界

内部候选 ID 使用 `jshpos-internal-rc-<commit短SHA>-<GitHub Run ID>`，绑定完整 commit、构建 Run、制品 SHA-256、合成临时 Ed25519 签名、公钥、SBOM、许可证、迁移测试、变更说明与证据索引。私钥只在单次 CI 内存/临时目录存在，绝不上传。

候选证据等级固定为 `INTERNAL_RELEASE_CANDIDATE`。外部支付、真实硬件、打印与设计伙伴仍为 `BLOCKED`；完整 Alpha、现场试点、生产和商业发布均为 `NO-GO`。

## 2. 本候选包含

- 服务端模块化单体正式 JAR、全量 Owner 测试、聚合 CycloneDX SBOM 与空 MySQL 前向迁移证据；
- Vue 正式生产构建、lint、typecheck、组件测试、依赖审计与许可证清单；
- Flutter POS 全量分析/测试/覆盖率、Linux 与 Windows 回归、Kotlin 编译、Android debug APK、Pub SBOM 与许可证清单；
- Server、Web、MySQL、Redis 与文件 SQLite 同窗合成运行闭环；
- UX、性能、OPS、Secret、漏洞、IaC、许可证、P0/P1 缺陷和证据门禁。

## 3. 内部 Go/No-Go

只有全部同一 Run Job 成功、必要制品唯一、摘要/签名可验证、P0/P1 为零、外部执行为零时，才允许 `GO_INTERNAL_RC`。`T2-LIC-001` 的 Aviator、simple-http、MySQL Connector/J 替换或法务关闭未完成，商业发布固定 `NO-GO`；该结论不得由内部构建覆盖。

## 4. 变更摘要

本 Sprint 在 Gate 6G 核心候选之上完成三业态体验收口、七维合成性能趋势、失败关闭部署配置、诊断脱敏、恢复/回退复验和可追溯内部候选装配；未新增支付机构、设备厂商、打印、现场伙伴或 V1 外业务算法。
