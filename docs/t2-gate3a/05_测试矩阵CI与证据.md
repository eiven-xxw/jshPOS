# Gate 3A 测试矩阵、CI 与证据

## 1. 固定测试矩阵

- 支付：创建幂等、重复异 hash、UNKNOWN 禁止二次 attempt、成功不回退、late success；
- 观察：重复、乱序、相同 ID 异 hash、金额/币种/主体不匹配隔离；
- 退款：部分/全部、并发占额、金额/数量超限、退款 UNKNOWN 和成功累计；
- 对账：内部仅有、渠道仅有、金额/币种/状态/重复引用/退款差异和生命周期；
- 安全：两个虚构租户、多门店、可信上下文缺失、Mapper/原生 SQL/任务/缓存/导出/对象存储攻击；
- 迁移：MySQL 8.4 从 V1 到 V10、重复 validate、外键/检查/不可变触发器和权限 ID 冲突；
- 范围：Provider HTTP/SDK、回调 Controller、凭据、真实数据、库存/促销运行时计数必须为 0。

固定 Fake 向量位于 `contracts/t2/gate3a/test-vectors/payment-fake-vectors-v1.json`，每个向量必须映射到可执行测试，禁止用随机成功掩盖失败。

## 2. CI 门禁

治理、服务端全 reactor、MySQL 迁移、支付状态机、退款上限、对账差异、租户攻击、Flutter Linux/Windows 回归、Web、安全/Secret、SBOM、许可证、覆盖率和证据聚合必须全部通过。禁止 `continue-on-error`、自动重跑、降低阈值或跳过失败测试。

## 3. 证据等级

所有 Provider 结果均为 `FAKE_CONTRACT`；`SANDBOX/REAL_DEVICE/PILOT=0`。Gate 3A 周门禁只能建议 `CONDITIONAL PASS`，不得宣称渠道已接入、真实资金可用、Alpha、可试点或可商用。
