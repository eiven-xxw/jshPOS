# Gate 3A 范围、非目标与逐项准入

## 1. 范围

| Requirement | 准入实现 | 验收重点 |
|---|---|---|
| `T2-PAY-001` | 支付意图、attempt、幂等命令和 Provider 无关状态机 | UNKNOWN 禁止自动二次扣款，成功事实不回退 |
| `T2-PAY-003` | 内部可信观察端口、重复/乱序/冲突合并 | 到达顺序不决定状态，相同观察异哈希隔离 |
| `T2-REF-001` | 原成功电子支付退款、金额/数量占额和退款状态机 | 并发累计不得超过原单可退上限 |
| `T2-REC-001` | 内部事实、合成账单双源和差异案例 | 不自动篡改资金事实，差异可追踪闭环 |

四项已经完成数据主权、状态、不变量、权限、审计、API/事件、Flyway、容量、回退、Fake 向量和 CI 准入，可以进入 `IN_PROGRESS`。

## 2. 非目标

- 不实现任何 Provider HTTP/SDK、外部回调 Controller、账单下载或沙箱网络调用；
- 不保存商户密钥、证书、付款码、银行卡敏感认证数据或完整敏感报文；
- 不实现现金退款、无原单退款、换货、跨单退款或人工改资金终态；
- 不实现库存回补、采购、成本、促销重算、会员或后续 Gate；
- Fake 不升级为 SANDBOX、REAL_DEVICE、PILOT 或商业验收证据。

## 3. 准入证据等级

Gate 3A 最高证据为 `STATIC+UNIT+MYSQL_INTEGRATION+FAKE_CONTRACT`。外部证据固定为 `sandbox=0, realDevice=0, pilot=0`，不得宣称 Alpha、可试点或可商用。
