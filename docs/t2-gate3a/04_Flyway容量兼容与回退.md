# Gate 3A Flyway、容量、兼容与回退

## 1. 迁移

- V9 创建支付、attempt、观察、退款、退款行、账单、对账案例、幂等、历史、审计和 Outbox；
- V10 创建权限；
- 不修改 V1—V8；发布后以 SHA-256 封印，只允许追加前向修复；
- 表以 `tenant_id` 进入所有业务唯一键、外键和主要索引。

## 2. 容量基线

- 单意图最多 8 个 attempt，UNKNOWN 时为 0 个新增；
- 单退款最多 200 行，单命令 JSON 最大 256 KiB；
- 单次对账批次最多 10,000 行，按租户/Provider/账单日分片；
- 观察、历史、审计和账单来源只追加，按租户与发生时间预留归档索引；
- API 列表强制游标/稳定分页，禁止无边界导出。

## 3. 兼容与回退

Gate 3A API/Schema 以 v1 发布，新增可选字段保持后向兼容。旧应用回退时不调用新模块，新表和不可变事实保留；迁移或发布失败采用前向修复和流量回切，禁止 DROP、TRUNCATE 或覆盖资金历史。Provider 适配器缺失时模块仍可启动，但 attempt 不会产生网络副作用。
