# Gate 6D API、离线、兼容、回退与测试准入

## 1. 端口边界

Flutter UI 只依赖：

- `PosSessionService`：可信终端校验、员工认证、权限、会话和安全退出；
- `PosCatalogRepository`：已校验目录/价格包的扫码和搜索只读能力；
- `PosSaleApplicationService`：购物篮、报价、人工优惠、挂取单和现金结算编排；
- `PosSyncStatusRepository`：积压、死信、最后成功游标和受控重试；
- `PrintTaskRepository`：打印任务只读预览与 Fake 执行；
- `PosDeviceGateway`：唯一设备契约，页面不得直接调用 `MethodChannel`。

Vue 只依赖 Foundation、System/RBAC 和 Catalog 正式 API。组合工作台不得引入新的聚合写接口，也不得把 `tenant_id` 作为业务参数提交。

## 2. 离线与一致性

- 终端可信绑定和当前员工会话必须仍在有效期内；吊销未知时按缓存有效期与风险策略失败关闭。
- 商品、价格、促销只来自摘要/签名/范围/版本已验证并原子安装的数据包；损坏、跨租户、过期和不兼容包不可见。
- 现金成交复用既有 SQLite 原子事务；UI 的 loading 状态不是事务或幂等保证。
- 同步采用既有 Outbox 事件和 ACK/游标规则；UI 只读取状态并请求应用层用原 event ID 重试。

## 3. 兼容、容量与回退

- UI 契约版本为 v1；未知枚举显示“待升级”且危险动作失败关闭。
- POS 最低触控目标 48dp；800×600 及以上布局不遮挡结算与错误状态；扫码输入按结尾符完成且 300ms 防重复。
- 单篮建议 200 行上限、搜索结果 100 行上限、挂单列表 100 条分页、同步积压显示至少支持 100k 计数而不加载明细。
- Gate 6D 不新增 MySQL/Flyway 和 SQLite Schema；若实现证明需要迁移，必须停止相应需求并重新准入。
- 回退通过保留 Gate 6C 技术基线入口、功能开关和兼容应用服务实现；不得删除或回写已形成的订单、支付、库存、成本、促销和审计事实。

## 4. 串行测试准入

### T2-POS-007

- 可信/未知/吊销终端，门店不匹配，登录成功/失败/重复，权限组合，会话过期，安全退出，业务日变化。
- Widget 覆盖键盘焦点、触控目标、加载防重复、锁屏和无敏感信息错误。

### T2-POS-008

- 扫码防重、搜索、空篮、200 行边界、促销/人工优惠权限、挂取单规则变化、现金不足、重复结算、磁盘失败、成交后打印失败、断网和同步积压。
- Java/Dart 既有金额和促销黄金向量继续逐字段一致。

### T2-ADM-001

- 正常、空、加载、部分失败、权限隐藏、服务端 403、租户/门店数据范围、重复提交、导入错误明细、版本冲突与发布回退。
- 组件测试断言只调用正式 API 且请求体不出现 `tenantId`。

### T2-E2E-001

- 两个虚构租户、三业态、多门店/终端；完整现金链路逐环节 correlation/event/idempotency 守恒。
- 注入重复、ACK 丢失、断网、跨租户替换、金额/摘要篡改、打印失败和业务日切换；最终收敛或显式失败关闭。
- Provider 网络、真实设备命令、现场试点和完整 Alpha UAT 计数必须为 0。
