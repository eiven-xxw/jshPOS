# Gate 6D 用户旅程、页面状态、权限、错误与审计

## 1. POS 主旅程

`启动 → 终端可信校验 → 员工登录 → 选择/确认班次 → 收银工作台 → 扫码/搜索 → 服务端或离线包报价 → 受权人工优惠 → 挂单/取单 → 现金结算 → 成交结果/打印预览 → 同步状态 → 交班 → 安全退出`。

页面只能表达应用层返回的状态。租户、门店、终端、员工、班次、业务日、价格版本和规则包版本不接受页面覆盖。

## 2. POS 页面状态机

| 状态 | 进入条件 | 允许动作 | 失败/恢复 |
|---|---|---|---|
| BOOTSTRAPPING | 应用启动 | 加载可信终端快照 | 超时进入 LOCKED |
| LOCKED | 终端未知、吊销、门店不一致或能力不满足 | 重试校验、查看稳定错误码 | 不允许登录和交易 |
| SIGNED_OUT | 可信终端可用 | 员工登录 | 失败不泄露账号存在性 |
| AUTHENTICATING | 已提交登录且按钮被锁 | 等待应用服务 | 重复点击复用同一次操作 |
| READY_NO_SHIFT | 员工与权限有效 | 开班、退出 | 业务日变化须重新确认 |
| SELLING | 有有效班次 | 扫码、键盘搜索、加减行、报价、挂取单 | 断网使用已校验包；无包失败关闭优惠 |
| SETTLING | 原幂等键已冻结 | 现金提交 | 禁止二次提交；未知结果按原键恢复 |
| SALE_RESULT | 成交事实已返回 | 预览打印任务、回到新单 | 不因打印失败回滚成交 |
| SYNC_ATTENTION | 积压/死信超过阈值 | 查看状态、按原事件重试 | 禁止生成新业务命令修复 UNKNOWN |
| SIGNING_OUT | 退出检查中 | 等待清理会话 | 活跃结算或未处理安全状态时拒绝 |

## 3. 权限矩阵

| 权限 | 作用 |
|---|---|
| `pos:session:login` | 登录可信终端 |
| `pos:shift:open` / `pos:shift:close` | 开班/交班 |
| `pos:sale:operate` | 扫码、搜索、购物篮、挂取单 |
| `pos:discount:manual` | 发起人工优惠 |
| `pos:discount:approve` | 审批超阈值人工优惠；操作人与审批人分离 |
| `pos:cash:settle` | 现金结算 |
| `pos:print:preview` | 查看打印任务与预览 |
| `pos:sync:view` | 查看同步积压和失败 |

Vue 沿用服务端正式权限：组织门店、用户角色、商品、导入和价格各自独立；前端指令只影响展示，不替代服务端授权。

## 4. 稳定错误码

| 错误码 | UI 行为 |
|---|---|
| TERMINAL_UNTRUSTED / TERMINAL_REVOKED | 锁屏且禁止离线绕过 |
| SESSION_EXPIRED / PERMISSION_DENIED | 清理敏感页面状态并返回登录或展示拒绝 |
| BUSINESS_DATE_CHANGED | 阻止新结算并要求确认班次 |
| CATALOG_PACKAGE_UNAVAILABLE | 禁止猜测商品/价格，提示安装已验证包 |
| PROMOTION_PACKAGE_UNAVAILABLE | 禁止猜测优惠，可按授权策略选择无促销结算或停止 |
| DUPLICATE_OPERATION | 保持原结果，不再次触发命令 |
| SETTLEMENT_UNKNOWN | 使用原幂等键查询/恢复，禁止重建订单 |
| SYNC_BACKLOG / SYNC_DEAD_LETTER | 明确积压数和人工修复入口 |
| PRINT_PREVIEW_FAILED | 保留成交事实，只重试原打印任务 |

## 5. 审计

登录成功/失败、终端锁定、权限拒绝、开关班、人工优惠申请/审批、挂取单、结算提交/恢复、打印任务和安全退出均保存 correlation ID、可信上下文摘要、动作、结果和稳定错误码。日志不得包含口令、原始凭据、会员身份密文或支付敏感数据。
