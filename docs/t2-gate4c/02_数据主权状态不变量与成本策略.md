# Gate 4C 数据主权、状态、不变量与成本策略

## 1. 数据主权

- `jshpos-inventory`：`inv_stock_*` 数量事实与库存流水序号。
- `jshpos-procurement`：`sup_*`、`pur_*`、冻结采购单价、换算、确认收货和原收货退货关系。
- `jshpos-costing`：`inv_cost_*` 策略、成本流水、成本余额、重建、审计和成本 Outbox。
- 客户端只能查询余额/流水和请求管理员重建或发布成本策略；不能提交 tenant_id、成本输入、单位成本、采购状态或库存数量。

## 2. 成本处理状态与顺序

成本事实没有可覆盖状态。一次库存流水只有 `NOT_SEEN → APPLIED`，失败时整笔数据库事务回滚，不留下半处理状态。成本维度的 `inventory_ledger_sequence` 必须等于 `last_inventory_ledger_sequence + 1`；重复同摘要返回原结果，异摘要、缺口和晚到未知事实拒绝。

成本策略发布后不可修改，按 `effective_from` 选择。Gate 4C 只允许 `WAREHOUSE/CNY/scale=6/HALF_EVEN/ZERO_KEEP_LAST`。

## 3. 核心不变量

- `quantity_before + quantity_delta = quantity_after`。
- `cost_amount_before + cost_amount_delta = cost_amount_after`。
- 成本流水序号严格递增；`inventory_ledger_id` 在租户内唯一。
- 数量非零时 `avg_unit_cost_after = cost_amount_after ÷ quantity_after`（六位 HALF_EVEN）；数量为零时成本金额为 0，最后有效成本保留。
- 采购收货、采购退货、销售退货只能使用 Owner 提供或历史流水冻结的成本，不接受客户端输入。
- 历史成本流水、出库快照、策略和审计不得更新/删除；更正通过新的权威反向库存事实、差异字段或受控重建表达。
- 同一事务中任何成本写入、审计或 Outbox 失败，库存流水和来源单据一并回滚。

## 4. 移动加权公式

- 正库存采购入库：`newAmount = oldAmount + inboundQty × inboundUnitCost`；`newAvg = newAmount ÷ newQty`。
- 销售/盘亏：按事务开始时 `avgUnitCost`；出库后原则上平均成本不变，数量归零时差异结清。
- 销售退货：优先使用原 `SALE_OUT` 成本；找不到时使用最近有效成本并标记估计，无任何成本依据则失败。
- 采购退货：使用关联原收货成本；成本数量不足时失败，不能让采购退货制造不可解释负成本。
- 负库存销售：使用最近有效成本并标记估计；无最近成本失败。后续采购先按估计成本结清负数量，实际差额写 `variance_amount_minor`，剩余正数量按本次采购成本估值。
- 盘盈：使用最近有效平均成本，无成本依据失败；盘亏使用当前平均成本。

## 5. 精度和货币

数量固定六位小数；成本用“分”为高精度计量单位并固定六位小数；币种固定 `CNY`；运算使用 `BigDecimal` 和 `HALF_EVEN`，禁止 float/double。财务展示或接口舍入不改变成本账本事实。
