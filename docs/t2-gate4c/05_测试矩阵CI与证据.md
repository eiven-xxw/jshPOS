# Gate 4C 测试矩阵、CI 与证据

## 1. 固定风险矩阵

- 采购：首笔/连续收货、冻结换算、部分退货、原成本、负库存结清差异。
- 销售：部分出库、出库快照、原成本部分退货、无原成本回退、数量归零。
- 顺序：重复、同键异摘要、乱序缺口、晚到、并发、事务回滚、重放和重建。
- 精度：六位小数、HALF_EVEN、零数量结清、金额/数量守恒、禁止浮点。
- 安全：两个虚构租户、多店多仓、Mapper/XML/任务/缓存/导出/对象存储攻击，Provider 网络和 Secret/PII 为 0。

## 2. CI

Gate 4C CI 至少包含治理、服务端完整 reactor、MySQL V1—V17、成本租户攻击、24 个固定向量、Flutter Linux/Windows、Web、安全/SBOM/许可证与证据汇总。`jshpos-costing` 核心 line ≥ 90%、branch ≥ 85%。不得 `continue-on-error`、自动重跑、跳过失败测试或降低既有阈值。

## 3. 故障注入

- 成本流水写入前后异常、余额更新冲突、Outbox 失败必须回滚库存与来源单据。
- 提交后响应丢失必须以同库存流水 ID 返回原结果。
- 序号缺口、乱序、晚到和并发必须拒绝或收敛，不能覆盖历史。
- 重建前后摘要一致；迁移失败使用前向修复，不能回写 V16/V17。

## 4. 证据等级与退出

本 Sprint 最高证据为 `STATIC+UNIT+MYSQL_INTEGRATION+SYNTHETIC_VECTOR`。全部门禁通过后 `T2-CST-001` 只可到 `VERIFIED`；`ACCEPTED` 必须等待项目发起人。Fake/合成数据不得解除 `SANDBOX/REAL_DEVICE/PILOT`，也不得形成 Alpha、试点或商用结论。
