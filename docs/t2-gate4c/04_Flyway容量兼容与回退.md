# Gate 4C Flyway、容量、兼容与回退

## 1. Flyway

- V16：成本策略、余额、不可变流水、重建、审计、Outbox、复合租户约束、唯一幂等键和不可变触发器。
- V17：`9200540—9200543` 成本菜单与权限。
- 迁移通过后写入 SHA-256 封印；已发布迁移不得修改，失败修复只能新增 V18+ 前向迁移。

## 2. 容量与索引

- 成本余额唯一键：`tenant_id + cost_scope_id + sku_id + currency_code`。
- 成本流水唯一键：`tenant_id + inventory_ledger_id` 和 `tenant_id + cost_scope_id + sku_id + cost_ledger_sequence`。
- 来源、业务日、重建和 Outbox 均有租户前缀索引。单维度短事务行锁；多维度仍按 warehouse、sku 稳定排序。
- 商业 V1 目标：单条成本处理 P95 < 100ms（不含网络），单维度百万流水可按库存流水、来源和日期定位；本 Sprint 只形成合成证据，不形成生产容量承诺。

## 3. 兼容

旧应用忽略 V16/V17 新表；新应用启动前必须确认成本策略存在。库存端口新增后，Admin 运行时必须装配 `jshpos-costing`，缺失实现时启动失败，禁止 No-op。

## 4. 回退与恢复

应用回退只能停用成本入口并回退应用；不得删除 V16/V17 或历史成本流水。事务失败全部回滚。投影异常通过只读聚合、差异审计和版本锁重建；序号缺口先补齐库存事实再重放。生产数据迁移、历史成本导入和财务期间切换属于后续实施门禁。
