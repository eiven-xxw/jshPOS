# 换货 CR 业务价值与影响摘要

权威 CR 为 `docs/governance/CR-T2G7B-009_exchange-orchestration-scope.md`。

## 推荐结论

建议 `CONDITIONAL GO`，采用“原单退货退款 + 新销售 + 只追加换货关联”的可恢复
Saga。拒绝创建独立换货资金、库存或净额算法。

## 决策要点

- 原退货按成交快照与累计已退上限；新销售按当前价格/促销冻结独立订单。
- 换货只持有两条腿的稳定命令 ID、摘要、状态、检查点和审计，不覆盖 Owner 事实。
- 跨 Owner 不使用分布式事务；不可逆事实后失败进入人工修复，不删除、不重建命令。
- 现金边界可以独立实现和验证；电子差额继续受 `T2-PAY-002` 阻断。
- 只支持同租户、同门店、有原单换货；不支持跨店、无原单或跨币种换货。

## 待项目发起人确认

确认本 CR 只代表允许进入 `T2-EXG-001` 正式设计准入和编码，不代表验收
`T2-EXG-001`，也不自动准入 `T2-PAY-004`、Gate 7C 或任何外部执行。
