# 测试矩阵、CI 与证据规范

| 维度 | 最低验证 |
|---|---|
| POS 原子性 | 正常、每写入检查点失败、磁盘失败、进程终止、重启同键恢复、同键异内容 |
| 金额 | 手工审批、抹零、挂取单后规则变化、业务日切换、头行守恒、现金找零 |
| 同步/订单 | 重复、乱序、Outbox/ACK 丢失、服务端已收客户端未知、快照替换、摘要篡改 |
| 退货退款 | 部分/最终退货、最后余数、累计上限、库存失败、退款 UNKNOWN、全量重放 |
| 租户权限 | 两租户、多店、多终端、Mapper/XML/任务/缓存/导出/对象存储攻击 |
| 跨端 | Java/Dart 对成交和退款固定向量逐字段一致 |
| 外部证据 | SANDBOX=0、REAL_DEVICE=0、PILOT=0，不能生成绿色占位 |

CI 必须继续执行 governance、server、Flutter Linux/Windows、MySQL、SQLite、跨端向量、交易故障、租户攻击、权限、Secret、依赖、SBOM、许可证、覆盖率和证据聚合。失败不得自动重跑掩盖 Flaky，不得降低阈值或跳过测试。

证据包含命令、提交 SHA、Runner、测试数量、失败 seed、迁移校验和、覆盖率、安全/SBOM/许可证摘要和 Artifact SHA-256。Fake 标为 `INTERNAL_SYNTHETIC`，不得用于外部验收。
