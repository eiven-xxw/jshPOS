# 会员与报表 DRAFT 设计准备

本文件仅为 `T2-MEM-001/002`、`T2-RPT-001/002` 建立后续准入输入，四项状态继续为 `DRAFT`，不得创建运行时表、Controller、Job 或写服务。

## 会员边界

- 最小化身份识别、分层授权、字段级脱敏、同意记录、撤回/导出/删除请求和操作审计；
- 等级与积分若后续准入，必须采用不可变权益流水和可重建投影，交易与退款只通过版本化事件；
- POS 离线不保存不必要个人信息，真实个人数据继续禁止。

## 报表边界

- 报表只消费权威 Owner 事件建立可丢弃投影，不成为订单、支付、库存或促销事实源；
- 查询强制租户、组织/门店数据范围、字段脱敏、导出审批、水印、限额和审计；
- 支付对账报表的外部账单部分依赖 `T2-PAY-002`，当前仍 BLOCKED。

## 合成验收输入

准备两个虚构租户、多店、多业务日的成交、退货、库存和支付差异向量；后续准入必须覆盖跨租户查询、越权导出、迟到事件、投影重建、重复事件和删除请求，不得以本设计文件宣称功能已实现。
