## 2. 本 Sprint 允许

- POS 离线现金成交与促销快照的同事务冻结和故障恢复；
- 服务端订单对不可变促销快照的只读校验及绑定；
- 原单退货退款对促销、退款、库存和审计 Owner 的幂等编排；
- 两个虚构租户、多门店、多终端和便利店、零食折扣店、社区超市合成数据；
- `MEM-001/002`、`RPT-001/002` 的纯设计准备。

## 3. 非目标与阻断

- `T2-PAY-002=BLOCKED`，不准 Provider SDK/HTTP、真实回调、账单下载、测试终端、密钥和资金；
- 不实现优惠券、积分、储值、会员/报表运行时、预算、应付、发票、总账、批次成本或复杂 WMS；
- Fake 不能解除 SANDBOX、REAL_DEVICE 或 PILOT；
- 不宣称 Alpha、可试点或可商用。

## 4. 准入结论

T2-POS-006 → T2-ORD-003 → T2-REF-002 已按依赖顺序分别完成设计准入、实现与独立验证，封板候选状态均为 `VERIFIED`。三项继续等待项目发起人确认；`VERIFIED` 不代表 `ACCEPTED`，未获确认前不得启动 Gate 5C。
