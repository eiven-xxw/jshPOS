# Gate 10A-R2 准备完成后的下一步操作指令

以下指令仅在 R2-Prep 完整治理 CI 全绿后使用：

> 我确认《Gate 10A-R2 启动评审报告》，接受准备阶段 CONDITIONAL PASS，并接受 ADR-074。
>
> 按 CONDITIONAL GO 启动 Gate 10A-R2-R1：G10A-MTN-P2-001 Server 可维护性正式整改。
> 以 R2-Prep 最终封存提交作为起点创建独立分支。本批只允许先补公开 API、错误码、事务回滚、
> 幂等、审计、Outbox、Owner 边界和数据守恒金标，再建立复杂度预算与既有 19 类只减不增白名单，
> 最后按风险顺序对获批类进行最小职责拆分。
>
> 禁止机械按行数拆类，禁止把领域逻辑移动到 Controller、Mapper 或通用工具类，禁止改变资金、
> 库存、租户、支付、同步、事件 Schema、API 或迁移语义。不得修改已发布迁移或新增业务能力。
>
> G10A-SQL-P2-001、G10A-RES-P2-001 继续保持 PREPARED，不得提前整改。完成后提交
> 《G10A-MTN-P2-001 独立周门禁报告》等待我确认，不得自动进入 SQL、资源、R3、完整 Alpha
> 或生产发布。
