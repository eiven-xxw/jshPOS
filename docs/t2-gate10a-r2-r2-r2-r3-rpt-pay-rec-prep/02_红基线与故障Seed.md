# 红基线与故障 Seed

## 当前可复现问题

1. v1 交互接口返回无界 `List`，正式 Mapper 没有 `LIMIT`、keyset 或签名游标；
2. 50 个门店的支付退款对账导出执行 50 次 JDBC 查询，并在内存中汇总；
3. 500 个 Provider 无关引用的现有核对旅程执行 1 次范围查询加 500 次逐引用查询，共 501 次；
4. Reporting 对账批量读取端口、Payment 事实批量只读端口和对账 HMAC 游标均未准入；
5. MySQL 8.4.11 固定 10k/100k 分布当前分别返回约 4,800/48,000 行并观察 filesort；
6. 租户攻击当前返回 0 行；十二项差异守恒金标需在后续分页、导出和恢复中逐项保持。

红基线只证明问题可重复，不是性能通过证据，也不代表生产容量或商业 SLA。

## 固定 Seed

| Seed | 当前红项 | 后续通过条件 |
|---|---|---|
| `R2R2R2-F03` | 交互结果无界 | keyset 页 1—500 且差异守恒 |
| `R2R2R2-F04-PAY` | 50 门店导出 50 查询 | 固定 10k/100k 分块预算为 1/5 |
| `R2R2R2-F07-PAY` | 租户/门店/权限攻击 | 越权结果恒为 0 |
| `R2R2R2-F08-PAY` | 无签名游标 | 租户、门店、筛选、快照或游标篡改失败关闭 |
| `R2R2R2-F09-PAY` | 500 引用共 501 查询 | 范围读取加批量引用读取不超过 2 查询 |
| `R2R2R2-F10-PAY` | 10k/100k filesort | 获批计划、索引和查询预算通过 |
| `R2R2R2-F11-PAY` | 资金与差异语义需金标 | UNKNOWN 不重发，十二项守恒不变 |
| `R2R2R2-F12-PAY` | 导出不可恢复 | 原身份恢复，0 重复、0 缺失 |
| `R2R2R2-F13-PAY` | 遍历期间投影可能漂移 | 失败关闭且不发布部分制品 |

静态红基线位于 reporting 测试目录，MySQL 证据探针位于 release 测试目录；二者只读取当前生产
实现并写临时测试数据库/制品目录，不创建候选索引。
