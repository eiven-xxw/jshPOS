# 测试矩阵与量化验收

| 维度 | 准备阶段证据 | 后续运行时量化门槛 |
|---|---|---|
| v1 兼容 | API/SQL/响应/摘要冻结 | v1 回归不变，v2 operationId 唯一 |
| 数据规模 | MySQL 8.4.11 10k/100k | 两级必跑；1m 未获准 |
| 交互分页 | 当前无界红基线 | 1—500/页，全遍历 0 重复/0 缺失 |
| 导出 | 50 门店=50 查询 | 10k/100k 查询数不超过 1/5 |
| 引用批量 | 500 引用=501 查询 | 范围+批量引用合计不超过 2 |
| 执行计划 | 当前 filesort 红基线 | 无不可接受全扫/filesort，摘要稳定 |
| 差异守恒 | 12 项金标冻结 | 分页/导出/v1 逐项一致 |
| 租户权限 | 跨租户 0 行 | 租户/门店/游标/导出攻击全部失败关闭 |
| UNKNOWN | Provider 无关金标 | 只观察原命令，资金命令新增数为 0 |
| 快照漂移 | Seed 已冻结 | 漂移显式失败，部分制品不发布 |
| 幂等恢复 | 当前路径缺失 | 原请求/游标恢复；同键异摘要拒绝 |
| 外部边界 | Provider 网络为 0 | 未独立解阻前继续为 0 |
| 迁移 | 当前不得变化 | 如需索引：独立 CR、空库/升级/重复/validate |

十二项守恒为：总行数、有内部事实行数、有账单行数、内部金额合计、账单金额合计、金额净差、
MATCHED 数、差异总数、OPEN 数、ASSIGNED 数、RESOLVED 数、IGNORED 数。另保存差异分类摘要，
保证分页/导出没有把不同差异类型互相吞并。

准备阶段退出要求 Ubuntu、Windows、静态测试、MySQL 和证据聚合 Job 全绿，生产目录变化为 0，
并取得项目发起人的运行时确认。该矩阵不形成生产容量、支付沙箱或商业 SLA 证据。
