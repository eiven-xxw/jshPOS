# CR-T2G8C-004：T2-SEC-002 生产安全加固独立准入

## 结论

`CONDITIONAL GO / IN_PROGRESS`。项目发起人已接受 Gate 8C-Prep，并只授权关闭三个既定内部安全发现。

## 唯一范围

- `G8C-SEC-P0-001`：生产配置 Secret 化、默认集成关闭和启动失败关闭；
- `G8C-SEC-P1-002`：Actuator 白名单、授权健康详情、独立认证与拒绝审计；
- `G8C-SEC-P1-003`：服务附件 10 MiB 前置校验、受限流式暂存、摘要与失败清理。

不新增业务能力、数据库迁移、前端页面、Provider/设备适配器或生产部署配置。`T2-MTN-001/T2-PERF-002/T2-RDY-001` 不因本 CR 获得编码权限。

## 设计准入

- 数据主权：配置由平台部署边界管理；管理认证由安全适配层管理；附件元数据仍由 Service Owner 管理，正文仍由受控对象存储管理。
- 事务：对象存储成功而数据库事务失败时删除对象；本地暂存独立于业务事务并在所有退出路径回收。
- 租户：对象键只能由可信 `tenant_id`、工单和服务端 ID 生成；请求、缓存、临时文件和对象存储攻击用例保持失败关闭。
- 容量：单附件最大 10 MiB，单上传堆缓冲区 64 KiB；全局 64 MiB multipart 只为既有迁移能力保留，不改变 Service 上限。
- 兼容与回退：不改 API 路径、业务状态、表或已发布迁移；只允许安全配置模板和正文传递方式变更。

## 验收

三个 Finding 必须全部有自动测试和完整 CI 证据，P0/P1 开放数为零，RTM 才能更新为 `VERIFIED`。外部四项、UAT/REL、LIC/JSH 及零执行边界必须保持不变。
