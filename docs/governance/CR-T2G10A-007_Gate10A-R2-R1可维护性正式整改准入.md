# CR-T2G10A-007：Gate 10A-R2-R1 可维护性正式整改准入

- 日期：2026-08-26
- 状态：APPROVED
- Finding：`G10A-MTN-P2-001`
- 基线：`5b02eebe165a6151b08f3d27fb64ec58210e3adf`
- 分支：`t2/gate10a-r2-r1-mtn-runtime`

## 决策

接受 ADR-074，仅准入 Server 可维护性整改。先建立行为金标和复杂度预算，再按采购、批次库存、
调拨、补货、退货编排顺序进行最小职责拆分。公开 API、错误码、事务边界、幂等、审计、Outbox、
Owner 数据主权和业务守恒必须保持不变。

## 停止线

SQL/索引、依赖、配置、已发布迁移以及资金、库存、租户、支付、同步或事件语义变化均不在范围。
出现此类需要时立即停止并提交独立 CR。`G10A-SQL-P2-001`、`G10A-RES-P2-001` 继续 PREPARED。
