# T2-E2E-003 可重复运行手册

## 1. 本地快速复核

```text
python scripts/check_t2_gate6g.py
python scripts/audit_t2_gate6g_core.py --output artifacts/t2/gate6g/core-audit.json
python scripts/audit_t2_gate6g_api.py --output artifacts/t2/gate6g/api-audit.json
python scripts/audit_t2_gate6g_data.py --output artifacts/t2/gate6g/data-audit.json
python scripts/audit_t2_gate6g_integration.py --output artifacts/t2/gate6g/integration-audit.json
python scripts/run_t2_gate6g_internal_v1_candidate.py --output artifacts/t2/gate6g/source-candidate.json --seed-ledger artifacts/t2/gate6g/source-seeds.json --defect-ledger artifacts/t2/gate6g/source-defects.json
```

在 `pos-flutter` 执行：

```text
flutter pub get --enforce-lockfile
dart format --output=none --set-exit-if-changed lib test/gate6g
flutter analyze --fatal-infos
flutter test
```

## 2. 独立 CI

推送 `t2/gate6g-sprint17-core-productization` 后只认 `.github/workflows/t2-gate6g.yml` 同一 run 的结果。候选 Job 必须下载同次治理、Server、MySQL、双平台 POS 和 Web 制品，不允许引用旧 run 或手工上传的绿色报告。

## 3. 结果核验

1. `internal-v1-core-candidate-report.json` 的 `evidenceLevel` 必须为 `INTERNAL_V1_CORE_CANDIDATE`。
2. `executionMode` 必须为 `SAME_RUN_FORMAL_COMPONENT_EVIDENCE`，P0/P1 为 0，六条销售、六条退货和十二 seed 全部存在。
3. 外部执行七项必须全部为 0，`commercialClaimAllowed=false`。
4. 删除报告中的 `evidenceSha256` 后，以排序、紧凑 UTF-8 JSON 重算 SHA-256，必须完全一致。
5. 最终 evidence index 必须包含治理、Server、MySQL、双平台 POS、Web、运行栈、内部候选和安全共九类上游目录及每个文件摘要。

## 4. 失败处置

保留失败 run 和日志；修复根因后以新提交完整重跑。禁止只重跑失败 Job、删除/跳过用例、降低覆盖率或安全阈值、修改已发布迁移或手工制造候选报告。
