# 范围、数据分布与执行拓扑

## 范围

本批只增加 `jshpos-release/src/test` 中的合成夹具、正式 Mapper 只读解析适配和 JDBC 证据测试。
生产 Java、Mapper、SQL、POM、索引、数据库对象、配置及 V1—V87 迁移保持不变。

## 拓扑

```text
GitHub ubuntu-24.04
  ├─ MySQL 8.4.11（固定镜像摘要，临时空库）
  ├─ 22 Owner V1—V87 正式迁移 + Flyway validate
  ├─ jshpos-release 测试作用域 JDBC 夹具/采集器
  └─ Artifact：参数、统计、SHOW INDEX、JSON/TREE计划、查询数和权限攻击
```

## 固定数据分布

- 两个虚构租户：80%/20%；使用相同自然键验证租户谓词。
- 每租户热点门店占60%，热点 SKU 占20%。
- `SMOKE_10K` 与 `BASELINE_100K` 对全部12条查询执行。
- `TREND_1M` 只扩容并执行获批的 `RPT-SALES`，标记 `SYNTHETIC_TREND_ONLY`。
- 三条动态报表查询的可选筛选项冻结为未提供，保持当前无分页主路径。
- 无真实商户、PII、支付凭据、终端号或外部网络。

## 证据判定

计划形态、估算/实际行、返回行、查询次数、租户攻击和只读权限是主要证据；墙钟时间只作诊断，
不得单独用于 Go/No-Go。发现需要索引或分页契约变化时必须提出 CR，不能在本批直接整改。
