# CI 与证据规范

## Gate 8C-Prep

本阶段未改运行时，复用 Gate 8B 封存全量 CI，并新增：

- Ubuntu 治理：RTM、合同、基线、状态、零执行、范围和依赖差异；
- Windows 治理：UTF-8、路径、同一审计规则可重复；
- 仓库审计：安全、Owner、OpenAPI、Flyway、SQL、文件规模、性能时序、许可证与发布阻断；
- 证据聚合：原始报告和 SHA-256 索引。

## Gate 8C 正式整改

每个整改批次必须恢复完整治理、Server、Web、Flutter Linux/Windows、Android/Kotlin、MySQL、SQLite、跨端向量、迁移、权限/租户、Secret/PII、依赖、SBOM、许可证、覆盖率和既有 Gate 回归。

## 禁止项

- 不得降低阈值、跳过失败测试或自动重跑掩盖 Flaky；
- 不得修改已发布迁移；
- 不得把发现从台账删除来制造 P0/P1 为零；
- 不得把内部静态或合成证据标记为 SANDBOX、REAL_DEVICE、PILOT、FULL_ALPHA、PRODUCTION 或 COMMERCIAL。
