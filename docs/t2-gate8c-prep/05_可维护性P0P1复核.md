# 可维护性 P0/P1 复核

## 结论

未发现会立即破坏资金、库存或租户事实的可维护性 P0；发现五项 P1。

1. `G8C-MTN-P1-001`：Service Owner 直接注入 SaaS 应用服务，违反跨 Owner 只通过端口/事件协作的边界。后续应在 Service 内层定义只读权益端口，由 SaaS 适配器实现。
2. `G8C-MTN-P1-002`：Gate 7B 准备期与正式运行时 OpenAPI 对换货和组合支付存在重复方法路径定义，导致全库契约审计无法确定唯一权威契约。
3. `G8C-MTN-P1-003`：Gate 6G 数据审计器把合法 Flyway `beforeEachMigrate` 回调当作非法版本迁移，说明质量工具已落后于仓库事实。
4. `G8C-MTN-P1-004`：Foundation 的锁定查询使用注解 `SELECT *`，不符合已生效的“复杂 SQL 进入 XML、显式列与 resultMap”规范。
5. `G8C-MTN-P1-005`：Flutter 结算应用服务 3343 行、主结算页面 1257 行，职责和变更半径过大。拆分必须保持 SQLite 单事务、恢复幂等、错误码、金标向量和故障 seed 不变。

整改不得复制状态机、改写历史迁移、跨 Owner 访问私表或借重构新增业务能力。行为变化必须另行 CR。
