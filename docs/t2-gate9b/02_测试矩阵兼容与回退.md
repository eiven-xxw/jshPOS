## 兼容规则

1. HTTP method、规范化路径和路径参数名均属于当前兼容契约；客户端与 Controller 保持现状。
2. 本批没有修改请求/响应 DTO、错误码、权限、幂等键、分页、资金、库存或租户行为。
3. Service/Subscription 的原 `openapi.yaml` 保留为不参与当前运行时的替代指针，历史文档引用更新到
   新当前契约，防止同一能力同时存在两份权威声明。
4. 已发布 MySQL/SQLite 迁移不修改；无 Schema 或数据回退动作。

## 回退

若本批契约造成客户端生成、文档发布或权限回归失败，只回退当前 OpenAPI 和 Gate 9B 治理提交，
不回退业务事实、不执行数据库脚本、不修改 Controller。回退后 `G9A-API-P1-001` 恢复为 OPEN，
重新冻结差异并等待评审；不得以删除契约检查或放宽精确路径比较完成回退。
